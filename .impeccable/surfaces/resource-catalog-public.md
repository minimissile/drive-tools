# 公开资源清单

Mode: Read。目标是快速找到资料并进入本人网盘分享，必要时查看已有内容介绍。

适用 `/c/<slug>`，实现来源 `cloudflare/resource-links/src/catalog-page.ts` 与 `catalog-style.ts`。沿用 `site-shell.ts` 的白色背景、系统中文无衬线、品牌蓝 `--blue`、蓝灰辅助色 `--muted`、轻分隔 `--line` 与中性底 `--wash`；不改变单资源页和全站公共组件。

标题32px、介绍15px、资源标题16px、分类及操作12px。桌面分类栏168px，列表为内容列与160px操作列，行内18px/16px留白。通过共同对齐线、字重和分隔线组织目录，不把每个资源包装成卡片或大块标题。

分类数量来自完整清单；结果数量来自当前筛选。搜索与分类由SSR保留，不让只读访问触发生成或发布。多分享保留一个直接入口，附加链接使用原生details展开；提取码与链接成组，长内容自然换行，不隐藏可访问资料。

当前实际18项清单用于人工视觉核对。保留唯一H1、canonical、结构化数据、既有分页和noindex边界。按项目桌面范围验收，不因常规预览扩展到小屏专项。
