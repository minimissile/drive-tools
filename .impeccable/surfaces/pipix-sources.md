# 公共皮皮虾采集

Mode: Operate。将既有采集工作区独立到工作台通用内容操作，继承白色桌面系统。

## Direction contract

THESIS：一次采集、多渠道草稿各自编辑；来源记录与渠道交付状态明确分离。

OWN-WORLD：沿用系统中文字体、白色 Panel、蓝色主操作、语义状态，以及 tokens.css、form-controls.css、Select、CheckboxField、Pagination 和 QueryError 的规格。

STORY：用户先采集并挑选原帖图文、评论，再指定渠道及必要的账号；保存后打开已有渠道编辑器，不自动填写或发布。重复采集保留各渠道编辑成果。

FIRST VIEWPORT：独立“皮皮虾采集”标题；左侧“获取数据列表／分享链接”两个采集方式及采集历史，右侧内容预览及挑选。新用户默认本地知识库，可切图文搜索／推荐／作者／话题；Key 统一在“连接与设置 → 内容数据源”维护，采集页只显示状态与跳转。批量采集操作位于候选列表上方，不必滚过全部帖子。渠道去向、字数提示、草稿操作与交付记录位于内容之后。工作区纵向滚动覆盖 1440×900 与 1366×768。知乎和微博页面提供公共采集快捷入口。

SETTINGS EXTENSION：沿用 SecretField、Panel、Field、Status、Notice、table 及 settings.css；只新增“内容数据源”分区和折叠的容量实测。参数回传与返回量效果分开，实测结果只报告当前关键词和接口的最大观察值，不宣称全局上限。知识库按接口整页入库，选择上限与本地显示分页不截断归档。

FORM：既有双列工作区，新增去向选择与交付记录；seed: none (unavailable)。测试图片标明本地模拟，不是发布素材或装饰资产。

FINISH：unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

## Documentation boundary

普通业务结构调整，不新增视觉系统或公共 token。初版记录时根目录没有 PRODUCT.md、DESIGN.md；后续以实际已有规范为准。复核仅记录现有控件、样式和截图的符合性，保留先前知乎采集的历史验收记录。

## 2026-11-03 · 公共编辑供稿

本轮已读取当前根DESIGN.md，继承白色紧凑工作台，没有替换公共规范或引入装饰图。工作区改为单层“供稿候选／编辑队列／供稿日志／发现与采集”导航。候选区按计划、账号、方向、受众组织紧凑两列表单，关键词与批量操作同行；编辑区以约1:2的来源与稿件分区，原图、真实评论和来源缺失提示在左，观点、正文、依据与交付在右。共用Select、CheckboxField、QueryError、Pagination、LogWindow，移除新表单对全局相邻Field间距的叠加。

实际源码窗口手动查看了10条长内容候选、无匹配空态、两项采集队列、真实餐具配图、保存后的v3记录、AI事实锁定、暂不采用禁用状态及7条真实日志。原始图片为采集材料，不作装饰资产。未做自动化截图回归、计费生成或渠道发布。来源/编辑/交付已拆为领域组件，备份、审核失效与账号约束做源码复读；发现日常稿来源URL与原校验冲突、账号归属遗漏及旧入口不识别新交付的问题并修正。类型检查和差异检查通过；动态验收范围限于上述本地流程，完整神评补采与渠道交付未宣称通过。

最终复读还发现共用原帖图片getter会读取重采集后的最新图片，与编辑快照不一致；已改为按编辑单和图片哈希读取冻结附件，并在当前源码界面重新看到同一原图。收尾结论：本地候选、采集、编辑保存、暂不采用及日志可交付；付费生成、评论接口和完整渠道交付不包含在本轮动态验收结论中。

## 2026-11-03 · 评论库与按方向补料

继承既有Operate布局，自动补料放在候选关键词之后，以当前预算、一次授权、运行状态和缺项提示组成同一分区。评论库默认折叠，展开后用真实归档数、可用数、过滤数、神评标签、分页与独立的单次补采授权说明覆盖范围。共享规则放到内容数据源设置；免费网络检查和计费请求分开。沿用Select、CheckboxField、QueryError和LogWindow，不引入图片装饰或新设计系统。

实际源码桌面已手动查看13条PPT搜索结果、1份自动资料包、1张原帖图片、5条真实评论、空正文和作者观点、不可直接交付状态，以及正式过滤词维护入口。临时词“好家伙”命中后，旧快照对应复选框禁用，评论库保留归档5条而仅展示可用4条；随后恢复正式词表。用户授权最多4次，实际3次（含首次未知结果），没有新增第4次请求；不把高赞标成神评。采集图片保留在来源快照中，未声明原创或批准使用。最终复读补上上限耗尽后处理已有数据、旧快照在使用前重新过滤及原始分享页评论不被过滤覆写的边界。结论限于真实列表、评论、图片到待编辑资料包的连通；未做自动化回归、付费生成、稿件交付或公开发布。

日志复核发现供稿页最初仅放入LogWindow本体，缺少知乎页的阅读控制；已补齐全屏、暂停显示、跟随、复制入口，并复用共享格式化方法。当前源码中实际查看14条事件、打开全屏、暂停阅读、按运行ID筛出3条事件、清除搜索并按Esc退出；文字与底部操作可见，长任务ID正常换行。复制未进行剪贴板写入实测。此处继续遵守白色桌面工作台约定，不拓展小屏验收。
