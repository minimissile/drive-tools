# 资源清单
Mode: Operate

沿用盘序现有白色桌面工作台。用户可描述需求由AI检索生成草稿，或手动选取/按分类收录；在清单上下文中审阅条目与维护发布记录。使用清单索引、编辑与预览内容区、发布维护区；不引入新视觉系统。

手动条目编辑器使用1040px宽版公共Dialog：顶部标题、收录方式、排序共享对齐线，介绍独占一行；下方左侧检索资源，右侧维护选集。使用13px条目标题、12px提示及公共30px紧凑操作，内容区可滚动、保存固定在底部。条目覆盖编辑与移除均只影响本清单。

AI入口保留需求、范围、数量和直接可见的批次进度，费用范围就近说明。暂停只停后续批次，未知结果的重试显示可能再次计费。生成结果仅交接到编辑器，不把生成成功写成清单已保存或已发布。

首屏应看懂当前清单、分类、可发布资源数量和主操作。未建立清单时仅保留创建入口与简短流程说明。公开预览用紧凑表格，长标题换行，描述限制行数；编辑表单使用现有公共控件。

工作区沿用双栏，外层按剩余高度铺满，不随资源内容整页滚动。左侧清单标题、搜索和状态固定，仅长清单条目区内部滚动；右侧标题、页签、预览搜索工具栏与分页固定，资源内容独立滚动。使用公共SearchField合并图标、输入、清空与外框焦点，所有文字按钮使用公共带边框Button，包含禁用状态。

清单item使用10px内边距、6px条目间距，名称下方按可用宽度排列分类/数量与发布状态。预览表格使用独立32px选择列、资源内容列、访问链接列及72px操作列；单元格上下10px，说明默认最多两行并可展开，表头跟随内容区吸顶。“删除所选”与搜索同行，跨页选择数量就近显示；条目删除后提供撤销入口。分类编辑器可恢复已删除条目；翻页和搜索回到资源内容顶部。

发布是明确的辅助交接：复制/导出、打开官方编辑器、设置分享权限、登记链接。状态不暗示后台自动发布。页面无大指标卡、装饰渐变、手机适配或深色主题。

验收：1366×768 / 1440×900；检查主要操作、空态、加载/错误、长内容、版本差异及账号入口。
