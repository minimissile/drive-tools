# 资源图文营销

Scope: existing workspace tool extension, Operate mode. Entry: 工作空间 → 资源图文营销; also listed in 工作台 → 通用内容操作.

THESIS: 从本人资源与中文口令制作三张真实 PNG，再交付到指定平台官网，保存实际提交结果。
OWN-WORLD: 继承 DESIGN.md 的白色桌面工作台、系统中文字体、品牌蓝、公共控件和语义反馈。图文画布是可导出的内容素材，配色独立于应用主题。
STORY: 选择资源 → 编辑说明与口令 → 三页预览 → 保存与核验导出 → 官网人工发布 → 回填结果。
FIRST VIEWPORT: 左侧内容表单，右侧三页并排预览；当前资源、任务选择、版本和操作结果清晰可见。桌面按1440×900及1366×768检查，不做移动端专项。
FORM: 使用现有 Header、Panel、Field、Select、QueryError；新页面只组合领域组件。code-led local extension; concept-seed not applicable to this specified extension; context launcher unavailable (permission denied).
MEMORY: 三页对应封面、详情、获取；中文口令原样进入领取图和平台文案，独立于四位提取码。

## 2026-11-01 封面强化

应用编辑器维持 Operate；导出画布按 Persuade 处理。大字封面用满幅电光蓝、荧光黄重点词、倾斜海报标题和独立卖点块，暖色版使用朱砂红与奶油纸。已有原封面可切换为完整主图海报：竖图配右侧大字，横图配下方标题，保留原图内容。资源名优先读取，卖点其次，领取提示收在底部；不增加销量、热度、稀缺或资源完整性主张。

封面标题支持人工换行和原文重点词高亮；短标题字号可达280px，文字自适应并保留溢出拦截。新任务不再将含作者、来源地址的资源摘要自动塞入封面卖点。标题字体为本地得意黑v2.0.1，正文与口令保持系统字体。两版与三页复用同一渲染、预览和导出路径；排版版本升级要求已有任务重新保存、导出。

本轮为源码检查与手动视觉核对，不自动运行测试。共享源码窗口已查看编辑器，另由开发预览直接调用相同画布模块核对原图与缩略图；开发预览没有业务IPC、不写任务、不构建进发行包。

约束：不接服务商、不调用付费模型；四盘仅复用既有同盘转存；首版官网上传与提交由用户完成。打开官网不等于提交或公开。固定持久会话目前每工作空间每平台一份，真实登录身份识别与多账号选择留待后续适配。

首版工作流验证记录（非本轮封面调整）：隔离数据库业务专项；共享源码窗口按窗口ID操作，只创建和清理当时任务。导出测试须区分模拟分享核验与真实远端核验。未验证的实际平台能力不得标为已通过。
