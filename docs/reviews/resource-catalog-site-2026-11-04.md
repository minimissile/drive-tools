# 资源清单与落地页打通 · 2026-11-04

## 分工与接口

用户明确授权创建“资源清单功能维护”对话（`01a1a609-7cd2-7002-a39c-276cc8bc3505`），与“资源库 Agent -SEO&GEO”协作。前者维护本机清单与发布适配；后者维护公共协议、Cloudflare存储、站点页面和部署。两侧使用同一工作区，没有复制仓库或另外启动桌面后台。

- `shared/catalog-landing.ts`：公开快照白名单，不上传排除项、网盘账号或内部路径；新增可选的已有资源页短码关联。
- `GET/PUT/DELETE /api/catalogs/:catalogId`：沿用固定入口管理令牌；首次生成16位随机短码，更新及重新发布保持同一网址。
- PUT包含operationId、expectedVersion、清单revision与不可变快照。数据CAS、操作回执、IndexNow通知在单条写入及D1触发器内原子提交。重试返回原回执，客户端再读取当前版本，避免把历史回执误认作现状。
- DELETE为软撤下，公开网址返回410；可用新版本恢复同一地址。归档本地清单不自动撤下，存在站点发布/待核对操作时不允许直接删除本地维护记录。
- 管理连接地址可以是原Pages/Workers别名，公开URL采用服务回报的正式域名；客户端校验HTTPS与清单路径，管理令牌始终只发送原配置服务，不随公开URL换向。
- 首次发布至少一份资源；已有清单可更新为空，以移除旧分享。1MiB、2000资源/每资源200分享限制会明确报错，不静默截断。

## 公开展示与发现

`/catalogs`列出已发布的非空清单；`/c/<短码>`服务端输出标题、介绍、分类、资源说明、标签与网盘链接，支持关键词、分类及每页50条分页。已有合格的单资源说明页可从清单进入；云端每次读取时再次检查其仍可公开。没有单资源正文的资源可以保持清单条目，不触发AI生成。

页面使用现有站点品牌、白色阅读布局、规范网址与CollectionPage/ItemList/BreadcrumbList结构化数据。清单首次页面可索引，筛选和后续分页noindex,follow。只有非空已发布清单进入首页入口和XML站点地图，发布/更新/撤下会进入原IndexNow队列；不保证平台接受或收录。llms.txt提供已发布清单链接，但它不作为收录前提。
