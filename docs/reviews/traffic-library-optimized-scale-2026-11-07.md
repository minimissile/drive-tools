# 流量词库结构优化与50万规模复测

2026-11-07～11-08，v35开发源码。50万独立词条及150万条历史的隔离磁盘库测试均完成，已测读取全部低于5秒。实际工作空间尚未加载新后端，不将本结果解释为所有设备、磁盘冷启动或完整界面的5秒承诺。

## 完成的优化

- 保留词条、历史观察和查询归档三层。现有词条表按稳定来源键保存当前值，长尾分类和来源筛选直接用索引；无需增加另一份当前值表，也不再逐词扫描历史查来源。
- 使用整数最新观察指针和较窄排序索引，保留所有对外观察ID。常规列表不计算全库概要；概要单独读取，仅随流量数据修订号失效。
- 界面下一页使用游标，上一页恢复已访问位置；数字深页保留兼容。旧暂存按原观察ID修复词条身份、去重，并保留最先选取的指标快照。
- 应用快照只传词池摘要和最多5词预览。展开、复制、搜索选词及创作按ID读取完整冻结内容，手工和AI词不强制关联采集历史。既有池JSON保留；摘要仍由SQLite解析该JSON，尚未正规化池内存储。
- 数据库备份导出与恢复统一8GiB上限，校验改为流式读取，保留摘要、完整性、路径及凭据检查。

## 迁移与回归

v35在事务中迁移，升级前有一致性备份；保留单来源词条ID，混接口旧词条拆分，原观察ID、指标、查询报文及冻结词池JSON保留。悬空历史引用会拒绝升级并回滚，避免连接查询静默丢记录。恢复只在独立临时空间测试，未迁移业务库。

- 词库、历史、百度采集、长尾、游标、统计修订号和独立迁移审查共49项通过；包括10万观察的查询计划检查。
- 词池专项3项、ideas4项、大库备份3项通过。513MiB合法稀疏SQLite验证容量预检和恢复边界，不冒充大行数性能测试。
- 旧版迁移fixture已正确还原物理旧表，Studio v8、traffic v7及pipix v20定向迁移通过；类型检查与差异检查通过。
- 1440×900任务窗口连续21组交互通过，控制台与页面错误为0。覆盖游标前后页、排序/筛选重置、跨页选词、慢响应、旧选择修复去重、冻结快照、词池最多5词摘要和完整按需内容；已查看关键截图，窗口已关闭并切回main。
- 额外搜索、completion及channels旧回归仍有资源同名去重、模板文案或浏览器环境规则相关失败，未扩修并行模块。上述专项通过不表示全仓测试全部通过。

界面测试仅在任务页面替换业务传输，未修改共享网络、业务数据或系统剪贴板，也未付费查询。编译已暂存且无错误，须用户手动点击“应用更新并重启”；当前客户端读取不计作新后端实库验收。
