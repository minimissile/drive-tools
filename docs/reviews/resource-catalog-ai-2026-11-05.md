# 资源清单AI检索与条目维护 · 2026-11-05

## 本轮交付

- `shared/resource-catalog.ts`扩展固定集合、条目展示覆盖、资源查询与AI生成契约；既有分类清单保留兼容。
- `core/catalog-ai.ts`维护候选元数据快照、分批语义匹配、相关度选入、标题/介绍生成和显式付费重试。复用AiService，不新增账号、代理工具循环或另一套预算。
- `core/catalog-content.ts`抽取清单公开文本脱敏，供清单快照及AI候选投影共用；模型输入不使用含分享/提取码的CatalogSnapshot。
- `core/resource-catalog.ts`实现本地资源搜索和条目资料读取；手动集合按资源ID维护，展示覆盖不修改资源库，发布前继续本人分享核验。
- IPC新增独立saveManual入口，防止新前端在旧后端上被静默保存成整类清单；本地查询列入useIpcQuery白名单，AI命令保持显式调用。
- `CatalogAiDialog`与`CatalogItemsEditor`分开负责生成会话和条目维护；页面组合入口，CatalogEditor保存及暂存，Workspace开放直接删除入口并保留远端状态保护。

## 并行协作与边界

资源清单专线负责后端、条目UI、整合和人工查看；原SEO/GEO协作对话只读审阅AiService的模型/预算/脱敏边界，并单独实现CatalogAiDialog。没有另建子对话或子代理。协作提醒已整合：新调用名归入analysis、未知失败明确可能再次计费、进程中断inFlight保护、最终介绍输入有界，以及旧后端不得静默降级保存。

生成只依据保存时的元数据，不能证明文件正文、授权、下载成功或当前资源仍可公开；这些边界保留在各自流程。模型输出的ID逐批校验，保存/发布时重新读取本地资源与本人分享；资源删除、分享失效或多窗口修改不能被AI判断覆盖。真实模型效果及计费尚未实调，需用户应用后端更新后显式使用。
