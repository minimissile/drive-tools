# 资源清单紧凑布局 · 2026-11-08

保留现有双栏、白色工作台及全部业务操作。本轮仅改前端布局：通过公共workspace-frame与min-height:0约束剩余空间，移除左侧基于视口减固定高度的整面板滚动。左侧标题/搜索/筛选固定，长索引内部滚动；右侧标题/页签及搜索/分页固定，资源正文内部滚动，表头吸顶。发布页签在同一内容面板滚动。
