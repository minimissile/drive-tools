# 网盘文件布局验收 · 2026-11-24

用户优先级：首屏多展示文件，操作集中。使用 impeccable 的布局与完工检查流程，延续 DESIGN.md 的白色紧凑桌面风格。

## 改动

- 账号选择改为横向上下文栏，账号管理入口移至页头。
- 本地目录的同步状态、同步操作、搜索与批量录入合入一个工作区。目录树与文件表格各自滚动，表头和分页保持可达。
- 根目录省去重复路径栏，子目录与搜索保留单行可滚动路径。文件行取消重复路径及读取时间，搜索保留所在目录，完整位置和读取时间可悬停查看。
- 多个关联资源收进操作列的公共菜单，长资源标题可换行。录入预览展开时聚焦输入，收起后恢复触发按钮焦点。
- 实时网盘的目录导航与维护操作合为一行，保留新建、广告、重命名、删除和分享的原有显式操作。
- 首次读取和读取错误分别显示相应状态；未读到本地目录前禁用同步提交，避免把未知状态误显示为尚未同步。
