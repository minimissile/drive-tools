# 内容分发渠道扩展开发计划

制定日期：2026-10-17。当前在源码开发与实时调试阶段，本计划不提升应用版本、不制作安装包。

## 目标和范围

将盘序从10个平台扩展到21个平台，并把平台、内容形式、发布账号、网盘链接位置分开管理。资源事实、流量词池、搜索选题、内容草稿、本人网盘分享、发布记录和效果数据继续关联到本地SQLite知识库。

本轮交付使用现有比特浏览器流程：生成或手写内容、人工审阅、导出物料、打开对应账号的官方创作入口、人工发布、回填内容地址与审核状态。打开编辑器不代表已发布。

所有测试使用临时工作空间和模拟服务。真实API查询、网盘转存、创建分享、内容发布不在自动验收范围内。最终账号能力由实际后台和平台规则共同决定。

## 一 渠道目录与内容形式

- 平台ID集中维护，前后端校验共用，补齐11个平台的名称、官方入口、编辑器域名白名单、发布内容域名白名单、规则来源。
- 只使用已知官方站点作为默认入口，不猜测登录态深层编辑器URL。账号可保存经过白名单校验的编辑器地址，未进入编辑器时用户可在官方站点继续导航。
- 内容形式与媒体形式独立：文章／回答／图文／长文／短文／视频脚本是平台交付形式；文字／单图／组图／动态视频是现有创作物料形式。
- 新草稿保存平台内容形式；旧草稿按原平台的默认形式兼容读取。形式变化生成独立草稿，不修改历史已审阅版本。
- 创作页增加渠道分类和搜索，21个平台不无限拉长导航；稿件列表和交付页显示具体内容形式。
- 抖音、小红书长文入口标记为待核验；能写稿不等于已确认账号能发布。

验收：21个平台均可选择、创建本地草稿和恢复；不支持的平台与内容形式组合由后端拒绝；旧草稿和资源关联保留。

## 二 账号能力与链接位置

- 每个发布账号独立保存已核实的内容形式、网盘链接位置、规则依据及核实时间。
- 区分正文、简介／说明、阅读原文和官方组件；只有该平台适用的位置才能选择。
- 链接授权仅对选定账号、内容形式及位置生效，继续使用30天复核周期；修改窗口或编辑器后需要重新确认依据。
- 正文中手写的网盘链接同样受正文权限约束，不能借简介或组件权限绕过。
- 正文位置才附加到正文；简介、阅读原文和组件信息单独作为交付字段，不自动注入文章，也不表示已经实际挂载。
- 新平台与未核实账号默认无网盘链接权限。老账号原有权限仅兼容原默认形式的正文，不自动授权新增形式。
- 转存与分享仍须属于当前副本的本人账号，来源链接、其他副本链接、过期分享、拆分失效、未保存编辑、未审阅版本继续阻止交付。

验收：跨平台、跨形式、跨位置、过期权限均不能附链；非正文资料入口在导出中独立且不误记为正文已有链接；原有本人分享核验继续生效。

## 三 提示词和发布物料

- 平台及形式指令共用一份定义，AI创作和本地模板使用相同的结构要求。
- 通用SEO／GEO要求：围绕真实问题完整作答；自然使用主词和长尾词；提供适用对象、前提、步骤、限制和资料版本；区分事实、示例及待验证内容；不编造搜索量、实测结果、用户评价、搜索排名或AI引用。
- 技术社区稿件要求环境、可复现步骤、代码／截图证据、结果与限制；不足时保留待补充项，不伪装实测。提示用户按平台要求审阅与填写AI标识。
- 普通笔记、短文和视频脚本使用相应结构，不能将同一份营销文案机械复制到所有渠道。不生成网盘口令、谐音、私信领取等绕行话术。
- 导出统一提供文案、文章Markdown、摘要和标签、平台及内容形式、交付字段、规则提示、本人链接所在位置、素材文件清单、草稿版本及资源关联。
- 保留CSDN专用交付字段，新增渠道不破坏既有流程。导出与复制均调用同一后端校验。

验收：用模拟AI核对提交的渠道指令；本地模板可离线运行；新渠道导出字段完整；未经核验的原始分享不进入可发布内容。

## 四 发布记录与效果回流

- 21个平台均支持绑定比特窗口、校验官方入口及回填内容地址；错误平台域名、伪装子域、HTTP、带凭据URL拒绝。
- 保留打开编辑器、已提交待审核、确认发布三个状态；未点击真实发布前不生成“已发布”。
- 发布记录继续关联具体草稿和版本，通过草稿恢复内容形式、流量词池、搜索选题、资源及本人副本。
- 复用现有搜索效果与网盘统计，不推算不存在的跨平台用户归因。人工录入与服务商统计保留来源，无法取得的数据保持未知。

验收：模拟比特接口打开新渠道；回填内容地址按平台校验；打开页面不增加已发布数；现有统计和搜索选题回归通过。

- 使用临时SQLite验证旧数据升级、所有渠道的创建／导出、链接权限和本人分享保护。
- 运行TypeScript检查、相关单测与完整回归；使用npm run dev提供Vite源码页面，Electron后端输出dist-dev。
- 用隔离Electron工作空间验证渠道搜索、选择内容形式、新建稿件、设置账号、交付页面及错误提示，保存截图到临时目录。
