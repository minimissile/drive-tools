# AI 资源导出

入口为侧边栏“AI 资源导出”，或资源库右上角“AI 筛选导出”。用于把已经积累的网盘资源按实际交付需求重新整理：按主题或资料类型筛选、参考截图组织表格、导出资源清单，以及结合已选资源生成一篇可编辑的主题短文。

## 使用流程

1. 在“连接与设置”保存 OpenRouter Key，分别配置资源分析与截图理解模型并设置美元预算。文字需求使用资源分析模型，带参考图片时自动使用支持图片和结构化输出的截图理解模型。图片输入能力依据 [OpenRouter 模型目录](https://openrouter.ai/docs/api/api-reference/models/list-all-models-and-their-properties)，请求格式依据[图片输入文档](https://openrouter.ai/docs/guides/overview/multimodal/image-understanding)。
2. 输入需求，或上传、拖入、粘贴参考截图。文字和图片可以组合使用，也可以单独提交图片。每次最多三张PNG、JPEG或WebP，界面接受每张8MB以内的原图，转为最长边2000像素的图片；服务接收每张4MB、合计8MB以内的图片。
3. 选择资源数据库、资源数据库与知识笔记、仅有可读知识笔记的资源。可进一步限定分类、网盘、保存账号、是否仅已归档。
4. 点击“解析需求与表头”，核对筛选条件、短文要求、表头和数据映射。纯文字需求保留原文作为筛选条件，避免模型擅自添加文件扩展名、授权或质量门槛；按字体主题筛选时，已有说明的ZIP压缩资料也可以命中。短文要求只保存写作指令，不在解析阶段生成资源事实。开始前可以修改筛选条件与短文要求；表头可以改名、调整顺序、添加、删除及修改字段映射。价格等没有真实对应数据的字段留空。
5. 确认后开始筛选。使用提交时的全量资源快照，逐批判断，每批最多30份，资料文字较多时自动缩小批次。可以在当前批次结束后暂停；重启或切换页面后手动继续。失败批次保留已完成进度，不自动重试或重复收费；人工重试失败批次仍可能产生新的模型费用。
6. 查看匹配依据，勾选需要的资源。可以查看未匹配资源并手动补选。完成全量筛选后，可导出Excel工作簿、CSV、Markdown表格、JSON或文本清单。表格导出不再调用AI；包含本人分享链接或提取码列时，保存前会调用原有网盘核验流程，只输出通过核验的本人分享。提取码仅在明确选入该列时导出，不发送给AI；多账号的链接和提取码按相同顺序换行对应。
7. 需要介绍文案时，点击“生成主题短文”。使用已选资源的全量分类统计和最多40份详细样本，避免把大量资料挤进一次模型请求；具体资源引用只能来自样本。生成后可以修改、点击“保存短文修改”，或导出Markdown/TXT。保存修改及导出不调用AI。更改资源选择后，需要重新生成短文以保持依据一致；打开历史时恢复该短文原来的资源选择。

示例需求：

> 导出数据库和知识笔记中全部英语教学资料，包含少儿英语、口语、语法和考试备考。按截图中的“资源名称、资料类型、文件格式、资源说明”列顺序整理，没有信息的字段留空。再写一篇面向英语教师的300字资料介绍。

## 数据覆盖范围

- 遍历整个资源库，不受资源列表25份一页、最近500份或前端当前资源的限制。每份资源一行，同一资源的多个账号副本合并；设置账号范围时只使用该账号的副本及笔记。
- 依据标题、分类、标签、摘要、已记录文件名、已读取的拆分路径及个人知识笔记判断。文件格式来自已记录文件名，不自动递归读取远端目录；文件数是已记录的名称/路径数，包含目录，不能等同于网盘总文件数。
- 知识笔记限当前Vault的`盘序/Resources`中、已被盘序关联的资源笔记，读取“我的笔记”部分，元数据与文件清单来自数据库；不遍历任意Vault笔记，也不把5118流量词库当作网盘资料。不能读取的笔记、超过256KB的文件或指向目录外的符号链接会跳过并提示。
- AI每份资源最多使用3000字符摘要、5000字符个人笔记及100条文件名/路径，每条文件名最多200字符。短文每个样本最多使用400字符摘要、400字符个人笔记，分类统计最多提供100个分类，并提供实际分类总数。长资料可能遗漏相关信息，应核对未匹配项，必要时补充摘要后新建导出。
- 截图用于识别表头、字段含义和列顺序，导出为标准数据表；不复刻合并单元格、复杂装饰或像素级排版。Excel单元格超过32767字符时会提示改选CSV/JSON/TXT，避免静默截断。
- 每次导出是提交时的资料快照；随后新录入或修改的资源，需要重新提交需求。导出本人链接时使用当前账号归属及有效性核验，任一待输出链接核验失败会阻止本次文件保存。

## 历史与费用

最近20次方案、逐项筛选结果、匹配依据、进度及已保存短文保存在本地SQLite中，无新增数据库迁移。打开历史或重启后恢复原始文字需求和检索范围；参考图片不保留，需要重新添加，不混用其他历史的截图。历史查看、表头调整、结果勾选、手工保存短文和文件导出不产生AI费用。需求解析、分批判断与短文生成使用现有OpenRouter美元预算及调用台账；进行中的相同请求合并，费用未知时保留待核记录。格式错误、不完整判断或虚构资源引用不会落入成功结果，但已经发生的模型费用仍如实记录。短文失败原因保存在本地并在短文区持续显示，筛选结果和原有短文保留，不自动重试；手动重试可能产生新的模型费用。

图片会提交给模型，不保存在导出历史中。范围内的资源文字和个人笔记片段会发送给模型；文字中的链接及常见凭据字段会剔除，图片中的敏感内容需要本人提前遮盖。导出不读取网盘文件正文，不自动发布短文，也不改变网盘文件或分享。

尚未提交或解析失败的输入也会保留。切换页面调整模型后返回，文字、检索范围和截图仍在；重启后恢复文字、范围及失败原因，截图字节不写入本地存储，界面会提示重新添加。打开历史方案时清空其他请求的截图，避免混用。

## 验证

- `npm test`：包含全库523份资源覆盖、并发去重、检查点恢复、无效AI结果、预算、图片输入、知识笔记范围、五种格式、本人链接核验及短文引用/保存测试。
- `npm run build`：类型检查、前端和桌面主进程构建。
- `npm run test:e2e:resource-export`：使用临时工作空间和模拟模型，验证文字+截图、表头编辑、分批暂停与重载继续、真实文件保存端口、人工补选、短文编辑保存导出、历史复用以及1320px/840px布局。禁止真实账号和外部AI/5118调用。

自动化验证覆盖程序行为，真实模型对自然语言需求、截图表头和主题相关性的识别质量仍需结合本人资料验收。

本轮验证：141项核心测试、5组AI资源导出专项桌面交互和24组原有桌面回归通过，前端异常0条；独立使用openpyxl读取实际导出的Excel，中文列序、空单元格与冻结首行符合预期。桌面测试使用临时数据和模拟外部服务，不代表真实模型的主题召回率或截图识别质量验收。

后续真实体验（2026-10-16，源码开发窗口）：从公开网盘分享整理[霞鹜文楷轻便版](https://www.100font.com/thread-1481.htm)和[得意黑](https://www.zishuai.com/freefonts/19848.html)，作者项目分别为[LxgwWenKai-Lite](https://github.com/lxgw/LxgwWenKai-Lite)和[Smiley Sans](https://github.com/atelier-anchor/smiley-sans)。实际读取并转存的ZIP分别为50,644,131字节和5,712,924字节，完成本人分享归属核验及真实Vault归档。Qwen在6份实际资源中选中这2份字体、排除4份其他资料；导出七列Excel，独立读取OOXML核对列序、ZIP格式、本人链接与提取码排除。主题短文生成后经人工核对和精简、保存并导出，保留两份资源依据。此次小样本不代表全库召回率，也未读取ZIP内容或使用真实视觉模型。

真实体验同时覆盖内容工作室文字模板、AI营销稿、跨页编辑恢复、未保存稿的交付拦截、保存与重新审阅、核验复制和实际内容包导出。8次文本模型请求（含未采纳方案和失败尝试）合计$0.001624，均有实际费用返回，低于本人授权的$0.05；没有付费图片/视频生成或对外发布。后续完整161项核心测试和类型检查通过，涉及外部异常的回归仍使用模拟服务。

后续截图实测（2026-10-16，按用途模型配置后）：本人扩大OpenRouter模型测试授权后，以仅含表头及空白行的PNG作为参考，没有在文字需求中逐项列出表头。Qwen3.8 Max视觉输入正确识别“资源名称、资料分类、已知文件格式、资源说明、本人分享链接”五列及顺序，短文要求保持为空。随后分析模型在6份真实资源中选中得意黑与霞鹜文楷，排除4份其他资料。人工确认后核验本人链接，实际保存XLSX，独立读取OOXML确认五列、两条数据、ZIP格式、本人链接和无提取码；未推断压缩包内容，也未额外生成短文。识图解析与分批筛选分别返回实费$0.008718和$0.016932。

同轮在源码页面实测先填写需求并附图，切换设置再返回，文字与参考截图保持。当前连接的Gemini视觉模型曾返回地区限制403，已保存失败原因并调整为可用的Qwen；既有筛选成果保留。上述验证仅是两份字体的小样本与清晰表头，不代表低清截图、复杂合并单元格或全库召回率已经验收。
