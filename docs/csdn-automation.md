# CSDN 单篇自动创作与发布

开发版入口：**工作台 → CSDN 内容操作 → CSDN 自动创作与发布**。原有“教程创作”和“发布准备”仍可使用。

## 操作流程

1. 输入具体搜索问题，或从本地词库与词池选择关键词。保留原始来源、采集时间和已知指标；手工选题标记搜索量待核实。新增付费找词仍在“流量发现”显式执行，本页面不自动请求 5118。
2. 自动按资源标题、摘要、标签和文件名查找相关的已核验本人资料，选择实际配套副本。匹配不代表已经阅读网盘文件正文，也不自动转存或建链。
3. 填写软件版本、适用系统和实际操作依据，创建本地单篇任务。重复创建同一关键词与资料的任务会返回原任务。
4. 点击“使用 AI 生成教程”。生成前实时核验配套分享；复用已有 OpenRouter 文案模型、预算和费用台账，稿件同时关联搜索选题与本人资料。
5. 核对标题、Markdown、代码、图片与 1–5 个站内已有标签；修改后保存为新版本并重新人工审阅。编辑器复用内容工作室的暂存、恢复及版本逻辑，任务也可选择同一选题的历史稿件版本。
6. 选择已核实文章发布能力的 CSDN 比特窗口，填写个人主页中的用户名及摘要。正文须已有当前本人分享，或勾选在获准正文位置附加本人分享与提取码。窗口链接权限仍按原有30天核实有效期检查。
7. 点击“核验并自动填写”。在指定比特窗口中新建本任务的编辑页；核对登录用户名，填写标题、正文、标签、摘要，设置原创、全部可见及相应 AI 辅助声明，取消额外 GitCode 备份。已有的其他用户编辑页不被覆盖。
8. 核对窗口后，勾选本次提交授权并点击“提交当前文章到 CSDN”。授权不随切页、刷新或重启恢复；更改稿件或发布配置后必须重新填写。填写凭据有效期15分钟，提交前再次核验本地稿件、分享、账号、平台正文及字段。
9. 仅在实际发布请求返回成功且有文章 ID 时自动保存地址并同步“已提交 · 待审核”。在 CSDN 后台核对正常公开后，人工确认已公开；继续使用原发布准备页记录资源入口验收，搜索运营记录实际效果。

## 中断与恢复

- 登录、账号不一致、找不到站内标签、正文被改动或界面结构变化时停止，保留任务与编辑现场。使用“打开任务窗口”继续处理。
- 最终点击前保存提交意图。超时、进程中断、成功响应缺少 ID 或无法识别回执均进入“提交结果待核对”，不自动重发。
- 先在 CSDN 核对，取得实际地址后登记已提交；只有明确确认未提交，才能重新准备。已取得回执的任务不能清空状态后重发。
- 提交回执先单独保存，再同步原发布记录。若本地同步失败，可同步待审核回执，无需重新发布。
- 同一比特窗口的任务串行执行。重启后进行中的生成与填写暂停，已填写状态失效；进行中的提交转为结果待核对。不会在启动或本地自动读取时恢复付费生成、建链或发布。
- 任务、断点、来源及执行记录保存在当前工作空间 SQLite 的独立设置记录中，随现有备份保存；不保存本次授权或登录 Cookie。

## 当前范围

首版提供单篇教程流程，使用现有比特浏览器映射和官方 Markdown 编辑器。未实现批量排期、无人值守扫码、自动读取平台审核结论、CSDN 站内精确搜索量或收益自动归因。图片须先取得可用的 HTTPS 地址，本版不自动上传本地实测附件，也不会代做实测。

平台适配依据2026-10-21读取的 CSDN [Markdown 编辑器](https://editor.csdn.net/md/)及其公开脚本 `app.chunk.e9fc4e37.js`：使用页面控件操作，不直接构造、签名或重放发布接口。监听官方页面自身发出的 `https://bizapi.csdn.net/blog-console-api/v3/mdeditor/saveArticle` 且 `pubStatus=publish` 的请求回执，排除自动保存的草稿。页面选择器改变时需要重新核验适配。

## 代码与验证

- `shared/csdn-workflow.ts`：任务、字段校验与 IPC 契约。
- `core/csdn/workflow.ts`：本地词源、资源匹配、单篇任务、分享与版本校验、提交意图及恢复。
- `core/csdn/editor.ts`：指定比特窗口内的官方页面适配、账号与字段检查、发布回执。
- `core/ipc/csdn.ts`：领域入口校验；`core/service.ts` 组装现有 AI、分享、草稿与发布记录服务。
- `src/csdn/`：工作流与恢复界面；`src/studio/DraftEditor.tsx`：两处共用的草稿编辑器。
