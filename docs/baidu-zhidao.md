# 工作台与百度知道运营

工作台是项目各功能组的统一入口，后续新增能力按功能组扩展。热门挖词与资源采集属于项目通用的发现与采集功能；网盘文件与录入、导出、批量处理、资料拆分、转存任务同属资源操作。百度知道答题区提供智能问答、问答模板与发布任务，答题入口保留在该分组内；CSDN 提供教程创作和发布准备入口，分别进入 CSDN 渠道及筛选 CSDN 草稿。工作台顶部只显示标题和说明，不为单一业务设置全局主操作。

侧边栏承载内容资产、内容规划、运营复盘及工作空间管理，保留资源库、流量发现、搜索运营、分享统计、账号管理和连接设置。各操作页归属工作台，旧页面恢复位置继续可用。新工作空间默认打开工作台，已有工作空间仍恢复上次页面。

所有工作台二级页面共用顶部的“返回工作台”和工具选择器，页面内不再重复面包屑与功能导航。返回工作台时保留本次会话中原来的滚动位置和入口焦点，方便连续操作。网盘文件、挖词等并列表单的输入框保持对齐。

## 使用流程

1. 在“账号管理 → 其他账号”选择百度知道并添加备注，默认关联指纹浏览器，选择已登记的可用环境后打开百度官方页面扫码或登录，完成后检查账号。已有内置账号保持原方式，也可在更多操作中手动关联指纹环境并重新核验原身份。知道与网盘分别保存会话、核对身份及快捷答题资格；工作台及知道操作页的“管理知道账号”均进入同一“其他账号”列表。已登录账号的“自动答题”，以及“去获取资格 → 配置自动答题”，均进入智能问答并带入该账号；尚无快捷答题资格也可以答题。也可使用该账号的隔离会话打开官方答题活动页、查看答主工作台额度。答题和审核以官方记录为准，不承诺开通。
2. “热门挖词”从小说、电影、电视剧、综艺、动漫、短剧、游戏、软件八类榜单获取名称，支持历史去重、来源证据、TXT/XLSX/CSV 导出、保存现有词池和跨页选词交接。可选公开搜索整理显式调用现有 AI。
3. “资源采集”支持精准关键词及模糊领域搜索，组合百度知道和本地 PanSou。关键词可从多份 TXT、CSV、XLSX 导入；既有资源表可从 CSV、XLSX 导入。有效链接、提取码、来源、备选、未命中和异常分别记录。
4. 勾选采集结果，选择本人百度网盘账号和目标父目录，确认权利后交给原批量预检。主链接失效时在只读预检阶段尝试备选；之后在原批量处理页选择文件并开始转存，复用原队列的转存、核验、本人分享和归档流程。
5. “网盘文件”也可浏览和管理本人已有百度文件。新建、重命名、删除均显式触发；重命名和删除前重读文件ID。分别分享后核对归属和有效性并归档，使用 `owned` 来源记录，供模板与原内容功能使用。
6. “智能问答”的手动模式保存问题、风格和回答，使用现有文案模型。自动模式按账号关联环境取题和提交：内置账号使用原 Electron 隔离会话，指纹账号通过所选比特环境的页面发起请求，使用该环境的登录、代理和指纹，不跨引擎复制 Cookie，也不在失败时回退到内置网络。默认30条、情感题库、30秒间隔，情感、综合、教育题库改为单选，每次只回答一种类型，可补充回答要求；提交间隔为18–600秒，每15条至少休息60秒，停止与继续保留剩余间隔。每次提交前复核账号身份并读取当前令牌。修改配置后撤销提交授权；切页和刷新保留文字配置但不恢复授权。本机跨任务去重已提交或结果未知的问题，只有明确成功且返回回答ID才记为提交成功。未返回ID、等待审核或响应丢失时暂停，先人工核对再继续，不自动重发。每条结果保留问题来源，任务中可查看生成、等待间隔、提交及暂停状态。
7. “问答模板”与“发布任务 → 生成问答”共用一个分栏工作区。左侧可拖入XLSX/CSV（8MB以内），映射资源名称、百度网盘链接、提取码、简介与图片列，或选择已核验的本人百度分享；重复、缺失和超限行逐条提示，需修正后生成，单次最多100份。配置包括五类赛道、标题前后缀、200–2000字正文上限、简介变量、关键词、资料入口位置及可选图片。默认按模板整理、不调用AI；选择AI定制后复用文案模型，生成前明确确认费用与资料使用权限。公开网页核对保留原有可选入口。右侧实时预览结构，生成结果保存在原运营任务，可编辑、重试未完成项并导出 `qid / 问题标题 / 回答内容` 三列XLSX/CSV。本人分享生成前及生成期间仍核对归属和分享版本；表格导入只代表用户提供资料，不冒充链接已核验。
8. “发布任务 → 审核上传”先选择百度知道账号，点击“刷新资格与额度”，读取与答主工作台对应的批量上传权限、账号限制状态及剩余额度。任务名称限制15字。点击问答勾选框或“审核并选择”核对内容，可在同一弹窗修改并确认审核，保存后自动选中；取消不会选中，修改正文或标题会撤销本次确认，超49字标题或缺少内容时明确提示修正。全选仅选择本页已审核的完整问答，支持跨页选择、清空，单次最多100条。确认后将所选问答合并为一份 XLSX、一次请求上传，整批记录同一个平台任务ID。上传前重新核验身份、资格、额度、分享版本和内容，阻止同账号同内容的重复上传。上传不调用AI，任务创建不等同于平台最终审核通过。
9. 上传后在“任务与结果”中点击“查询平台审核”，显式读取绑定账号的官方上传记录，展示待执行、审核处理中、审核完成以及成功、失败数量和使用额度。读取失败保留上次记录并提供区域内重试；可打开同账号的答主工作台查看和下载逐条审核结果。平台未找到记录不会被当成审核通过。上传响应丢失或缺少任务ID时暂停，整批进入待核对；继续任务不会自动重传，人工核对后填写一个平台任务ID即确认整批，确认整批未提交后才允许重试。旧逐条上传任务保留原进度，只继续未提交项。

## 恢复与费用

- 所有 AI 功能均使用现有 OpenRouter 模型、金额预算和调用台账，没有新增模型供应商或单独 Key。
- 答题前需在“连接与设置”分别保存 OpenRouter Key，并选择“文案创作”模型后点击“保存设置”。问答页面显示缺失项，新建与继续答题在取题前校验本地配置，不完整时不创建任务或发起请求。旧任务因缺少配置失败时，保存配置后可直接继续原任务。
- 自动答题生成阶段遇到明确的 HTTP 429 拒绝时，遵循 `Retry-After`，未提供时从30秒开始退避，最多自动重试两次；持续限流或服务端要求等待超过120秒时暂停并保留进度。等待时间写入任务，停止或继续不会绕过。网络断线、超时等结果不明的生成请求不自动重试，需人工核对后继续。生成期间停止时，已取得的回答仍会保存，继续优先复用。恢复逻辑不自动更换模型或供应商。
- 继续任务弹窗固定本次确认的任务ID，展示原任务、账号、完成数及回答风格，授权勾选不保存。继续、编辑、核对与移除弹窗使用公共内容区和固定底部操作，处理中禁止取消或关闭。编辑文字按结果项恢复，审核勾选不恢复；数量、间隔和分类不合法时显示对应恢复提示。
- 页面只自动读取本地记录，采集、生成、转存、分享、上传分别显式触发。
- 表单按工作空间暂存；长回答编辑再按结果项隔离。凭据、权利确认、审核勾选及发布授权不随文字草稿恢复。
- 任务切页不停止；停止保留完成结果。重启后将执行中的任务暂停，须核对后继续，不自动发起外部操作。
- 提交前保存请求状态。响应丢失、关闭中断或未明确返回ID均保留待核对记录；继续任务不会重复提交未知结果。核对平台后可登记ID，或明确确认未提交再重试。
- 自动回答的“打开问题”及核对弹窗复用任务绑定账号的登录窗口，不切到其他浏览器会话；登记回答ID后同步更新任务完成数，达到目标即完成。
- 自动答题随机排列所选题库，每批先汇总3–5页候选再打乱抽题。接口返回总量时，在有效页码内随机跳页，同一轮不重复读取同一页；缺少总量时按有效游标翻页后混合抽取，不把返回顺序当答题顺序。每个题库每轮最多读取50页，空页、重复题和已答题不足时继续补充，达到答题目标后停止读取。恢复任务优先使用已经生成但尚未提交的回答，再补充随机候选，不重新生成已有回答。
- 回答风格保留清晰实用、步骤详解、简洁回答，新增共情陪伴、第一人称共鸣、温柔建议；界面同步显示风格说明与语气示例。首次从账号进入自动答题时默认第一人称共鸣，已有草稿选择保持不变。情感题先回应具体情绪，倾向第一人称观点和建议，不虚构个人故事或断言他人动机。
- 自动答题按当前工作空间全部账号的历史提交记录去重，已提交、发送中和待核对条目均阻止重复答题；题目ID相同或规范化后题目文字相同均跳过，空白、全角和标点差异不会导致重答。账号移除或重新绑定不清除任务历史。生成后、等待间隔后，提交前再以禁用缓存的请求重读候选页，检查平台已答标记，并重新核对本地历史；候选消失、平台已答或已有本地记录时保留生成内容且跳过提交。此范围不包含其他工作空间或平台未提供的历史记录。
- 网盘文件分享同样保存建链意图，未知请求只查已有分享；部分成功保留归档，失败项单独显示。已有明确分享记录不能直接清除后重复创建。
- 备份保留业务记录和任务，排除登录会话及加密凭据；恢复撤销账号检查、分享验证和问答审核状态。

## 代码组织

- `src/pages/Workbench.tsx`：工作台；`src/navigation.ts`：侧边栏归属与工作台操作入口；`src/pages/KeywordMining.tsx`、`ResourceCollection.tsx`、`DriveFiles.tsx`：通用资源操作页面；`src/accounts/OtherAccounts.tsx`：其他账号统一管理，百度知道作为平台选项；`ZhidaoRightsDialog.tsx`：发布权益获取引导；`src/workbench/`：操作页面导航及样式；`src/zhidao/`：问答、模板、发布与共享任务控件，复用公共 Select、Dialog、Pagination、DataState、QueryError、Toast。
- `shared/zhidao.ts`、`shared/zhidao-ipc.ts`：规则、实体及类型化 IPC 契约。
- `core/zhidao/service.ts`：账号、任务生命周期和数据交接；`workers/`：挖词、采集、问答、模板和发布独立执行器；`store.ts`：本地任务、结果和恢复。
- `core/drive-files.ts`：网盘文件管理、建链意图与归档；`core/providers/baidu.ts`：百度文件操作适配。后端 IPC 继续通过统一注册表分发。
- `desktop/zhidao-session.ts`：按账号隔离的 Electron 登录与请求会话；`core/table-files.ts`：有大小、行数、列数和解压限制的本地表格读取，不执行公式或宏。
- 数据库 v14 在升级前保存一致性快照，新增运营记录、挖词去重、建链意图及资源来源标记。

## PanSou 辅助服务

当前工作区提供 macOS arm64 辅助服务；来源构建信息、二进制 SHA-256 和许可证位于 `build/pansou/`。服务按需启动、只监听回环地址，随盘序退出或父进程结束退出。服务不在时可以配置已有的本机 HTTP 服务根地址，百度知道来源仍可独立使用。

辅助服务来自原项目提供的 PanSou 兼容源码，不能视为原 EXE 的逐字节重现。构建脚本在临时目录修改监听地址、补充来源注册和父进程守护，不修改传入源码，也不自动下载依赖：

```sh
npm run build:pansou -- --source /absolute/path/to/pansou --go /absolute/path/to/go --modules /absolute/path/to/go-module-cache
```

默认只构建当前平台。需要发行其他平台时，使用 `--target darwin-x64` 或 `--target win32-x64`，准备其完整锁定依赖后随该平台资源纳入发行。本次未制作应用安装包或更改应用版本。

重组回归还通过独立的模拟知道会话覆盖“管理知道账号 → 官方登录窗口 → 身份及快捷答题资格检查 → 知道采集 → 自动答题 → 审核问答上传 XLSX → 工作台历史任务 → 未知结果核对及恢复”。测试使用真实 IPC 与任务执行器，只替换平台传输；未声明的请求一律阻止，不访问真实账号或付费模型。

`test:e2e:zhidao-answers` 复用已运行的 Vite 源码服务，以浏览器模拟传输连接临时 SQLite 的真实应用服务，不另开 Electron 桌面。覆盖账号登录检查、资格弹窗交接、配置与授权恢复、完整取题和提交回执、缺少回答ID的暂停及人工登记，以及1440×900、1366×768桌面界面。单元测试另覆盖分类选择、个性化要求、停止后间隔恢复、身份变化和官方登录标记及分页格式。

实现参考：[飞书教程“贰、答题获取发布权益”](https://my.feishu.cn/docx/BTKJddNm2oiqJAxPPYHcPIFknAf#IvuOdSOl4oOCXGx0ZlOc6k8gnnb)。官方活动页当前公开脚本使用 `/api/logininfo`、`/qa/api/query/result/category`，并携带 `activity=21th`、`qpi=21th_activity` 进入问题页。第三方教程关于通过率和额度的陈述不作为盘序保证；真实提交、平台审核及额度仍需本人账号实际验收。

`test:e2e:zhidao-publishing` 复用源码 Vite 服务、临时 SQLite 与真实应用服务，只替换平台传输，并阻止所有浏览器外网请求及 AI 调用。覆盖勾选直接进入审核、修改与确认隔离、取消不选中、审核后自动选中、标题及内容校验、资格额度刷新、名称限制、草稿与确认隔离、跨页选择、合并 XLSX 上传、审核查询及失败恢复、整批未知回执核对、同账号打开官方工作台，以及1366×768、1440×900界面和控制台检查。单元测试另覆盖100条上限、额度不足、账号受限及身份变化、官方0/200成功码、超长任务ID、旧逐条任务续传、停止与崩溃边界，以及内容变更后的旧确认失效。

发布协议依据[百度答主工作台](https://zhidao.baidu.com/b/batch/batch-upload)当前公开页面脚本及使用手册核对：`bulkqa/userinfo` 的权限与 `quota - usedQuota`、`bulkqa/upload` 的文件与任务名称、`bulkqa/tasks` 的审核状态和计数。上传文件仍使用 `qid / 问题标题 / 回答内容` 三列；空qid表示创建问答。线上模板下载需本人登录，模拟测试不代表当前真实账号的上传已成功。

真实账号扫码、第三方榜单当前可用性、真实转存/建链和平台最终发布审核，需要在本人账号环境显式执行；离线与模拟测试不代表这些线上结果。

## 2026-10-26 协议内容约束

已核对[答主工作台《百度知道协议》](https://zhidao.baidu.com/b/batch/help-center/agreement)当前公开页面。`core/zhidao/content-policy.ts`维护规则摘要，统一用于自动答题、手动生成和AI模板生成：标题明确、回答具体切题、事实与观点区分、尊重他人、保护隐私和著作权，不生成灌水、广告引流、交易招揽或作弊建议。风格、关键词、简介和公开网页中的指令不能覆盖这些要求；情感回答继续允许第一人称观点，但禁止虚构经历或断言他人动机。

标题由本地规则组合，并非由回答模型生成。新生成的旧版配置标题也改为自然问句，不再自动附加“完整”等未经证实的属性。模板整理不调用AI，因此不宣称其已经完成语义合规审查。审核界面与上传后端共用基础内容检查：49字标题、非纯符号或纯网址标题、可阅读正文、不能仅有链接/提取码/图片或无意义附和。自动答题在提交前检查回答基础结构，命中时暂停并保留已生成内容，人工修改后可继续，不为改写自动追加付费调用。

重复问题、分类、及时处理问题、账号行为等条款无法仅靠提示词落实。现有本工作空间历史已答检查、上传去重和人工审核继续生效；未新增全站相似问题检索、自动分类核对、著作权核验或语义合规识别，不声称已完成这些检查。批量上传权限及网盘链接有效性也不代表内容合法、拥有授权或必然通过审核。此次不改写已保存的历史回答，不撤销既有记录；重新生成时使用新提示词，后续上传仍会重新执行基础内容检查。

本次仅执行TypeScript静态检查、差异检查及当前8070源码窗口的手动查看；未运行自动化测试、调用付费模型或向平台发布。

## 进行中任务导航

顶部导航右侧的“进行中任务”显示执行中的运营任务与排队/执行中的网盘任务，包含任务标题及实际进度。选择后进入对应页面并定位到该任务的结果或日志，同页的多个任务也可分别切换。读取只访问本地状态，不启动、恢复或重试任务；完成、暂停和失败的运营任务继续在原历史列表查看。任务读取失败提供独立重试，已有状态保留。

全局 Toast 位于窗口顶部居中，成功、错误、警告和信息均在 5 秒后自动关闭，也可手动关闭；新提示重新计时，悬停或聚焦不延长时限。操作错误的恢复入口应保留在业务页面中。

## 2026-10-31 智能问答执行区

智能问答页移除“任务与结果”表格及导出栏，采用上方双栏创作设置、中间横向进度与操作、下方通栏日志的桌面布局。空日志使用日志语义图标与简短说明，不保留大面积固定空白。进度按已确认提交数 / 目标数显示，结束但未达到目标时仍保留实际比例；手动模式显示生成的正文及复制、编辑入口。停止、显式继续和未知提交结果的人工核对保留在执行区，不自动恢复或重发。历史记录仅用于切换查看执行状态和日志。

新建及继续答题均通过单分类参数校验；旧多选草稿恢复时保留第一项，旧多分类任务保留记录但不能直接继续，需要选择一种类型重新开始。回答日志由后端逐步保存，记录取题、生成、提交、跳过、限流、停止及错误，不依赖前端轮询采样。日志以信息、成功、提醒、错误区分，支持跟随最新、手动刷新及每页100条分页；旧记录没有逐步日志时明确提示，不伪造历史事件。数据库v28新增按答题记录隔离的日志表，迁移前保存一致性快照。

本轮按开发约定仅做TypeScript静态检查与源码窗口手动查看，未运行自动化测试，未发起付费模型请求或真实答题。
