# 内容工作室：模板与多媒体营销内容

内容工作室按“选择资源和平台 → 选择内容形式与模板 → 编辑创意方案 → 生成实际素材 → 人工审阅 → 导出内容包”组织工作。文案、方案与素材关联到具体版本，沿用资源归属、搜索选题、词池、渠道规则和发布准备流程。

## 按用途设置模型

在“连接与设置 → OpenRouter”分别选择文案创作、资源分析、截图理解、图片生成和动态视频默认模型。保持原有页面样式，每个原模型下拉框前部加入带“性价比优先、均衡推荐、效果优先”标记的候选及报价；同模型对应多档时合并标记。直接选择后保存AI配置，存储的仍是实际模型ID。原有其他模型搜索、刷新全部模型和效果优先推荐按钮继续保留。没有新增独立推荐区、统一预览栏或费用展开面板。更换某个用途不会改动已有稿件、素材和远端任务。

推荐按用途与当前官方目录能力筛选，结合本次报价整理候选，不是全站最低价、实测排名或延迟保证。性价比档和均衡档要求有可识别的当前生成报价，未知价和本次未刷新成功的旧图片报价不会当作低价推荐；无匹配时保留原模型。效果档可展示能力合适但报价尚未完整的候选，费用会明确标注。手动选择与已有设置保留。

2026年10月17日至18日核对的首选候选如下（以刷新后的目录、能力与地区可用性为准；候选失效时按各档备选顺序处理）：

点击“刷新能力与报价”只读取公共元数据，不生成内容。文字目录保存输入/输出费率、上下文、图片输入、文字输出与结构化能力；包含时段或长上下文阶梯价时明确提示基础费率。图片按[官方端点记录](https://openrouter.ai/docs/guides/overview/multimodal/image-generation)读取供应商、输入/输出、分辨率档及张/像素/令牌等计价单位，不能把输入图片费用当生成费用。图片端点采用最多4路并发，个别失败保留旧报价及原读取时间，完全无报价则标为未知。

视频按[官方目录](https://openrouter.ai/docs/guides/overview/multimodal/video-generation)区分美元与美分、按秒与视频令牌、音频、文生/图生及分辨率规格。下拉选项标明每秒或每百万令牌等实际计价单位，不强行换算为每秒或每张；供应商报价、规格与读取时间保存在目录元数据中，不在页面增加展开面板。最终以任务台账及服务商结算为准。

本轮公共目录元数据读取取得61个图片模型与30个视频模型，5个图片模型无可用生成报价；没有发起付费生成。示例基础报价：Qwen3.8 Flash 输入/输出为$0.15/$0.47每百万令牌，Qwen Image 2.1 Turbo 的1K/2K输出为$0.0184/张，Veo 3.1 Lite 的已报价档为$0.03–$0.08/秒。后续以刷新结果为准。此前推荐面板方案已按反馈撤回。恢复原布局后，在隔离模拟工作空间重新检查1320px与840px原下拉框的推荐选项、选择真实模型及搜索；原生桌面窗口操作连接超时，未将模拟保存等同于本人工作空间改配，也未对推荐模型做本轮付费质量或视频测试。

营销稿、主题短文、图文方案和视频分镜使用文案模型；关键词、选题和文字筛选使用分析模型；导出需求包含截图时自动改用识图模型。图片和视频在工作室带入对应默认模型，可为本次任务临时更换，刷新目录不重置选择。视频优先带入支持的1080p，时长、比例、音频与参考图仍受实际能力约束。图片模型支持质量参数时默认使用high。

保存时检查用途与模型能力，不能误把看图模型当作图片生成模型。推荐基于[官方文字模型目录](https://openrouter.ai/docs/api/api-reference/models/list-all-models-and-their-properties)、[图片目录](https://openrouter.ai/docs/api/api-reference/images/list-image-models)和[视频目录](https://openrouter.ai/docs/api/api-reference/video-generation/list-videos-models)，不根据名称猜测能力，也不默默改用目录第一项。已知失败的模型会从推荐中跳过；上次出现地区限制时，推荐暂时避开同一接口类型下的同一服务商，但仍允许手动选择重试。文字模型的地区限制不推断为图片、视频接口也不可用。目录可见不等于当前连接必然能调用，实际拒绝原因会保留。

每日金额预算留空表示不设本地金额上限，服务商额度和限制仍以实际返回为准；费用台账不关闭。不设上限时素材费用预留收进可选项。创作失败保留输入、原稿和具体原因，并可直接前往调整模型；不会自动换模型重新计费。图片/图文的必需页数和画面要求也写入结构化输出约束。

旧工作空间沿用原文字模型作为文案与分析的兼容配置，无数据库迁移。新配置保存在本地，真实Key仍通过原加密存储管理。模型角色本身不调用生成接口。

## 内容形式与交付

| 形式 | 方案 | 实际交付 |
| --- | --- | --- |
| 文字 | 标题、正文、话题、封面文字 | 发布文案 |
| AI 图片 | 单张图片的标题、页面文字、画面要求 | PNG图片与配套文案 |
| 图文组图 | 1至8页，每页独立标题、文字和画面要求 | 逐页PNG、图文Markdown与配套文案 |
| AI动态视频 | 动态主体、动作、场景、镜头与转场要求、口播参考 | 服务商生成的MP4动态视频、配套文案和口播参考稿 |

图片与视频直接使用OpenRouter的生成接口。图片返回图像文件，视频使用异步任务生成动态画面；应用不会用轮播图代替AI动态视频，也不会将分镜文字当作完成的视频素材。视频时长、比例、清晰度、是否支持原生音频及参考首帧由所选模型决定。

规划采用统一创意方案、独立素材生成、持久化任务、版本绑定、发布交付五个部分；五部分均已接入首版工作流。后续可在现有任务模型上扩展更多服务商和素材编辑能力。

## 模板与创作

内置“资料推荐、步骤教学、清单合集、问题解答、场景故事、动态展示”六种创作模板。模板控制内容结构与视觉方向，各平台原有表达和渠道规则继续生效。界面的缩略图是风格示意，具体画面由模型生成。

可以基于当前模板填写名称、视觉风格与内容结构，另存自定义模板；自定义模板可以更新、删除。内置模板需要另存，不能直接覆盖。自定义模板保存在当前工作空间，跟随整库备份恢复。

“生成AI草稿”先生成可编辑的方案；“使用本地平台模板”和“新建手工草稿”可在未配置AI时创建内容。图片方案包含每页标题、文字和画面要求；视频方案包含动态画面要求与口播参考。默认要求方案各字段使用中文，便于核对和继续修改。编辑方案后先保存，再生成素材，防止素材与未保存文案混用。

文案模型使用“连接与设置”中选择的结构化输出模型。创作依据包括已录入的摘要、标签、文件名、所选词池以及原草稿绑定的选题依据；不自动读取网盘文件正文。来源链接、提取码和常见凭据文字会剔除。资源封面只在明确勾选参考封面/首帧且模型支持时发送。

## 图片与视频生成

在素材区域点击“刷新素材模型”，分别选择图片或视频模型。模型目录用于检查比例、时长、清晰度、参考封面与音频能力，避免用不支持的参数提交。报价入口打开对应模型的官方详情页。

图片可以逐页生成，也可以依次生成剩余尚未提交的图片。每张分别预留费用，预算不足或某页失败时停止后续批次；已经完成的图片保留。重新生成某一页只针对该页，按钮会提示再次计费。

视频提交后保存远端任务ID。可以手工查询进度，也可以在当前页面启用每30秒查询；离开页面或存在未保存的方案修改时暂停自动查询。重启后可以继续查询原任务。完成后下载到本地，通过本地播放器预览并导出MP4；视频接收上限128MB，单次下载超时或中断可继续用同一任务重试下载。模型返回的外部下载地址不会直接携带Key访问，下载使用固定的OpenRouter任务内容接口。

原生音频按模型能力选择。口播参考稿供审阅和后期配音使用，不表示已经自动完成指定口播配音、中文字幕或口型同步。应检查实际画面的主题、动作、文字准确性和音频内容。

依据的接口文档：[图片模型目录](https://openrouter.ai/docs/api/api-reference/images/list-image-models)、[图片生成](https://openrouter.ai/blog/tutorials/image-generation/)、[视频模型目录](https://openrouter.ai/docs/api/api-reference/video-generation/list-videos-models)、[动态视频生成与下载](https://openrouter.ai/docs/guides/overview/multimodal/video-generation)。模型与报价以刷新时的实际目录和官方说明为准。

## 版本与任务恢复

- 修改并保存会创建新版本。没有改变画面要求、页面文字或比例的素材可直接复用，不再生成或计费；改变的图片页或视频画面需要重新生成。
- 只修改文案时，已提交且拥有远端ID的视频任务可以关联到新版本，继续查询同一生成结果。
- 同位置正在提交的重复请求合并。已存在任务时默认复用；重新生成需要点击明确标示再次计费的按钮。
- 提交响应丢失且无法取得任务ID时，保留“远端结果待核”和费用记录，不自动重发。本人核对服务商记录后，可以明确允许新建一次生成；旧请求的待核费用记录仍保留。
- 查询原任务时须使用提交时的同一OpenRouter Key。更换Key不会把旧任务悄悄绑定到新账户。
- 图片和视频都要生成实际文件后才能完成整份内容审阅。重新生成素材会撤销审阅，需要再次核对。

## 编辑暂存与恢复

文案标题、正文、话题、封面文案，以及图文各页文字/画面要求、视频要求/口播参考和当前版本比例，会自动暂存到当前工作空间的SQLite数据库。界面同时保留恢复副本，避免窗口刷新打断最后一次输入。暂存不调用模型、不生成内容版本，也不会改变已保存版本的审阅结果。

切换页面、资源、网盘副本、平台和内容版本后，返回可继续原来的编辑。重新启动开发窗口或应用后可以恢复；数据库里的暂存也会随整库备份恢复。每份草稿的暂存相互独立。内容版本选择及新内容的形式、模板、创作要求和词池保存在当前界面环境，按副本和平台区分；这些界面偏好不随整库备份迁移。

已有稿件时默认收起“创作下一份内容”，优先呈现当前版本和编辑内容；展开后仍可选择四种形式、模板或新建手工草稿。页面显示“编辑已暂存到本地”和“已恢复上次编辑”，暂存读写失败会提示保留当前内容。

“保存修改”创建正式新版本并清理原稿的暂存，新版本需要重新人工审阅。校验失败会保留编辑内容。若要放弃当前编辑，点击“恢复已保存版本”并确认；只清理这一份稿件的暂存。

有未保存的编辑时，发布准备会提示下方为已保存的旧版本，并阻止复制文案、导出内容包和打开发布窗口。可点击“继续编辑”，完成保存与审阅，或明确恢复已保存版本后交付；后台接口同样检查，避免侧边栏切换时误用旧稿。

通过侧栏进入发布准备时跟随工作室当前选中的稿件，避免默认回到上次交付的另一份稿。文字AI生成兼容模型多返回的图片页字段：分段文案保留到正文，图片要求丢弃，不触发素材生成；HTML换行转换为普通换行。图片/图文仍检查实际页数，视频仍要求动态画面方案。

## 费用与交付

图片与视频复用当前OpenRouter Key及每日AI美元预算，调用阶段分别记入费用台账。提交前填写的费用预留是本地估算，应按所选模型报价填写；它不是服务商的硬性收费上限，实际金额可能更高。返回`usage.cost`后记录实际美元费用；未返回或提交结果不确定时保留费用预留与待核信息。

预览本地素材、修改模板、保存新版本不调用生成接口。查询已有视频任务和重试下载不会重新提交视频生成。

可以单独导出PNG/MP4，也可以人工审阅后进入“发布准备”导出整份内容包。内容包包含发布文案、编号素材、创意方案及素材目录；图文附带每页文案与图片相对引用，视频附带口播参考。原有本人分享核验和渠道链接规则仍适用于内容包，导出不会自动发布。

内容信息附带草稿ID、版本号、资源ID和副本ID，便于对应本地原稿与账号。文本模板及AI输入统一处理中文说明中的链接和常见凭据，保留中文标点后的用途、授权与其他事实，避免来源网址吞掉后续正文。

数据库从v8升级到v9前自动保存本机一致性快照。素材存放在工作空间的`media`目录，使用内容哈希作为文件名；备份、恢复会检查素材完整性。历史文本草稿继续保留，旧版本程序不能直接打开v9数据库。长视频等大文件会增加备份体积。

## 验证

核心测试覆盖四种方案、自定义模板、素材提交去重、预算及能力检查、PNG/MP4落盘、视频重启查询、下载失败恢复、版本复用、审阅门槛、内容包、备份完整性和v9迁移。

`npm run test:e2e:studio-media`使用隔离工作空间和模拟生成接口，验证模板选择、图片显示与导出、图文组图、视频ID恢复、MP4实际播放、发布准备及1320px/840px窗口。该测试使用本机ffmpeg制作动态视频测试样本；应用使用真实模型时不需要安装ffmpeg。

开发验证先运行`npm run dev`，再用`PANXU_E2E_DEV=1 npm run test:e2e:studio-media`或`PANXU_E2E_DEV=1 npm run test:e2e`。此模式使用当前Vite页面与`dist-dev`后端，测试工作空间仍单独创建。`tests/studio-working-copy.test.ts`覆盖暂存隔离、未完成输入、旧请求保护、交付门槛、损坏记录及备份恢复。

测试没有调用真实付费模型，不能代表某个模型的画面质量、汉字准确性、动作效果或生成耗时已经验收；这些需要在本人模型和资料下核对。

多媒体首版通过150项核心测试；编辑暂存与交付保护加入后，完整155项核心测试、开发模式下6组多媒体专项桌面交互及24组原有桌面回归通过，前端异常0条。专项交互包含真实有效的本地PNG与动态MP4文件保存、显示和播放验证，生成服务使用模拟接口。另在源码开发窗口验证跨页面/平台/资源恢复、版本切换、后端重启、长正文保存、恢复操作确认与旧稿交付拦截。

后续真实模型体验（2026-10-16，源码开发窗口）：经本人授权使用当前OpenRouter Key，按实际可用性配置Qwen3.8 Max用于文案、分析与截图理解，GPT Image 2.5 Sunburst生成图片，Veo 3.1生成动态视频；每日本地AI预算留空，仍保留费用台账。Claude Sonnet 5.5及Gemini 3.8 Flash文字接口在当前连接返回地区限制403，错误持续显示，推荐跳过，已有内容保留，未自动重发。
