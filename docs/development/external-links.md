# 外部网页跳转

`system.external` 和兼容入口 `zhidao.open` 共用 `core/external-links.ts` 的输入规则，经 `AppPorts.openExternal` 交给系统浏览器。

- 允许任意有效 HTTP/HTTPS 网页地址，包括自定义域名、清单 `/c/`、资源 `/r/`、公众号长链及非默认端口；不维护渠道域名白名单。
- 两个入口统一规范化 URL，上限4000字符；拒绝含用户名或密码的地址及非网页协议。
- 这是用户打开网页的规则。采集来源、登录会话、账号身份和发布目标仍在各自业务入口校验，不能把这些白名单或公众号文章路径限制复用到通用浏览器跳转。
- 工作台自身仍禁止被外部网页替换，系统浏览器跳转不需要解除 Electron 工作台的页面隔离。
