## 5118本地流量知识库（0.7.0）

每次真实外部请求开始前建立查询档案；完整收到响应后立即落库，不依赖后续页面、整批查询或用户手动保存词池。所有响应业务字段均保留，包括接口后续新增字段；Authorization、Cookie、API Key及回显的当前接口密钥会隐藏。关键词、热点、事件链、查询参数、种子词、平台、采集时间与源更新时间可追溯。原始归档与永久观察独立于缓存，刷新、过期和换Key均不覆盖旧快照；缓存复用不伪造一次新观察。网络中断或响应超过现有单次8MB读取上限时，只记录未取得完整响应，不捏造内容。

在“流量发现 → 本地知识库”检索全部资料，按接口与平台筛选，查看某个词历次来源档案和指标。列表合并展示同词/平台/接口的最近快照，CSV导出保留筛选后的全部历史观察，单份档案可导出JSON。可将所选词保存为词池，或带回种子词框再开启AI联想，复用操作不请求5118。AI仅发送最多50条相关文本参考，不上传完整响应、历史指标或事件链。

“本地样本规律”展示本人有响应的查询主题频次、关联观察数及按字面粗分的意图表达数量，分类可重叠；多种子搜索量任务关联整批结果。这些是本地操作与返回样本，不是平台真实用户的搜索日志，不能推断全网热度、搜索次数或因果趋势。

升级时仅恢复仍存在的长尾缓存、完整整理结果、下拉词和搜索量结果。旧记录可能缺少原始字段、查询参数、确切采集时间及接口来源，都会明确标记；重叠的旧缓存可能有重复观察，不计入新查询主题频次。已覆盖的旧数据无法还原。新归档随整库备份恢复保留，恢复后不会再次导入当前缓存制造重复。数据库v8升级前保存本机快照；旧程序不能直接打开v8库。词库持续积累会占用本地磁盘，可定期导出和备份。SQLite是主数据源，本轮没有把每份API报文额外写成Obsidian笔记。

本轮采用独立源码副本构建（`build/knowledge-source-0.7.0`），保留并整合当时已有改动；141项核心测试、最终ARM64打包应用24项桌面回归和4组知识库专项交互通过，前端异常0条。两个平台归档各34个构建文件与独立构建一致，不含用户数据，DMG与SHA256校验通过。交付目录为`release/0.7.0-knowledge`，请使用其中的安装包。专项联调均使用临时数据库及模拟接口，没有产生真实5118或AI费用；Windows实机安装与正式签名/公证仍待相应环境。

## 第一次使用

1. 在“账号管理”添加百度、夸克、UC或迅雷账号别名，打开隔离窗口完成官方登录，再点击“核验登录”。同一网盘可添加多个本人账号；同一个 UID 不能重复绑定。不要在聊天或源码中填写 Cookie、密码或 Key。
2. 在“录入资源”粘贴分享文案，填写标题、分类和说明。标签可选，封面支持上传、拖放和粘贴。可先保存资料草稿。
3. 选择目标账号，读取分享并选择文件，确认有权保存和分享，再开始转存。应用创建资源专用目录，保存后核验目标清单，再由同一账号建分享。
4. 在“连接与设置”分别保存 OpenRouter Key 和各个 5118 接口 Key。填入所购套餐的单位摊销价格、每日单位预算；需要时设置金额预算。OpenRouter 模型通过“刷新模型列表”选择。
5. 在“流量发现”提取种子词、查询长尾词或下拉词，保存词池。批量搜索量采用异步任务，至少 60 秒后手动提取；任务重启后仍可查看。热点雷达默认关闭，需先核实已开通权限与数据时效。
6. 在“内容工作室”选择资源副本、词池、平台、内容形式和模板，生成或手写方案。图片、图文和动态视频另行选择素材模型生成实际文件，预览核对后进入发布准备；保存修改会新增版本，当前版本须人工审阅。
7. 配置比特浏览器本地 API，读取窗口，建立平台账号与窗口映射。发布准备会重新核验本人分享，复制文案并打开指定窗口中的编辑器。发布由本人完成，最后回填内容链接。
8. 可选：选择 Obsidian Vault。已归档资源会导出到 `Vault/盘序/Resources`，封面在 `Attachments`。笔记的“我的笔记”区可自由修改。

OpenRouter 可点击“验证Key与用量”查询当前 Key 的服务商用量、上限与剩余额度。刷新公开模型列表不能证明 Key 可用；Key 剩余额度不是账户钱包余额。未返回的金额显示未知，不当作 0；更换或移除 Key 后清除上次诊断。诊断不会调用生成接口。接口依据：[当前 Key 查询](https://openrouter.ai/docs/api/api-reference/api-keys/get-current-api-key)。

### 批量录入与本地内容

“批量录入”接受UTF-8 CSV（可带BOM），最多500条、2MB。必填列为标题、链接、分类；可选标签、说明、账号、提取码。标签用中文逗号或分号分隔，带英文逗号或换行的字段须使用标准CSV引号。账号列填写唯一的已启用账号别名，否则使用页面选择的账号或该网盘默认账号。预检标明新增、同资源新账号副本、重复和错误行；导入只建本地草稿，不自动读取分享或执行转存。同资源的新账号副本沿用已有资源资料，避免覆盖原信息。

手工词池不调用5118、不生成流量数值；“复制编辑”另存词池，保留原稿引用。本地平台模板只使用已录入说明并保留待填写位置，初始未审阅；不会把模板当作已验证体验。TXT/Markdown说明由本人通过文件对话框选取，不自动下载或读取网盘文件。

发布准备可导出包含文案、平台信息及可选封面的本地文件夹。导出与复制共用人工审阅、内容版本、本人分享及渠道链接检查。附链接时仅附核验后的本人链接及提取码；导出不创建已发布记录。内容包可能含本人分享和提取码，请只交给预期的发布账号。

## 批量转存与三级拆分总体规划

本轮按“先规划，再开发”将两项功能纳入同一任务系统。每份资料仍绑定创建时的本人账号；四个网盘分别通过同盘适配器接入。拆分结果作为原资料的子链接保存，原文件和原资料分享保持保留。

| 功能 | 操作流程 | 边界 |
| --- | --- | --- |
| 批量转存 | 选择草稿 → 读取预检 → 调整文件选择 → 权利确认 → 入队转存 → 本人分享及归档 | 每批1—100份资料，每份最多100个所选顶层项；文件夹整体转存 |
| 三级拆分 | 选择本人已归档副本 → 只读读取三级目录 → 树状展开并逐项勾选 → 核对链接清单 → 权利确认 → 本人子链接 | 每批最多100个链接，预览最多处理2000个节点，目录树支持展开、收起与搜索；不会复制或移动远端文件 |
| 恢复与结果 | 查看批次或拆分记录 → 核对异常项 → 恢复任务或粘贴本人已建分享 → 核验后复制/导出 | 来源链接不能充当本人链接；响应未知时只查已有结果，不直接重发建链 |

批量录入CSV后可将新草稿带入“批量转存”；超过100份时先带入前100份，其余从候选列表继续分批。也可直接在批量转存页按账号、标题或分类查找草稿。已有转存任务的资料从原任务恢复，不重复创建。

未选择过文件的资料会读取分享根目录全部项；已有文件选择时重新读取并核对原清单。预检不创建目标目录、不转存、不建链。失效分享、提取码错误、目录超限及账号问题分别记录，一项失败不丢弃其他项。预检完成后才能确认本批所选资料；重复点击开始会复用已创建的任务。同账号串行、全局最多两个账号并行，批量预检、转存、拆分预览和子链接创建共享此限制。

资料专用目录定义为第0层。通过“第3层”快捷选择下例时，勾选 `说明.txt`、`简介.txt`、`视频.mp4`、`更深目录` 和 `空目录` 五个独立链接目标；目录树同时展示父目录供自由勾选。不会读取“更深目录”中的第4层文件，但分享整个第3层目录仍会包含其下的内容；“最多三级”限制的是拆分展开深度。

```text
资料专用目录 第0层
├── 说明.txt 第1层
├── 课程 第1层
│   ├── 简介.txt 第2层
│   └── 章节 第2层
│       ├── 视频.mp4 第3层
│       └── 更深目录 第3层
│           └── 第四层文件.txt
└── 空目录 第1层
```

界面默认一次读取前三层全部节点并全部展开，初始不预选。勾选文件夹表示给该文件夹整体建一个独立链接，不会级联勾选子项；文件和子文件夹可单独勾选。可同时选父子项，但界面会提示分享内容重叠。右侧清单列出当前选择、预计链接数、已生成状态和单项操作；收起目录或搜索不会清除选择，搜索会显示匹配项及其祖先路径。键盘上下移动、左右展开/收起，空格或回车切换当前项选择。

保留原“按指定层级拆分”语义作为第1/2/3层快捷选择：目标层每个文件或文件夹单独选中，较浅的文件和空文件夹保留，替换当前选择。超过100项时选择前100项并提示分批处理；手动选择同样最多100项。历史层级预览会重建目录结构，未包含在旧预览中的父目录仅作路径展示；重新读取后可选择全部三级节点。空目录是否获准分享以网盘实际响应为准。

每个拆分项保存原资料副本、稳定文件ID、祖先目录、路径、层级、本人分享ID、归属UID、版本及核验时间。创建分享前重新检查路径和文件清单，先查有效本人分享并复用；请求结果未知时只查本人记录，找不到时交给本人在官网核对并恢复。文件被移动、替换或账号UID变化时阻止建链和分发，不自动改绑。

子链接复制与导出会重新检查本人归属和分享有效性，提取码加密存储；清单默认不附提取码，需要时勾选。Obsidian在原资料笔记中增加“本人拆分链接”区，沿用原笔记的提取码开关与冲突保护。本轮没有将子链接另建为独立资源或独立AI草稿，创作工作室继续按原资源副本组织内容。

账号要求登录、实名、验证码、容量处理或其他人工核实时，暂停同账号尚未执行的任务，其他账号继续。停止等待不删除远端文件或撤销已发出的分享；停止后收到可核验的成功分享仍会保留，避免丢失远端结果。备份恢复会清除子链接核验标记并暂停任务，需要重新登录和复核。

实现顺序：v5数据迁移与共用任务类型 → 批次预检及执行 → 三级目录遍历及子链接 → 笔记、导出和恢复 → 核心测试、模拟网盘界面联调与安装包验收。

## 费用口径

5118 公开文档未确认可用的账单或余额查询 API，因此应用记录的是**本地请求数、预留计费单位和所购套餐摊销估算**。官方扣费保持未知，不能把成功 HTTP 请求等同实际扣款。

- 长尾词按关键词 × 页预留；下拉词按关键词 × 平台；搜索量提交按关键词数。
- 搜索量轮询是否计次未确认，独立记为待核并预留 1 单位；禁止 60 秒内重复轮询。
- 热点雷达按最多 10 条的一页预留 1 单位，权限与数据时效需实测。
- 超时或响应不明时保留预算占用，不自动判定为免费。成功的单页会缓存，后续页面失败不会丢掉已付费查询结果；再次查询时保持“优先缓存”可复用。
- CNY 与 OpenRouter USD 分列，缓存 0 外部请求。OpenRouter 返回实际 `usage.cost` 时单独记录；未返回时保持未知。
- 本地预算只能约束应用发出的请求，不能代替服务商账单；其他客户端用量不在这里。

搜索量提交前先落本地检查点。响应丢失后，同一组关键词即使换序、重启或再次点击查询，也不会自动重交；“提交结果待核”记录不能当作远端任务轮询。请先在 5118 后台核对，再点击“已在5118核对，允许重新提交”。解除拦截保留原费用预留，再次提交仍可能计费。

下拉词返回 `200104` 时保存的是本地分析记录，服务商没有返回远端任务ID。普通查询复用未完成记录；“继续查询（可能计费）”按原关键词和平台再次请求，先要求勾选计费确认，并执行至少60秒的应用限频和原有预算限制。上次待核费用不会因后续成功而自动清零。已完成记录的“查看已存结果”不发送请求，普通查询可在10分钟内复用缓存。更换Key后不能继续旧Key的未完成记录。0.1.1只保存了下拉词错误台账，没有完整查询条件，因此不会推测并补造历史分析记录。

首次从0.1.1打开0.1.2时，SQLite从v2升级到v3。迁移前在数据目录创建 `panxu.db.before-v3-<UUID>.bak` 一致性快照，权限为仅本机用户可读写；快照含原库的加密凭据记录，不含网盘会话文件。事务失败保留原库。0.1.1不能直接打开v3数据库；回退时先退出盘序、保留当前目录，再将迁移快照的副本恢复到空数据目录，不能与活动WAL文件混用。日常对外导出的备份仍排除API Key。

0.2.0打开v3数据库时，先创建 `panxu.db.before-v4-<UUID>.bak`，再在事务中增加分享巡检记录表并升级为v4；从更早版本逐级迁移时只在首次迁移前保存一致性快照。旧程序不能直接打开v4库。自动迁移快照保留原加密凭据，只供本机故障回退，日常跨设备使用仍应选择排除凭据的“导出一致性备份”。

0.3.0打开v4库时，先保存 `panxu.db.before-v5-<UUID>.bak`，在事务中添加批次、拆分项、拆分预览关联和任务种类，原有任务默认归类为转存。v5库不能直接交给0.2.0或更旧版本打开。自动迁移快照含原加密凭据，日常分享或跨设备迁移请使用排除凭据的导出备份。

## 中断与恢复

转存请求发出前写入检查点，收到响应后写入任务 ID。如果请求结果未知，恢复时先检查专用目标目录；目录仍为空时不自动重复提交，提示人工核对。如果建分享响应未知，先查询本人记录，避免重建重复链接。

百度分享记录有时不返回提取码。此时在原账号网盘里核对本人分享，再使用“恢复本人分享”粘贴链接及提取码。恢复仍要核验本人记录、目标文件与分享内容。来源链接一律不接受。

如果目标文件已核验，在“恢复本人分享”中可点击“查找或新建本人分享”：先查本人有效分享，没有匹配记录时创建新链接，不重新转存。夸克若返回 `32011 / user NOT real name`，请本人在夸克官方客户端或官网完成实名认证，再回到这里继续。应用不收集实名资料；平台拒绝时不会伪造成功或用来源链接替代。

“停止本地等待”不会撤销已经发送的网盘操作，不自动删除远端文件。登录 UID 变化不会改绑任务，需要登录原账号。资源或分享更新后，旧草稿必须重新人工审阅。

Obsidian 中生成区或 frontmatter 被外部修改时，导出报告冲突并保留文件；手写后缀保留。SQLite 是主数据源，当前没有双向导入或自动合并手改生成区。

## 数据与备份

设置页可打开实际数据目录。默认使用操作系统的应用数据目录，包含 `panxu.db`、`covers/`、隔离 session 等。开发/测试可用绝对路径环境变量 `PANXU_DATA_DIR` 指定独立目录，不要将真实数据目录提交到版本库。

在“连接与设置 → 本地数据与备份”导出一致性备份，或选择一个备份文件夹并预检。预检核对数据库完整性、版本、SHA-256及封面哈希，拒绝缺失附件、符号链接、工作日志和含凭据记录的备份。确认后恢复到当前数据目录下的独立 `restored-workspaces/workspace_<UUID>`，原工作空间及备份保持保留；应用重启后使用新空间。默认数据目录的 `workspace-location.json` 仅保存当前空间位置。开发/测试指定 `PANXU_DATA_DIR` 时不写入正式位置文件。

恢复后重新登录原UID、填写Key、选择Vault，并恢复本人分享提取码及重新审阅内容。分享复核标记和链接放行权限会重置；未完成任务暂停为“需人工核对”，每日AI预算默认为0。原已完成任务不会自动重跑。需要回退时点击“切回恢复前工作空间”，恢复后的数据也保留。存在排队或执行中任务时禁止切换，请先停止本地等待并核对远端结果。备份支持v1—v7数据库，不支持由未来版本生成的备份。

## 接口依据与联调限制

百度/夸克同盘转存使用其网页登录会话和网页接口，当前没有把这些接口描述为网盘官方承诺稳定的开放 API。可能遇到验证码、容量限制、风控或页面结构更新；应用会保留检查点并提示处理，不会绕过验证，也不会使用来源链接兜底。

接口实现独立编写，只将公开接口定义用于协议核对，未引入或复制 AGPL 项目的实现。参考：

- [BaiduPCS-Go：分享数据结构](https://github.com/qjfoidnh/BaiduPCS-Go/blob/master/baidupcs/share.go)、[网页转存协议](https://github.com/qjfoidnh/BaiduPCS-Go/blob/master/baidupcs/transfer.go)
- [夸克接口协议说明](https://github.com/zhaocongqi/clouddrive-auto-save/blob/main/docs/quark_apis.md)
- [5118 API 商城与计费文档](https://www.5118.com/apistore)；具体接口链接内置在设置页
- [OpenRouter：结构化输出](https://openrouter.ai/docs/features/structured-outputs)、[API 用量](https://openrouter.ai/docs/api-reference/overview)
- [比特浏览器：浏览器接口](https://doc.bitbrowser.net/zh/api-jie-kou-wen-dang/liu-lan-qi-jie-kou)
- [Electron 安全](https://www.electronjs.org/docs/latest/tutorial/security)、[系统加密](https://www.electronjs.org/docs/latest/api/safe-storage)

各内容平台默认策略是应用的发布限制，并非对某账号一定获准发布外链的保证。链接权限随账号能力和场景核实；规则来源入口在设置内提供。当前未实现自动发布、批量评论、私信导流或账号身份自动识别。
