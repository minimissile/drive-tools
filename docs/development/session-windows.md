# 共享工作空间的会话窗口

当前源码开发使用一个 Vite 服务、一个 Electron 主进程和一个 `AppService`。开发与自动化窗口共用源码、数据库、Cookie、缓存、账号会话与附件目录。每个窗口的导航、筛选、选择和本地输入按稳定窗口 ID 暂存；主窗口保留原有暂存键，其他窗口使用同一 localStorage / IndexedDB 中带窗口前缀的键。

## 手动开发

正常启动 `npm run dev`。首次采用本功能需要有序重启原开发服务一次，因为开发监督器脚本不会自行热更新；不要同时再启动一套服务。

顶部“会话窗口”可以修改当前窗口的内容描述和会话名称、打开新窗口、切换窗口。原生标题栏同步显示这些标识。自动化窗口还显示运行、暂停、通过、失败或手动接管状态。

也可以从另一个开发会话执行：

```sh
npm run dev:window -- --label "资源目录编辑" --session "资源清单开发" --page resource-catalog
npm run dev:window -- --list
npm run dev:window -- --focus 窗口ID
npm run dev:window -- --close 窗口ID
```

命令通过本地开发监督器申请窗口，不启动第二个 Electron。连接描述保存在被 Git 忽略的 `.panxu-dev-session.json`（仅当前用户可读写），包含本地认证令牌；不要提交或打印该文件。开发调试通道只绑定本机回环地址，用于连接现有测试窗口。生产应用不开启该通道。

## 共享窗口自动化

仍然只在用户明确要求自动化时执行。可从多个终端同时运行不同模块，每次运行创建自己的可见窗口：

```sh
npm run test:session -- --module ./scripts/my-feature-check.ts --label "资源目录专项" --session "资源清单会话" --page resource-catalog
```

模块需导出 `async function run({ page, checkpoint, windowId })`。`page` 是本轮窗口的 Playwright 页面代理；定位器构建保持同步，页面操作开始前检查暂停/接管状态。长时间的自定义异步步骤在阶段边界调用 `await checkpoint()`。测试模块由实际任务提供，以上路径是接口示例，项目未附带或自动执行示例测试。

运行器用窗口 ID 查找页面，默认保留完成或失败现场；`--close` 只关闭本轮窗口。连接断开不会关闭共用后台。顶部暂停在当前操作结束后生效；“手动接管”中断本轮，之后的人工操作不再作为自动化通过结果。运行器只应通过给出的页面和检查点操作，不能调用 Electron 全局求值、修改进程级 `fetch` 或使用共享 BrowserContext 的全局拦截。页面级 mock 只覆盖渲染器请求，不能冒充后端第三方调用的模拟覆盖。

脚本异常、SIGINT 和 SIGTERM 会尽力更新本轮状态。若运行器被强制终止，保留窗口可能仍显示运行中；手动接管或关闭该窗口可以解除重启等待。

## 生命周期与数据

任一窗口保存业务数据后，后台向所有工作台发送变更事件，各窗口按现有读取逻辑刷新，不替换本地未提交输入。原生文件对话框通过请求上下文绑定发起窗口。关闭一个窗口不会退出其他工作台；最后一个窗口仍遵循现有后台任务退出确认。

自动化处于运行或暂停状态时，后台源码更新会等待，不重启其他测试。结束、接管或关闭后恢复原有空闲重启。监督器在正常开发重启期间保留窗口 ID、标签与会话，窗口重新打开后恢复各自暂存。普通刷新优先恢复已保存的当前页面，创建时的初始页面只在首次使用。

前端仍共用 Vite 热更新；本方式用于当前工作区的并行调试，不冻结测试代码版本。同一个业务对象、账号登录态和全局设置仍然共享变更；测试不能清空公共数据或以完成测试为由撤销其他窗口的操作。

历史 `scripts/e2e-*.mjs` 中有些依赖临时数据库、`electron.launch()`、全局 mock 或退出应用，仍属于独立/安装包验收。它们不能直接当共享窗口测试运行，也没有在本次批量改写为操作当前数据。新共享任务使用上述接入器，迁移旧用例时需逐项移除这些假设。
