# 搜索运营

搜索运营工作台复用已有词池、本人资料副本、内容草稿和发布记录。首版适合用小批量工具教程验证搜索需求与配套资料效果；所有数据保存在当前工作空间，不预置演示选题或流量。

## 从选题开始

1. 在左侧打开“搜索运营”，新建关键词、搜索意图和目标平台；也可点击“从词池创建”，每次最多选择100词。流量发现中的已有词池也提供“创建搜索选题”入口。
2. 同平台相同关键词会去重，词池来源保留。选题创建本身不请求5118或AI接口。
3. 打开选题，在弹窗中搜索资料，选择本人副本及“整份资料”或已核验的本人拆分链接。资料属于词池绑定资源时，应选择该资源下的本人副本。
4. 在“教程依据”填写已核实的软件版本、适用系统和实际操作记录。资料不足的地方保留待填写内容，不把文件名当作已读正文。
5. 使用本地教程模板进入“内容工作室”，补充实际步骤与配图；也可使用既有OpenRouter连接生成待审阅草稿，沿用原模型预算和费用台账。

## 从资料拆分开始

原来的三级目录树、逐项勾选、批量建链、复制、导出、核验和恢复流程继续使用。在已就绪拆分项详情中点击“用于创作”，为资料新建选题或关联已有选题，再进入内容工作室。

搜索选题中的关联弹窗只选择已经保存的本人资料，不替代目录拆分，不创建新的网盘分享。

## 审阅与发布

保存修改仍会产生新草稿版本，并要求重新审阅。选题及具体子链接的关联会随版本保留。

“准备发布”继续使用原来的发布准备页面：核验本人资料、复制或导出内容、打开已配置的比特窗口，由本人发布并回填文章链接。附加链接时，使用当前草稿关联的本人子链接和对应提取码，不替换成整份资料链接或来源链接。本人分享与渠道链接权限继续核验。

## 记录效果

已回填的文章可在搜索运营选题详情中录入效果：

- 选择文章和“单篇文章”或“账号汇总”范围。
- 填写统计开始、统计结束、后台来源，以及已知的阅读量、转存量、有效拉新和已结算人民币。
- 未知数据留空，真实零值填写0。账号汇总不会显示成单篇效果。
- 同来源、同统计周期的重复记录会被拒绝。多个周期的累计值不自动相加，也不会推测转化率或收益。
- 可以导出当前选题相关的效果CSV，保留范围、日期、来源和未知值。

效果由本人根据后台填写；首版未接入CSDN流量、High推结算或自动归因接口。发布状态仍由本人确认，不自动发布。

## CSDN 技术教程交付

发布准备按 CSDN 分开提供“复制标题”“复制正文（Markdown）”和“复制摘要建议”。摘要从正文段落提取，跳过标题、图片与代码块，保留 `font_manager` 等代码标识符；可在 CSDN 后台继续修改。正文不重复拼入标题和话题，避免直接粘贴时混入多余内容。

正文预览可独立滚动，完整文章不会把复制、导出与发布步骤推到页面末尾。已提交但平台仍在审核的文章，可先填写实际地址并点击“记录已提交 · 待审核”；下次打开同一草稿版本与账号时自动带回地址。核验文章通过并正常公开后，点击“人工标记已发布”更新同一条记录。重复提交同一版本、账号与地址不会增加重复记录，已确认发布的记录不能误退回待审核；待审核不计入搜索运营的已发布数量及效果录入。

“资源获取方式”会区分正文已有本人链接、复制导出时附加链接、尚无网盘入口三种情况。缺少入口会提醒，作者仓库参考链接不算已交付本人网盘资料。URL 检查匹配实际分享地址，排除相似 ID、示例代码、图片地址与注释；不替代原有渠道权限与本人分享核验。官方组件须实际挂载后从文章点击验证，创建卡片或看到后台预览不代表读者已可访问。导出的 `includesOwnLink` 根据最终正文记录，正文内已有链接也会正确标记。

导出内容包除原有文件外，增加 `文章.md` 与 `CSDN发布字段.json`，分别保存带一级标题的完整文章，以及标题、标签、摘要建议、所用模型和发布步骤。内容包继续记录草稿版本、资源与副本归属，并经过原有审阅、未保存编辑、本人分享和渠道权限核验；导出不修改发布状态。

默认编辑入口为 `https://editor.csdn.net/md/`。允许 CSDN 编辑器在 `editor.csdn.net` 与 `mp.csdn.net` 的 HTTPS 页面间正常跳转；HTTP 403 等错误页不再显示为打开成功，其他域名和登录页仍单独报告。已有自定义映射保留原值，旧的根域入口可在“连接与设置”中编辑为 Markdown 入口。

一次实际发文按以下顺序操作：

1. 核对比特窗口中的 CSDN 账号、发文权限和当日额度。
2. 在盘序创建搜索选题，关联已有本人资料，补充已运行的示例、环境、许可和一手来源，再进入内容工作室选择“步骤教学”。
3. 生成后校对事实并实际运行完整代码，上传真实结果图，将图片地址保存回盘序；保存新版本并重新审阅。
4. 从发布准备分别复制标题和 Markdown 正文，检查 CSDN 预览中的代码、表格、图片及参考链接；确认本人资料获取入口已包含在正文，或使用已实际挂载的官方组件，发布后从文章点击核验。
5. 选择站内已有标签，填写摘要、AI 辅助声明和可见范围。低等级账号可能不能创建自定义标签，可从 Python 等分类选择已有标签。不需要 GitCode 备份时保持不勾选。
6. 提交时若要求微信绑定或绑定微信再次扫码确认，由本人在官方窗口完成；绑定完成不代表本次提交已验证。未看到提交结果前，不重复点击提交。
7. 查看文章页与平台审核状态。审核中先回填地址并记录待审核，实际审核通过且正常公开后再确认已发布。阅读、转存和收益等待后台实际数据，未知值留空。

步骤与字段整理已固定在 `shared/csdn.ts`、发布准备页面和内容包导出中；当前未实现无人值守的 CSDN 上传、审核状态采集或账号安全验证。

## 资料维护与升级

选题详情会提示本人副本、分享或草稿资料版本需要复核的情况。可以主动核验配套分享，进入原资料拆分页面恢复本人链接后重新审阅文章。临时网络失败不会被记为已确认失效。

本功能使用v6数据库。首次从v5打开前，在本机保存`panxu.db.before-v6-<UUID>.bak`一致性快照；从更早版本升级时沿用首次迁移快照。日常导出备份包含选题、草稿关联和效果记录，仍排除Key、提取码及登录会话。恢复后需要重新登录和核验资料。旧程序不能直接读取v6库。
