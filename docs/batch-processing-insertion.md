# 批量处理与批量插入开发计划

## 用户确认的范围

将批量录入与批量转存合并为一个“批量处理”入口：CSV 添加资料 → 本地草稿 → 读取分享与选择文件 → 确认转存。保留仅导入、选择已有草稿以及任务历史。导入上限 500 行，转存每批上限 100 份，超出部分留在草稿中，不丢弃。

新增批量插入，支持两个目标来源：项目中已转存的本人目录，或浏览本人网盘选择其他目录。只写入勾选目录，不递归扩散。素材包括以名称引流的空文件夹、UTF-8 TXT 和 PNG/JPEG/WebP 图片；只操作本人已核验账号。

## 实现结构

- 统一批量处理页面组合导入、转存和插入三个业务界面；旧路由保留兼容，侧栏只保留一个入口。
- 插入素材与任务保存在本地数据库，表单按工作空间暂存。图片不放入 localStorage；确认写入的勾选不会恢复。
- 专用插入服务与 IPC，复用账号 UID 核验、账号互斥锁及现有网盘适配器。文件上传增加小文件专用协议，不借用转存接口。
- 文件夹沿用网盘创建目录能力。夸克/UC 使用预上传、摘要、OSS 分片与完成协议；百度使用网页预创建、分块上传与提交；迅雷使用临时 S3 凭据；PikPak、光鸭使用临时 OSS 凭据。临时云存储凭据不写日志、不落盘。

## 执行契约

1. 每批最多 100 个目录、10 个素材；单图片最多 4 MiB，TXT 最多 512 KiB。
2. 执行前核对账号 UID、目录路径与 ID，展示各项预检结果；同名内容一律跳过，绝不覆盖或自动改名。
3. 开始时再次读取目录，防止预览后出现同名内容。每个写入先保存检查点，再请求远端，成功后核对名称、类型和大小。
4. 取消停止后续项，不承诺撤销已经提交的写入；结果不确定的项保留“待核对”，不得自动重试写入。应用重启不会自动恢复远端写入。
5. 目录素材不会自动加入以文件 ID 列表创建的已有分享；界面明确提示需要重新选择分享内容。插入不自动建链、不自动发布。
6. 任务与素材随工作空间数据库备份；处理结果保留本地历史，支持核对与导出。

## 验证与交付

使用临时数据库、模拟网盘与模拟存储服务验证：所有素材类型、同名项、错误目录、UID 变化、并发启动、取消、响应丢失、重启与恢复。当前源码开发环境检查桌面与 840px 最小窗口的实际界面。本轮不打包、不提升版本、不自动使用真实网盘数据。

协议调研依据为现有官方网页与 OpenList 的公开兼容实现；这不等同于各网盘提供稳定的官方上传 API。真实账号的上传验收应单独执行，不能用模拟测试冒充。

## 本轮实现与验收记录（2026-10-17）

- 已实现：单一“批量处理”导航、CSV 导入与转存衔接、两种目录来源、目录树多选、文件夹/TXT/图片素材库及预览、插入预检、显式确认、逐项结果、停止后续项、只读核对、CSV 导出及刷新恢复。
- 六种网盘均已接入小文件上传适配器。仅完成模拟协议验证，尚未进行真实账号插入验收；不将其标记为线上接口已验收。
- SQLite 升级到 v13，升级前保留一致性备份；插入素材和任务随数据库备份。导入/转存继续复用已有持久化流程。
- 根目录不能作为插入目标；目录浏览树最多展开 8 层。本地素材库最多 200 项、约 96 MiB，单次最多选 10 项。
- TypeScript 检查通过；全量 241 项自动测试通过，其中新增 22 项涵盖插入工作流与上传协议；后续针对受影响部分复验通过。
- 当前 Vite 源码 + 独立 Electron + 临时数据库界面验收通过：导入衔接、三种素材及预览、两个目录共六项模拟插入、刷新不重复执行。已查看 1440px 与 840px 界面截图。所有外部写入均以模拟服务替代。
- 不生成安装包、不提升应用版本；开发输出仍为 dist-dev。
