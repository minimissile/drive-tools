# 微博图文营销

开发版入口：**工作台 → 微博内容操作 → 微博图文营销**。

本轮确定的方向是资源推荐图文：说明本人资料的用途、适合人群和使用限制，按账号的已核实权限附加本人分享。当前已接通官方网页发布器：自动填写文案、上传本地图片、确认提交、读取官方回执并保存单条链接；人工交接保留为备用路径。发布器复用“其他账号”的隔离会话，不需要购买第三方发布 API，也不依赖文案或图片生成模型。

## 不带网盘链接的直接发布

账号管理 → 其他账号 → 已登录的微博 → **发布微博**。手写文案，选择 0–9 张 PNG、JPG 或 GIF 本地图片，选择公开或仅自己可见。勾选已核对内容后点击“自动填写并上传”；核对官方窗口的账号、图文、可见范围和内容声明，再在盘序点击“确认发布到微博”。应用点击官方发送按钮，监听本次 `/ajax/statuses/update` 的响应，自动保存微博 ID 与链接。查看回执使用同一账号的官方会话窗口，保留其他发布框中的未提交内容。

直接发布支持本地草稿、附件、状态和回执恢复；默认仅自己可见，确认勾选不恢复。没有网盘资料也能验证发帖能力。带网盘分享的推荐仍从“微博图文营销”关联本人已核验资料，不能通过此入口绕开资料归属和外链权限。AI 创作是原有的可选付费能力，手写文案与本地配图发布不调用它。

## 微博账号登录

1. 进入 **账号管理 → 其他账号**，平台选择微博，填写可选备注，点击“登录新账号”。该分区只管理非网盘账号，原网盘登录继续在“网盘账号”。
2. 在打开的微博官方窗口自行扫码或登录，安全验证也在官方页面完成。账号按工作空间、平台和本地账号记录使用独立的持久化会话；不复制比特浏览器的 Cookie，不在数据库、IPC 或图文包中传递微博凭据。
3. 登录导航及会话变化后会尝试识别身份，也可点击“检查登录”主动向微博核实。列表自动刷新只读取本地状态，不循环请求官网。账号行显示昵称、UID、核实时间，以及待登录、已识别或需重新登录状态；网络错误显示可重试提示，不作为登录过期的证据。
4. 首次核实后固定账号 UID。若窗口改登其他微博身份，连接会被阻止，不自动改写历史账号和任务；请恢复原账号，或单独添加新账号。同一微博 UID 不重复连接到多个本地账号记录。
5. 在账号行打开“发布能力”，记录已核实的图文能力及网盘域名依据，明确选择是否允许正文外链。核实说明按工作空间和账号暂存；本次确认勾选不恢复。登录成功不自动授予外链权限，沿用链接权限 30 天复核规则。
6. 微博营销任务选择上述已登录账号，UID 从身份识别结果带入。导出和交接前再次核实；打开的仍是该账号的官方会话，过期、换号、账号移除或配置变化时阻止继续交接。回执作者仍按导出时的 UID 校验。
7. 账号备注、发布能力、重新登录和移除统一在“其他账号”。移除清除本机会话，停用其发布连接，并保留历史任务、发布和效果记录。旧版比特窗口任务的原回执保留；尚未发布的任务需重新选择官方会话账号并导出。

登录核实使用同一隔离会话，在后台新加载微博官方首页，读取首页自身的当前用户配置；不刷新用户可见的微博窗口，也不根据访问的个人主页地址认定身份。后台核验窗口有超时限制，完成或失败后销毁；普通列表刷新只读取本地结果。它不等同于微博开放平台 OAuth 或稳定的公开 API。平台拒绝访问、配置结构未知或要求安全验证时保留会话并提示处理，不将 Cookie 存在视为已登录。

## 产品流程

1. 从本地词库选词，或输入明确的推荐主题。来源、采集时间和指标保留原始口径，不将百度、5118 指标标成微博搜索量。本页面不自动调用热搜或付费找词接口。
2. 按关键词搜索已核验的本人网盘资料。匹配依据为标题、摘要、标签与文件名，不代表已经读取文件正文。不自动转存或建链；这些操作继续在原有资源与网盘流程显式执行。
3. 填写适合人群与至少 10 字的已核实资源依据，创建本地任务和微博短文草稿。同一主题与资料已有任务时继续原任务，避免重复创建。
4. 直接手工编辑，或显式生成推荐文案。配图可选资源封面，或通过现有内容工作室生成单图方案，再在共用编辑器生成实际图片。模型、预算和费用沿用原有 AI 配置；图片方案不作为成品发布。
5. 保存版本，检查资源事实、话题和图片，完成人工审阅。文案建议 140–280 字，最多 3 个相关话题；工作台按完整交付文本（含标题、正文、话题、本人链接与提取码）设置 2000 字符上限，不静默截断。该上限是工作台的产品约束，不是对微博所有账号限额的承诺。
6. 选择“其他账号”中已登录的微博，查看自动带入的昵称与 UID，选择配图来源。需要网盘入口时勾选附加本人分享；正文外链权限及 30 天核实有效期来自该账号的发布能力。正文已含当前本人链接时不重复附加。
7. 点击“核验并导出图文包”，选择本地目录。准备时复核当前已审阅版本、本人分享、账号能力和实际图片。导出 `微博文案.txt`、1–9 张图片及 `发布清单.json`；每张图片小于 20MB，格式为 PNG、JPG/JPEG 或 GIF。清单记录选题、资料、文案版本与目标 UID，导出本身始终标记未发布。
8. 点击“自动填写并上传图片”，再次核验账号身份、内容与图文包后，使用同一账号的官方发布器填入文案并上传全部图片。发布器已有其他草稿时停止，不覆盖网页内容。选择公开或仅自己可见；核对官方窗口及平台要求的内容声明后，勾选确认并点击“确认发布到微博”。应用只触发一次官方发送按钮，网站原有的身份验证和安全机制继续生效。也可选择原有的复制文案人工交接。
9. 平台明确返回成功时自动保存单条微博链接并登记已提交，关联任务、选题、本人资料和公共发布台账。尚未确认公开时不冒充已公开；仅自己可见的任务不能登记为公开。回执不明确时禁止自动重发，允许核对后手工登记 `https://weibo.com/目标UID/微博ID`；不接受主页或其他作者。原“搜索运营”的效果记录及资料入口验收继续可用。

## 状态与恢复

- 编辑与审阅 → 正在生成方案／正在核验图文 → 图文包已就绪 → 图文已上传待发布 → 正在提交 → 已提交待核对／已确认公开。人工交接仍使用已交接待回填；提交中断或回执未知进入待核对，不能再次点击提交。
- 长表单和当前任务按工作空间暂存；稿件继续使用原数据库暂存、版本与素材继承。结果确认复选框只在本次界面内有效，不随切页、刷新或重启恢复。
- 生成和导出失败时保留原稿件及任务，提供明确错误。重启不会自动恢复 AI 生成、远端核验或发布操作。
- 交接前比较文案、账号配置、本人分享版本及图片内容摘要；导出图片或文案被移动、删除、修改后不能继续交接。
- 打开窗口前先保存交接意图。窗口打开失败、应用退出或本人已手工发布但尚未回填时，任务继续保留待核对状态。可重新复制并打开窗口；必须明确确认尚未发布，才能返回改稿和重新准备。
- 回执先保存，再同步公共发布记录。同步失败显示警告并保留链接，可重试同步，不需要重复发帖；已公开记录不能退回未提交。
- 当前图片来源是资源封面或本稿件已生成素材。首版生成入口提供单图方案；已经关联的工作室组图可一并导出。视频和微博头条文章不在本图文流程中。

## 实现边界

- `shared/weibo-marketing.ts`：领域类型、短文组成、字符和话题检查、回执作者校验及 IPC 契约。
- `core/weibo/marketing.ts`：本地资源任务、内容生成编排、图文导出、网页填写与提交、发布台账及回执恢复。
- `core/weibo/posts.ts`、`shared/weibo-posts.ts`：不带网盘资源依赖的直接发布、本地附件与状态持久化。
- `desktop/weibo-publisher.ts`、`desktop/weibo-publisher-page.ts`：官方发布器适配，复用网页自己的上传和发送流程；仅监听匹配当前文案与可见范围的实际提交响应，不读取或导出 Cookie。网页结构变化、草稿被修改、图片未完成上传、可见范围不同步、附加排期或其他内容时停止操作。
- `core/content-sources.ts`、`shared/content-sources.ts`：微博和 CSDN 共用本地词源及本人资料匹配，避免重复实现。
- `core/ipc/weibo.ts`：参数校验及领域入口；`core/service.ts` 只负责组装原有 AI、草稿、分享、发布与系统端口。
- `src/weibo/`：选题、编辑组合、图文预览与结果登记；复用公共选择器、数据状态、分页和 `DraftEditor`。

任务及来源保存在当前工作空间 SQLite 设置记录中；导出文件留在用户选定的本地目录。账号复用 `website_accounts`，数据库结构升级到 16，新增昵称、身份核实时间及发布连接的账号关联列，升级前自动保存数据库副本。没有新增第三方依赖；微博 Cookie 仅由 Electron 官方窗口会话管理，不进入业务数据库、备份或图文包。

## 后续迭代顺序

1. **当前：官方网页图文发布。** 已完成本人会话下单条私密图文的填写、上传、提交、回执保存及同账号查看；继续验收真实资源推荐的网盘域名、账号外链能力及资料入口。
2. **热点辅助选题。** 如需要，再配置第三方热搜榜数据源，明确返回的是榜单热度；将候选词与已有资料匹配，相关性不足时不自动生成。付费接口保持显式触发。
3. **网页上传和回执适配已接入。** 已在当前账号完成单图私密发布；后续继续验收真实网盘资源推荐、不同账号、更多图片和平台异常交互。网页适配以当前官方发布器为依据，结构变化时停止并提示处理，不静默猜测选择器。
4. **排期与效果。** 在单条发布稳定后，再扩展账号排期、重复内容提示与实际可取得的效果指标；不预设微博有公开的任意词搜索量或收益归因接口。
