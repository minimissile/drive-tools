# 网盘分享统计

侧边栏的“分享统计”集中查看本人在百度、夸克、UC、迅雷网盘发出的分享。先在“账号管理”完成官方登录及 UID 核验，再点击“同步筛选账号”。使用原有隔离会话，无需填写 Cookie 或额外购买统计服务。

## 能读取哪些数据

| 网盘 | 浏览 | 保存 / 转存 | 下载 |
| --- | --- | --- | --- |
| 百度 | 分享记录实际返回的浏览数 | 实际返回的保存数 | 实际返回的下载数 |
| 夸克 | 分享记录实际返回的浏览数 | 返回时显示 | 返回时显示；受限计数显示为下限 |
| UC | 分享记录返回时显示 | 返回时显示 | 返回时显示 |
| 迅雷 | 实际返回值；“100+”保留为下限 | 返回时显示 | 返回时显示 |

“返回时显示”表示适配器已接入字段，但账号权限、版本或接口可能不提供数值。界面显示“未返回”，不会用 0 填补。真实返回的 0 与未知值分别保存。迅雷若返回完整数值会保留原值，返回受限标记时才显示“100+”。未接入访客身份、IP、地域、UV、下载完成率或推广收益；企业版专用数据看板不包含在个人账号接入中。

百度的下载计数口径是点击下载，并不代表完整下载；浏览量可能包含自己的访问。其他网盘口径也不完全一致，跨链接相加可能重复计算同一人，不能当作独立人数或渠道归因。页面同步只读取认证分享记录，不打开公开分享页；手动“查看分享”可能被网盘计入浏览。

## 同步与历史

- 支持全部已启用且已核验账号、指定网盘或单个账号同步；同账号使用现有操作锁，统计读取最多同时运行两个账号，每账号间隔至少 60 秒。
- 按页完整读取，每次最多 100 页、通常不超过 10,000 条。分页缺失、重复、身份变化或超过上限时，本账号本次结果不落库，保留上次成功快照。其他账号仍可成功。
- 首次同步建立基线，第二次起显示“较上次”快照增量。计数回落、未知或受限值不计算精确增量。增量不代表自然日统计，也不会重复累加累计数。
- 下架或取消的分享可能从远端列表消失。完整同步后，将其放入“已不在列表（历史）”，保留最后的累计值与时间；这不等于确认远端已删除。
- 关闭应用后可离线查看；中断的同步会标为失败。账号 UID 不匹配的缓存不会展示。

## 筛选、资料关联与导出

可以按网盘、账号、状态、分享标题、链接、项目资料标题或拆分路径筛选，并按累计浏览、转存、下载或分享时间排序。汇总卡片计算整个筛选结果，不限于当前页；“已知”及覆盖链接数说明缺失值情况。

“仅项目资料与拆分链接”依据同账号、同本人 UID 和分享 ID 匹配整份副本及拆分项。来源分享不会因 URL 相似而关联为本人资料。关联不代替原有分享有效性核验，也不会自动归档远端其他分享。

CSV 导出当前筛选的全部结果，保留未知、受限值、上次增量和快照时间。链接不含提取码，不导出账号凭据；标题等文本经过公式注入保护。取消保存对话框不会显示导出成功。

## 数据与恢复

首次打开保存 v6 升级前本机一致性快照，再升级到 v7。新增最新快照、上次快照指标及账号同步状态；不改动原资源、选题、效果回填或分享数据。导出备份包含统计历史，恢复后标明需重新登录和同步；旧程序不能直接打开 v7 数据库。

## 接口依据与验证边界

接入复用已有本人分享读取端点：百度 `/share/record`（`vCnt/tCnt/dCnt`）；夸克和 UC 的 `share/mypage/detail`（`click_pv/save_pv/download_pv`）；迅雷 `share/list`（`view_count/restore_count/download_count`）。仅保存经过规范化的字段，未将响应原文落库。

参考：[百度统计口径](https://eyun.baidu.com/knowledge/百度网盘怎么查看自己文件的下载量.html)、[夸克分享管理说明](https://www.quark.cn/documents/help/file-share)、[公开客户端的夸克分享记录结构](https://pkg.go.dev/gitee.com/hefy27/pan-client@v1.0.22/pan/driver/quark#ShareList)、[迅雷官方分享管理前端](https://static-pan.xunlei.com/_nuxt/dist/client/pages/share/pc/index.71ed25f51be5bd935031.js)。这些网页协议没有作为稳定开放统计 API 的承诺，协议变化时会明确报错或显示未返回。
