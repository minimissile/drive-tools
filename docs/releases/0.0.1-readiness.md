# 0.0.1 发布验收记录

更新日期：2026-10-21。本次已发布 macOS Apple Silicon（ARM64）DMG 与更新 ZIP，不支持 Intel Mac。Windows x64 在签名齐备后加入后续版本。按最新要求，交付和发布不以公证为前置条件；未宣称通过公证或 Gatekeeper 验收。

## 版本与历史

- package.json 与锁文件重置到 0.0.1；不重写 Git 源码历史，不删除用户数据。
- 本轮开始时线上发行仓库无旧 Release、无版本标签，无需删除旧记录；现已发布 v0.0.1。
- 本地旧发行产物在发布前暂存至 release-archive，发布和本机安装/升级验收后已按清单删除。当前 release 目录仅保留 0.0.1。
- 旧联调版本文档保存在 docs/development/release-history。旧 0.7.0 无法自动降级到 0.0.1，首次需手动安装；后续正式版递增，不放开降级。

## 普通用户配置

- 正式应用 ID com.panxu.studio；macOS 生产数据位于 Application Support/盘序，开发数据位于 Application Support/盘序开发。Windows 对应各自 AppData 目录。
- 两环境的数据库、会话、设置、恢复位置和缓存分离。未自动迁移或复制旧空间；既有生产数据原位保留。
- 新安装不包含账号、Cookie、API Key、资源、词库或模拟测试记录；使用者自行登录和配置服务。
- 生产使用 dist + dist-desktop，不读取 Vite 或 PANXU_DEV_URL；关闭 DevTools。开发使用 dist-dev 与 HMR，不联网检查更新。
- 正式版默认启用检查更新；下载、付费调用、转存、建链和发布均显式触发；退出时不自动安装更新。
- macOS 更新必须包含同一 Developer ID 签名的 ZIP；Windows 更新必须验证 Authenticode 发行主体。校验不通过禁止发布为正式版。
