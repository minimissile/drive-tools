# 0.0.1 发布验收记录

日期：2026-10-20。本次仅发布 macOS Apple Silicon（ARM64），不支持 Intel Mac。Windows x64 在签名齐备后加入后续版本，不再阻塞 0.0.1。状态：准备中，尚未对外发布。

## 版本与历史

- package.json 与锁文件重置到 0.0.1；不重写 Git 源码历史，不删除用户数据。
- 线上发行仓库 minimissile/drive-tools 当前无 Release、无版本标签，无需删除线上记录。
- 本地旧发行产物移入 release-archive/2026-10-20-before-0.0.1/installers，当前 release 目录重新开始；归档不纳入 Git。
- 旧联调版本文档保存在 docs/development/release-history。旧 0.7.0 无法自动降级到 0.0.1，首次需手动安装；后续正式版递增，不放开降级。

## 普通用户配置

- 正式应用 ID com.panxu.studio；macOS 生产数据位于 Application Support/盘序，开发数据位于 Application Support/盘序开发。Windows 对应各自 AppData 目录。
- 两环境的数据库、会话、设置、恢复位置和缓存分离。未自动迁移或复制旧空间；既有生产数据原位保留。
- 新安装不包含账号、Cookie、API Key、资源、词库或模拟测试记录；使用者自行登录和配置服务。
- 生产使用 dist + dist-desktop，不读取 Vite 或 PANXU_DEV_URL；关闭 DevTools。开发使用 dist-dev 与 HMR，不联网检查更新。
- 正式版默认启用检查更新；下载、付费调用、转存、建链和发布均显式触发；退出时不自动安装更新。
- macOS 更新必须包含同一 Developer ID 签名的 ZIP；Windows 更新必须验证 Authenticode 发行主体。校验不通过禁止发布为正式版。

## 已完成

- 版本重置、生产/开发目录隔离、生产关闭调试工具及开发 URL 覆盖。
- 290 项测试通过；新增环境隔离检查，修复旧数据库测试的版本常量漂移。
- 更新界面与控制器的 5 组隔离回归通过，含版本检查、下载进度、取消、错误重试、损坏包阻止安装和活动任务门槛；系统安装端口为模拟，不能代替真实升级验收。
- PanSou macOS ARM64、Windows x64 组件均由同一固定来源构建，携带许可证、依赖声明与摘要；仅监听回环地址。已撤去本轮不再需要的 Intel 产物。
- 已签名的 ARM64 应用全新用户验收通过：账号、资源、服务密钥与调用记录为空，默认最大化、生产不加载开发 URL、无法打开 DevTools；重启保持本地设置。1440px 与 840px 实际界面已查看。
- macOS 真实升级演练通过：独立应用 ID 的同一 Developer ID 签名副本，经本地更新源从 0.0.0 下载 ZIP、校验、由 Squirrel.Mac 实际安装并自动重启至 0.0.1；保留临时工作空间、设置及升级前快照。没有改动正式安装版或用户数据。正式 GitHub 更新源仍须发布后验收。
- Apple 钥匙串 panxu-notary 已通过真实服务验证；ARM64 应用已签名并提交公证，正在等待 Apple 返回结果。
- 已签名安装包的完整交互回归 24 组通过，覆盖多账号、资源与封面、中文检索、模拟计费查询、500+资源分页、批量处理、三级目录拆分、备份预检和空间恢复；前端错误为 0。测试网盘和付费接口均为模拟响应。同步修正了验收脚本中过时的批量入口与样式选择器。

公证密码、私钥与发布令牌不写入文档、源码或安装包。当前候选产物均位于 release-candidates，不进入正式发布目录。
