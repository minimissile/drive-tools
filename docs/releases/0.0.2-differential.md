# 0.0.1 → 0.0.2 差分下载专项验证

用户明确要求测试差分更新后执行。本次验证真实发行包的下载链，不操作本机已安装的 0.0.2，不将开发工作区代码当作已发布更新，不制作或发布新版本。

## 结果

五个隔离集成场景全部通过，公开 GitHub 的三个只读探测也通过。

| 数据 | 实测 |
| --- | ---: |
| 完整 0.0.2 ZIP | 147,082,667 字节，140.27 MiB |
| 差分 ZIP 数据 | 11,042,150 字节，10.53 MiB |
| 新旧 blockmap | 310,194 字节，0.30 MiB |
| 差分与 blockmap 合计 | 11,352,344 字节，10.83 MiB |
| ZIP 数据减少比例 | 92.49% |
| 含 blockmap 的减少比例 | 92.28%，未计 HTTP 头及 TLS 开销 |
| 成功案 Range 请求 | 91 次 |
| 成功案全量 ZIP 请求 | 0 次 |

成功案重建文件和后续差分所用缓存的 SHA512 均与正式 0.0.2 清单一致。只看下载完成事件或最终哈希不足以证明使用了差分；本次同时检查 Range 请求、零全量请求和实际传输字节，排除了隐藏回退全量的情况。

## 已验证场景

1. 有 0.0.1 旧 ZIP 缓存：实际读取新旧 blockmap、下载变化区间、复用旧文件并重建 0.0.2，SHA512 正确。
2. 没有旧缓存：不尝试差分，下载完整 ZIP 并正确校验。
3. 旧 blockmap 返回 404：差分失败后自动下载完整 ZIP。
4. 差分响应中一个字节被破坏：SHA512 检出错误，自动回退全量并正确校验。
5. 全量 ZIP 中一个字节被破坏：拒绝该包，不进入原生安装交接。

## 公开 GitHub 探测

- 匿名读取 v0.0.1、v0.0.2 的 ZIP blockmap，均返回 200，内容与对应本地发行附件逐字节一致。
- 对正式 v0.0.2 ZIP 请求 `bytes=0-65535`，返回 206 和 65,536 字节，内容与正式 ZIP 对应范围一致。
- 使用本机已有代理完成只读请求，未使用 GitHub Token。这里只探测有限数据，不代表完整公网下载、任意网络或代理环境均已验收。

## 方法和边界

使用锁定的 `electron-updater 6.8.9`，保留真实 `checkForUpdates → downloadUpdate → MacUpdater.doDownloadUpdate → executeDownload → differentialDownloadInstaller`、GitHubProvider 路径计算、差分规划、重建、缓存及 SHA512 校验。没有打开会改变回退行为的上游测试开关。

GitHub 元数据及下载来源在集成测试中映射到本机 HTTP 服务，使用真实发布 ZIP 和 blockmap 字节。HTTP 传输从 Electron net 适配为 Node HTTP，保留上游下载和校验逻辑；在最终 Squirrel.Mac 安装交接前停止。每个场景使用全新临时缓存，结束后关闭 HTTP 服务并清理临时目录，没有启动额外桌面实例。

因此，本次证明的是**隔离下载链可正确差分、重建、校验及回退**，并补充公开 GitHub blockmap / Range 条件的只读证据；没有验证完整 Electron / CDN 重定向下载、原生签名验证、安装或重启，也不代表开发工作区的最新功能已包含在已发布版本中。

通过 DMG 首次安装或清空更新缓存后，首次应用内升级仍可能下载全量包。后续差分要求保留上次更新的 ZIP 缓存及可用 blockmap，不承诺每一版都能达到本次节省比例。

## 复现与证据

仅在获得本次范围的自动化测试授权后执行：

```sh
node scripts/verify-differential-update.mjs 0.0.1 0.0.2
```

命令默认只访问回环地址，要求 `release/<version>` 中已有对应正式 ZIP、blockmap 和清单；不打包、不启动 UI、不执行安装。`PANXU_QA_DIR` 可指定证据目录。

- `release-evidence/0.0.2/differential/result.json`：五个场景的传输计数、校验和回退结果，以及 UTC 执行时间。
- `release-evidence/0.0.2/differential/github-probe.json`：公开响应状态、字节数及内容核对结果。
- 同目录的 `github-*.bin`：两份公开 blockmap 及 64 KiB 的 ZIP 区间响应。
