# 盘序 0.0.4

修复 0.0.3 安装包遗漏生产传递依赖、导致主进程启动失败的问题，保留其资源库、网盘操作、文章及问答改进和简体中文裁剪。

- 补齐更新器等模块的完整运行依赖；发行包增加递归依赖及模块入口检查，缺失依赖时阻止发布。
- 正式打包入口拒绝使用符号链接形式的依赖目录，避免依赖收集不完整。
- 保留资源档案“拆分为多个链接”的图标修复。

0.0.3 已撤回稳定通道，其已公开附件保持原样。使用 0.0.2 的用户可通过“连接与设置 → 备份与更新”升级到本版；具备旧 ZIP 缓存时优先差分下载，条件不足时回退全量，校验后重启安装。若已安装的 0.0.3 无法启动，请退出后从本版发布页安装 DMG，保留原工作空间。

本版继续提供 macOS Apple Silicon（ARM64）签名公证 DMG 与自动更新 ZIP。完整交付与本机升级结果见发布记录；不自动执行真实网盘写入、内容发布或付费请求。
