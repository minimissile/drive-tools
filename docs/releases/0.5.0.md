盘序 0.5.0 增加 UC 和迅雷网盘适配。

- 账号管理、链接录入、CSV批量录入、同盘转存和三级目录树扩展到百度、夸克、UC、迅雷。
- UC 使用独立隔离会话、UC分享访问令牌和本人分享记录核验；迅雷从官方隔离窗口衔接本账号登录令牌，使用系统加密保存，支持已有刷新令牌的续期。
- 迅雷目录支持游标分页；分页缺失、重复或超限时阻止继续操作。
- 账号验证要求会暂停同账号任务。明确拒绝的写入可在处理后恢复；提交后核验失败或响应未知时只查本人已有结果，避免重复转存或建链。
- 来源链接与本人链接仍严格区分。复制、拆分及导出继续核验本人UID、目标文件和本人分享记录。

数据库从v5升级到v6前自动保存本机一致性快照，已有资源及版本更新功能保留。UC/迅雷为网页协议适配，需要本人完成官方登录及真实资料验收；接口变化、人工验证和账号配额会影响可用性。此联调包未签名，不会自动安装未签名更新。


### 2026-10-16 · 搜索运营

- 新增搜索运营工作台，可从现有词池或手工关键词建立选题，并按待关联、待创作与审阅、已发布查看进度。
- 选题可以关联本人整份资料或已核验的拆分资料；原资料拆分功能完整保留，结果中增加“用于创作”。
- 教程可保存软件版本、适用系统和本人操作依据，复用内容工作室的本地模板、AI、草稿历史和人工审阅。
- 发布准备展示并核验文章实际关联的子链接，保存新稿时保留关联，过期分享版本仍需要重新审阅。
- 发布效果支持人工录入周期、来源、阅读、转存、有效拉新与已结算人民币，并可导出CSV。账号汇总单列；未知与零值分别保存，累计数据不自动相加。
- 已发布文章可查看资料、链接与草稿版本的维护提示。首次打开本开发版将保存v6升级前快照，旧程序不能直接读取升级后的数据库。
