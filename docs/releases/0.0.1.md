# 盘序 0.0.1

首个正式发行系列，从 0.0.1 开始计数。

本次提供 macOS Apple Silicon（ARM64）DMG 和自动更新 ZIP，使用 Developer ID Application 签名。Apple 公证尚未完成，本次按明确要求不等待公证结果，首次打开可能遇到 macOS 安全提示。Windows 将在签名和实机验收完成后加入后续版本；本次不提供 Intel Mac 安装包。

- 管理多个网盘账号，整理资源、同盘转存并核验本人分享。
- 支持批量处理、可视化目录拆分及文件夹、图片和 TXT 素材批量插入。
- 本地资源知识库、5118 查询归档、AI 选题与内容工作室，连接浏览器准备分发。
- 开发版和正式版使用独立工作空间；全新安装不携带账号、密钥、资源或测试记录。
- 正式版默认检查更新，下载及重启安装由用户触发；安装前核对活动任务并保存本机快照。

旧 0.x 联调版属于内部开发历史。其版本号高于 0.0.1，不能通过自动更新降级；需退出旧版后手动安装。用户数据不随版本号重置而删除。后续正式版本按 0.0.2、0.0.3 等递增。

网盘兼容接口、各平台账号权限及套餐限制可能因服务方变化而调整。外部付费查询、生成、转存及发布都需要用户显式操作。
