# 0.0.4 生产恢复与发布检查记录

日期：2026-10-29。本版修复 0.0.3 发行包遗漏传递运行时依赖导致的启动故障，仅提供 macOS Apple Silicon（ARM64）发行包。0.0.4 已公开为最新稳定版本，并完成真实 0.0.2 → 0.0.4 公网差分下载、原生安装、重启及主窗口检查，原生产工作空间保留。此前故障与稳定通道撤回情况见 [0.0.3 记录](0.0.3-readiness.md)。

## 源码与修复

- 本轮构建源码提交为 `3ad40035a921f487d0a3b025d3cf1db39534ca78`。
- 源码继承 0.0.3 的资源库、网盘查看与删除、文章及弹窗操作改动，保留 `FolderTree` 菜单图标与简体中文语言资源裁剪。
- 隔离构建的依赖改用 APFS 克隆得到的真实 `node_modules` 目录，替代触发 0.0.3 依赖收集缺失的符号链接结构。
- `package-release` 新增检查，拒绝以 `node_modules` 符号链接执行发行打包。
- 新增生产 ASAR 的递归必需依赖检查，并校验 `main` 与 unpacked 文件入口，避免仅核对应用源码和签名而遗漏运行时依赖。
- 最终包的 133 个生产构建文件检查通过；92 张源码映射中的 455 个源码文件、490 次引用及 679 个构建输入均与 Git 提交一致。
- 最终 ZIP 为 134,277,556 字节，DMG 为 134,920,273 字节。

五个场景包括有旧缓存时差分重建成功、无旧缓存时回退全量、旧 blockmap 返回 404 时回退全量、Range 内容损坏时回退全量，以及全量包损坏时由 SHA512 校验拒绝。所有成功下载或回退所得的 ZIP 均通过 SHA512 校验；损坏全量包被拒绝，未触发原生安装。

专项通过本机回环 HTTP 服务复用真实 macOS 更新器的下载、重建、校验和回退链。该隔离专项本身没有执行真实 GitHub 公网下载或原生安装；后续生产下载与安装结果另列如下。以上传输量不含 HTTP 开销，不承诺每次升级都取得相同比例。
