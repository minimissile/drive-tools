# 盘序 0.0.3

将最新开发改动交付到生产版，继续提供 macOS Apple Silicon（ARM64）DMG 和自动更新 ZIP，沿用原应用标识、发行身份及生产工作空间。

- 资源库显示文件类型图标，优化顶部、筛选与行操作布局；名称相似度达到80%时提醒已有资源，同类型网盘的重复资源在保存时拦截。
- 统一资源库及文章配套资源的网盘查看入口，按账号与文件 ID 定位本人副本；他人及未核验资源保持只读。
- 增加本地资源删除及本人网盘文件删除流程，展示涉及副本及关联内容，保留进度、未知结果和恢复入口，避免重复提交；仍被什么值得买文章引用的资源会阻止删除。
- 简化网盘文件操作、分享、文章发布及回执处理的重复确认步骤；保留必要的身份、权限、参数、任务和实际结果校验。
- 优化待处理记录解除、草稿恢复及编辑操作，问答支持直接保存或保存并审核。
- 安装包的 Electron 语言资源仅保留简体中文，减少安装与更新文件体积。
- 补齐资源档案菜单中“拆分为多个链接”的图标，与目录拆分入口保持一致。

通过应用内更新入口从 0.0.2 升级；具备旧 ZIP 缓存及可用网络条件时优先差分下载，条件不足时回退全量，最终仍需重启安装完整签名应用。差分不直接加载开发目录，不保证各版本节省比例相同。

真实网盘查看、写入、删除及业务中断恢复的验收范围见各功能文档；本次发布不自动执行外部业务或付费请求。签名、公证、附件校验、差分验证及本机升级结果将单独记录。
