# 盘序 0.0.2

本次继续提供 macOS Apple Silicon（ARM64）的 DMG 安装包和自动更新 ZIP，不提供 Intel Mac 或 Windows 安装包。沿用 0.0.1 的应用标识、发行主体和生产工作空间；已有 0.0.1 用户可通过应用内更新入口升级，安装前会检查活动任务并保存本机快照。

- 统一账号与浏览器环境管理，可配置内置浏览器或已有比特环境，集中查看登录状态、环境绑定和任务情况。
- 扩展网盘文件管理及分享目录选择，支持文件操作、素材插入和内容变更后的清单更新。
- 新增公共内容采集、知乎多号运营、微博单条数据统计，以及什么值得买文章导入、整理、审阅与分发流程。
- 内容分发按平台组织任务，保留提交进度、回执和待核对结果，避免不明结果下重复提交。
- 设置页回显已保存 API Key 的脱敏信息，支持更换、取消和读取失败重试，密钥继续在本机加密保存。
- 资源封面自动转为 200KB 以内的 WebP；兼容历史 PNG 封面、备份恢复、笔记及内容导出，优化资源库筛选布局。

平台能力取决于账号权限、服务方接口及网络状况，各业务的真实验收范围见项目功能文档。查询、AI 生成、网盘写入和内容发布仍由用户显式触发。本次发布未运行自动化功能测试，不将历史验收记录视为本版本全量回归结果。

签名、公证及附件完整性状态以本版本发布记录为准；未通过默认发行校验前不公开发布。旧内部联调版本的版本号高于 0.0.2，首次仍需手动安装，不能自动降级。
