## 实测边界

- 本轮没有运行后端行为的自动化测试；全量读取、快照哈希、并发保护、空版本输出、URL 校验和脱敏依据类型与独立源码审查，不能将其写成已通过运行时测试。
- 复制、打开、导出和登记的手动流程使用模拟端口；没有实际写系统剪贴板、创建文件或打开远端文档来宣称完整平台接入成功。
- 没有登录真实平台账号，没有写入远端内容，没有更改公开权限，没有验证未登录读者能打开真实分享链接。Cookie 名称与登录检测仍需真实账号核验；平台页面变化或组织策略可能影响会话识别。
- 三个平台当前均为辅助发布：用户在官方平台完成粘贴/导入、保存、分享权限设置，再登记链接。没有后台一键自动写入或自动同步。自动 API 发布需要对应应用资格、授权与适配。
- 石墨公开分享还受账号套餐限制。登录状态、本地登记版本一致不等于云端文档已实际同步或任何人可读。
- 刷新失败保留旧内容的行为已检查公共读取 hook 源码，尚未实际触发带旧数据的刷新故障；没有把首次读取失败截图当作该状态的证据。

## 验收路径

1. 在源码开发窗口选择「资源清单」，按资源库已有分类新建清单，核对预览与排除项。
2. 在「账号管理 → 其他账号」选择目标文档平台、添加并扫码登录，再检查本机会话。
3. 返回清单，准备内容，复制或导出，在关联账号的官方窗口完成粘贴/导入与分享设置。
4. 用目标读者身份检查分享链接，再回填该链接并登记交接版本。
5. 修改资源后刷新清单，查看新增、变化与移除项，准备更新原文档并登记新版本。
