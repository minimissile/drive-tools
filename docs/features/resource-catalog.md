# 资源清单

## 目标与范围

资源库菜单下提供「资源清单」。运营者按资源库分类整理一份持续维护的目录，可直接发布到盘序落地页站点，也可通过飞书、腾讯文档或石墨文档的分享链接提供给读者。

当前源码支持：清单创建、编辑与保存；全量分类聚合；有效本人分享筛选；公开内容预览；落地页站点发布、更新与撤下；复制富文本与文件导出；关联其他账号中的文档平台登录；官方编辑器交接；发布链接与版本登记；本地变化比较；已有文档更新交接；归档维护。

## 落地页站点（2026-11-04）

在一份清单的「落地页站点」页签点击「发布到落地页站点」，复用「连接与设置」中的固定入口服务，无需文档账号。公开范围就在操作区说明，点击发布即可，不额外增加核对复选框。首次生成 `https://panxu.site/c/<短码>`，后续更新、撤下和重新发布沿用同一地址；「读取站点状态」可核对云端现状，未知提交保留原请求供重试。

清单配置、资源和分享变化后显示与线上快照的差异，更新由操作者触发，不在切页和读取时自动发布。已有合格单资源说明页会关联「查看内容介绍」；没有单资源正文的条目仍可发布为清单资源，不自动调用AI。公开站点的 `/catalogs` 汇总已发布清单，单份清单支持分类、关键词和每页50条分页，并进入首页入口、站点地图和IndexNow队列。搜索平台是否收录另行观察。

撤下是直接、可恢复的操作，访客网址返回410；清单地址与版本记录保留。归档不自动撤下站点或文档平台内容，删除本地清单前需先撤下站点并处理待核对操作。本地分享读取失败不阻止撤下，站点状态与本地内容差异分别处理。首次发布禁止空清单，已有清单允许更新为0条，移除旧分享并显示更新提示；空清单不参与索引。

初次接入时云端已部署，桌面后端按开发约定等待用户点击「应用更新并重启」，当时没有发布真实清单；协议、人工查看与实测边界见[接入验收](../reviews/resource-catalog-site-2026-11-04.md)。用户后续已应用更新并要求发布，首份[求职与个人成长资源清单](https://panxu.site/c/dbedf7b723e3468e)现已公开，包含18项资源。

## 公开清单排版（2026-11-04）

公开清单采用紧凑目录行：左侧分类显示资源总量，右侧搜索与结果列表沿统一基线排列。资源标题、分类与网盘信息集中在内容列，打开网盘按钮固定在操作列；已有资源介绍链接保持可见。多分享保留一个直接入口，其余链接通过原生折叠区按需展开，提取码跟随对应分享显示。

样式维护在 `cloudflare/resource-links/src/catalog-style.ts`，由清单页面及首页清单入口复用。沿用站点白色、系统字体和品牌蓝，保留原搜索、分类、分页、SSR及搜索元数据规则。实际18项清单的新样式已部署；人工查看和部署证据见[样式调整记录](../reviews/resource-catalog-style-2026-11-04.md)。

## AI生成与条目维护（2026-11-05）

点击“AI生成清单”，描述主题、受众、需要包含和排除的内容，可选择资源分类与最多选入数量（默认50，最多2000项）。程序从完整的本地资源表保存候选快照，不受资源库界面500条快照限制；使用全局“资源分析”模型逐批判断相关性，再为按相关度选入的条目生成标题与介绍。结果通过“编辑并保存清单”打开编辑器，由用户保存，不自动发布或创建分享。

AI实际请求会发送用户需求及脱敏后的资源ID、名称、分类、标签和资源说明；每项说明最多2000字、标签最多30个，超出部分不参与判断。标题/介绍阶段只使用按上下文预算选取的最多40项元数据样例，每项说明最多300字，并向模型标明样例数量与选入总数。没有读取网盘文件正文、账号对象、个人知识笔记、分享链接、提取码或凭据。使用AI不表示数据始终留在本机；界面明确提示请求范围和可能多次计费。

调用复用AiService的OpenRouter凭据、模型设置、预算预占、实际费用与未知费用记录。每批最多30项，并按模型上下文及输入字节预算缩小；输出必须逐一返回当前批次的真实ID，不接受遗漏、重复或虚构资源。生成记录按requestId保存，已完成结果可复用；暂停或关闭只停止后续批次，正在进行的请求仍会完成。重新打开只读取进度，不自动付费续跑；调用失败或进程中断后，明确点击“重试（可能再次计费）”才会重新处理未保存批次。

清单有两种收录方式：原“按分类自动收录”继续跟随整类资源；新增“手动选取”维护固定资源集合。编辑器可搜索本地库并添加、移除条目，覆盖本清单中的标题、分类、说明和标签，恢复资源库原内容，或上下调整顺序。新增清单默认手动选取；旧分类清单可转换当前预览及排除项为手动集合。编辑采用窗口、工作空间与清单隔离暂存，保存继续校验revision，其他窗口的改动不会被静默覆盖。

清单列表支持名称/分类查询，条目预览支持内容检索；清单可编辑、归档、恢复及删除。移除条目不删除原资源或网盘文件。已有站点页面或待核对发布时仍需先处理站点状态再删除本地记录。保存后的预览、导出和发布继续只纳入有效本人分享，已删除或不能公开的所选资源会显示排除原因；手动选入并不绕过分享核验。站点仍显式发布/更新并保留原地址。

本轮源码已完成，后端按项目约定等待用户点击“应用更新并重启”。没有触发真实AI调用或新发布线上清单，人工内存界面与检查边界见[本轮记录](../reviews/resource-catalog-ai-2026-11-05.md)。

## 合集内容删除（2026-11-05）

在“资源预览”中，每行可直接“删除”，也可勾选后“删除所选”。全选仅针对当前搜索结果的当前页，勾选跨页保留，单次最多2000项；切换清单或内容变化后重置选择。未纳入公开内容的失效/缺失条目也可逐项移除。归档清单保持只读，需先恢复维护。

删除只改变本清单：手动选取删除对应entries，保留其他条目的覆盖内容与顺序；分类自动收录使用excludedResourceIds持续排除，刷新不会重新加入，并继续自动收录其他符合分类的资源。排除集合最多100000项，达到上限明确提示，不截断旧记录。原资源库、网盘文件和其他清单均保留。

当前工作区保留上一次删除的“撤销删除”，恢复前校验revision；其他窗口已修改时不覆盖新配置。离开清单后，手动集合可在编辑器重新添加资源；分类集合可通过“恢复全部已删除条目”并保存，清除排除标记，仍按当前分类和分享条件生成预览。普通保存及旧暂存缺省保留排除集合，过期编辑继续被revision拦截。

删除通过独立removeItems IPC触发，后端进行参数、成员、归档和并发校验；完成新快照读取后才保存配置。成功后立即显示服务端返回内容，后续读取失败保留结果并提示“变更已保存”，不诱导重复删除。主动删除标记不混入分享失效列表，也不进入公开payload；只按实际公开内容变化计算待更新状态。

删除不会自动改动已发布页面、不可变待核对发布请求或文档交接历史。待核对的原发布可能仍含旧条目，需要先核对原操作，再显式更新当前内容；清单可本地清空，已有发布允许更新为0项。源码与人工内存查看边界见[删除记录](../reviews/resource-catalog-delete-2026-11-05.md)。

## 可行性与发布方式

飞书开放平台的文档 API 需要应用权限与 access token；腾讯文档开放平台需独立授权；石墨官方 SDK 是企业集成体系。三个平台的网页登录均不等于开放接口授权。详细官方证据见 resource-catalog-platform-research.md。

首版采用适用于个人账号的辅助发布：生成清单 → 复制内容/导出文件 → 在关联账号的官方窗口创建或打开文档 → 用户粘贴/导入并设置可访问权限 → 回填分享链接并确认版本。界面明确标为「发布交接」和「登记发布」，打开窗口或复制成功不代表云端发布成功。不会调用未经核实的私有接口或自动改公开权限。开放 API 自动同步留给具备凭据的后续适配，网页登录不显示为自动发布授权。

## 数据与状态

- 清单保存标题、分类、介绍、展示选项、排序等本地配置，按工作空间隔离。
- 资源来源从数据库按分类读取全部资源，不能使用最多 500 条的首页快照；预览分页不限制导出总量。
- 对外内容只含已核实的本人分享及必要的访问说明；无分享、失效与未验证项给出排除提示。禁止导出来源地址、账号身份、内部路径和凭据。
- 交接时保存不可变快照。发布回执关联该快照，不能把交接后新增的资源算成已发布。
- 同一清单可分别维护多平台发布记录；每条记录含平台、关联账号、文档链接、登记版本与时间。
- 资源增加、删除、标题/简介/链接等公开内容改变后显示待更新；打开原文档交接，完成后再登记新版本。保留历史记录。
- 归档只影响本地维护状态，不删除远端文档。删除本地清单不暗示远端撤回。

## 架构

shared/resource-catalog.ts 定义类型和规则；core/resource-catalog.ts 负责聚合、快照、比较与维护；core/ipc/resource-catalog.ts 校验传输参数；AppService 只组装依赖。前端通过 src/api/client.ts 调用，领域组件及 hooks 放在 src/resource-catalog。

文档平台登录扩展现有 WebsiteAccounts 和隔离浏览器环境，不新增第二套账号系统。文档地址须校验 HTTPS 与平台官方域名。身份检测保守处理，不能用存在 Cookie 冒充已核实用户身份。
