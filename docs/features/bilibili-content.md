# 哔哩哔哩内容操作

## 目标与入口

工作台新增“哔哩哔哩内容操作”，集中处理账号连接、视频投稿、图文动态和专栏文章。账号共用“账号管理 → 其他账号”；本地视频继续复用内容工作室的 Remotion/FFmpeg 队列和每周热门配乐缓存，不为 B 站另建制作引擎或保存 TikHub Key。

首轮业务流程为：接入官网账号 → 选择真实资源与已有成片 → 编辑保存稿件 → 预览材料和待补项目 → 在该账号的官网编辑器填写投稿 → 记录官网结果链接。网页会话与开放平台授权分开，当前不要求另行申请开发者应用。

## 功能范围

| 功能 | 本轮实现目标 | 成功依据 |
| --- | --- | --- |
| 账号连接 | 独立内置浏览器扫码登录，已有 Bit 环境可核验身份 | 官方 nav 接口返回已登录 UID 和昵称；Cookie 存在不算身份通过 |
| 视频投稿 | 关联已完成的本地视频、封面、标题、简介和标签 | 本地素材完整，官网控件实际读回，上传选择状态单独报告 |
| 图文动态 | 编辑动态正文，预览真实资源或视频封面，打开并填写官网动态编辑器 | 文字和图片分别报告是否填入，未完成的项目保留待处理 |
| 专栏文章 | 编辑长文、预览配图并准备官网专栏稿件 | 使用现行编辑器；标题、正文与配图逐项核对 |
| 本地稿件 | 独立保存、恢复、类型切换、版本检查和文案导出 | 刷新/重开仍可恢复；旧版本不能覆盖已更新稿件 |
| 结果记录 | 保存匹配类型的官网详情链接 | 标记“待核实”，不把手工输入链接当成已发布证明 |

“本地草稿”“官网已填写/部分填写”“发布结果待核实”分别记录。打开网页、文件已选入、输入框有字均不代表发布成功。当前准备动作上传所选素材并填写官网编辑器，最终提交仍在官网完成，应用不点击发布、保存远程草稿或重复提交。

后续可扩展本人投稿扫描、审核状态同步和播放/互动数据复盘；这些不属于本轮已经验收的能力，不显示虚构统计。

## 操作与账号

首次连接可在内容页直接创建 B 站账号并打开官网登录窗口。用户扫码或完成平台验证后，明确点击核验身份。内置账号会话使用已有环境隔离机制，关联的 UID、昵称来自当前会话；错号、重复身份和环境变化沿用统一账号规则。任何凭据均不回显、不写入稿件或前端暂存。

每个窗口的未保存输入按工作空间、账号、资源及稿件区分，离开页面仍可恢复。明确保存后进入后台稿件库，远端账号检查、素材上传和官网填写均不放入自动读取 hook。异步返回不覆盖已经切换的账号或资源。

## 复用边界

- `shared/bilibili.ts`：稿件、预览、官网填写回执和 IPC 契约。
- `core/bilibili`：官网身份解释、本地稿件及素材归属检查；不接受任意前端文件路径。
- `desktop/bilibili-session.ts`：在原账号会话中核实官网身份。
- `desktop/bilibili-content.ts`：打开官方编辑器并读取/填写控件，逐项返回实际结果；不提交发布。
- `src/bilibili`：内容工作区；通用展示通过公共控件，业务请求通过类型化 IPC。
- 已完成的视频、封面和本地音乐复用原有媒体归档，不重复渲染、不为打开 B 站页面请求热歌。

## 官网要求与限制

当前入口：[视频投稿](https://member.bilibili.com/platform/upload/video/frame)、[动态](https://t.bilibili.com/)、[专栏编辑器](https://member.bilibili.com/york/read-editor)。旧版专栏编辑器已经下线，不作为正式流程入口。

官方开放平台提供视频和专栏管理能力，但需要身份审核、应用凭据及用户授权，不能把网页登录会话当成已经取得开放平台权限。[官方状态码文档](https://open.bilibili.com/doc/4/8673959e-f7bb-56e6-6e68-d225f971b81b)明确视频标题超过 80 字符、等级不足、投稿频率和图片验证等可能阻挡；[文章提交文档](https://open.bilibili.com/doc/4/b14b77b6-8889-8c8b-2e83-17c5a4c550fb)的专栏标题和字数属于 API 口径，网页最终要求仍以当前账号编辑器为准。

资源文案默认不插入网盘链接或提取码。[社区公约“违规推广”](https://member.bilibili.com/studio/convention/content?index=2-9&navhide=1)涉及恶意营销、不符合推广流程，以及可能引起争议或损害用户利益的导流、营销、交易转化用途网盘链接/二维码；不能据此推定所有网盘链接一律禁止，也不能默认任何链接均可发布。按具体稿件、承载位置和账号能力核查。
