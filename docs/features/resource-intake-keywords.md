# 资源入库：检索流量词

录入资源时，填写基本信息后点击“下一步：检索流量词”。每次可输入最多 5 个搜索词，用换行或逗号分隔。点击“检索流量词”后，结果会填入候选关键词框。已有资源可通过“编辑资料”进入这一步增删关键词，也可以留空继续。

| 渠道 | 读取方式 |
| --- | --- |
| 百度搜索 | 自动读取公开下拉联想和已出现的“大家还在搜”“相关搜索”。模块缺失或平台要求验证时，保留其他来源的候选并提示。 |
| [5118 关键词挖掘](https://ci.5118.com/) | 自动查询使用按工作空间保存的独立会话，读取官网免费公开结果。可打开同一内置浏览器完成登录后继续检索。 |
| 百度营销关键词规划师 | 复用「账号管理 → 其他账号」里的百度营销登录会话。页面显示账号是否可用，点击检索才查询拓词。会话失效时提示回账号管理检查，仍保留公开来源结果。 |

录入页左右两栏各占一半，左侧检索、右侧编辑。候选关键词框从内容区顶部延伸到底部保存栏上方，长列表可在框内滚动。每行一个词，粘贴或离开输入框时自动去除每行首尾空格。每次检索先清空候选框，再填入本轮去重后的结果。检索失败时显示错误，候选框保持为空。最多 100 个保留词随资源或草稿保存，搜索词和未保存的编辑按原有资源表单暂存。

点击「检查全部来源」可统一检查已有百度营销登录会话与公开检索页面，保留候选框的编辑内容。检查页面可访问后，实际取词仍以检索返回为准。查询区按来源显示状态图标。百度营销先显示账号可用状态，百度搜索及5118在检索后显示本轮可用、部分可用、需登录、无结果或失败状态。具体原因可展开「查看来源提示」。搜索词旁展示资源标题，可直接选中文字或点击复制。

资源级流量词与普通标签独立。显式生成或优化落地页时，保留的相关词可作为标题、摘要的候选表达；它们不代表搜索量或正文证据，不会据此自动生成或发布多个页面。

自有资源从检索步骤直接入库；转存型资源仍需明确选择文件。数据库由 v42 升至 v43，给老资源默认空列表；兼容调用方不提交此字段时保留旧词列表。开发后台由用户点击“应用更新并重启”后加载。可用性以平台官网和实际运行环境为准。

浏览器在首次使用后保留后台窗口，检索和来源检查复用同一会话。手动关闭查看窗口会回到后台，退出应用时释放窗口。工作空间之间隔离登录会话。

进入「校验与转存」后自动读取分享目录，回到这一步时保留已读目录和所选文件。百度分享目录、链接检查与「打开官方分享」复用同一读取页面，重复打开不会重新加载，读取从页面结构就绪后继续。读取失败保留错误和重试入口，转存仍由保存按钮明确启动。
