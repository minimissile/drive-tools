# 资源图文营销

入口：侧栏“工作空间 → 资源图文营销”，或“工作台 → 通用内容操作 → 资源图文营销”。当前为源码试用功能，不另行打包或升版。

## 使用流程

1. 选择夸克、百度、UC、迅雷中的已有资源及本人副本。需要转存时，点击“录入并转存资源”进入原录入流程；沿用现有同盘转存、文件选择、本人分享与归属核验。
2. 编辑封面标题、亮点、已核实的资源详情、适合人群，粘贴网盘已生成的中文口令。口令独立于四位提取码，原样保存，不在工具内申请或生成，也不接推广服务商。
3. 选择“在网盘 App 搜索口令”或“复制作品链接后打开 App”，以及电光蓝·荧光黄或朱砂红·奶油纸排版。封面可用大字构图；资源已设置原封面时，还可选原封面海报。标题支持换行，填写标题中的原文可高亮重点词，建议8–18字；亮点区单独填写简短、已确认的用途或特点。默认制作封面、详情、获取方式三张1080×1440图片；点击预览可以查看大图，Esc关闭。
4. 保存图文任务。表单按工作空间、资源/任务和窗口暂存，切页、刷新可恢复；尚未完成的标题和平台选择也保留。正式任务写入SQLite，其他工作台可读取，旧版本并发编辑会被拒绝。
5. 点击“核验并导出三张图”，显式读取本人分享检查有效性，然后选择本地目录。导出包含编号PNG、所选平台文案及版本与图片摘要信息；取消目录选择不记为成功。口令的真实App识别结果仍需用户自行核对。
6. 在平台发布区选择抖音、快手或小红书，复制文案并打开内置浏览器。用户在官网核对账号、上传图片、设置可见范围及AI声明并提交；工具不自动点击官网发布按钮。
7. 粘贴实际作品地址，记录“已提交 · 待审核”；确认公开后再记录“已公开”。打开官网本身仅记录已交接，不算提交或发布。修改内容产生新版本，须重新导出，旧版本发布历史保留。

## 登录会话与当前边界

每个工作空间、每个平台使用固定的持久Chromium分区。关闭官网窗口时写回站点存储及Cookie，同平台后续打开复用原会话；已有编辑页打开时直接唤起，不重载。当前每个平台使用一份会话，尚无多账号切换、UID自动识别或登录有效性探测，用户必须在官网核对实际账号。登录可由平台主动失效，工具不会伪造已登录状态。

图片采用本地Canvas排版，支持资源已有封面；不调用付费文字、图片或视频模型。缺少口令或资源详情、图片文字过长、未保存修改及本人分享变化会阻止相应导出或交付。工具不会把来源分享带入导出，不因填写口令就宣称它已与网盘建立绑定。

2026-11-01更新了三页海报：封面放大资源名与原图，提供醒目重点词与卖点区；详情按内容条目排版，领取页突出三步和完整口令。新任务不自动将摘要中的作者、来源网址填进卖点。新版排版有独立素材版本，旧任务打开后需重新保存并导出。标题使用本地[得意黑字体](https://github.com/atelier-anchor/smiley-sans)，许可证随应用提供；正文与中文口令继续用系统字体。版式以缩略图可读性为目标，实际停留与转化效果需发布后根据平台数据评估。

本次封面调整完成TypeScript源码检查与手动视觉核对，未自动运行测试；下方测试结果为首版工作流记录。

任务保存在独立的SQLite设置记录中，保留资源ID、副本ID、本人分享及版本。素材预览与导出使用相同画布；导出PNG由本地生成。首版任务选择显示当前副本最近100条记录，已选旧任务可独立找回；现有转存、内容工作室、资源库和其他分发流程保持独立。

## 首版工作流验证记录

- TypeScript与差异静态检查；6项隔离数据库业务测试，覆盖中文口令原文、并发版本、真实PNG文件导出、取消及失败、分享变化拦截、平台链接校验、交接状态、跨副本历史与旧任务找回。
- 复用8070源码开发后台，通过`test:session`创建并按窗口ID操作，验证真实本地保存、暂存/未完成表单刷新恢复、三页画布、平台文案、领取方式、版本、发布门槛及桌面布局。测试记录仅在本轮窗口创建并清理。
- 导出界面另用只作用于本轮页面图文IPC的内存模拟验证；模拟的是网盘核验和目录选择，不覆盖其他窗口、进程级fetch或共享网络。实际Canvas生成的三张PNG和平台文案已写入临时目录。
- 桌面查看1440×900及1366×768，实际后台13项交互检查与页面范围模拟15项检查通过；另确认保存等待期间锁定表单和任务切换、读取失败后重试恢复。未进行移动端验收、真实账号扫码登录、登录过期恢复、真实口令识别、远端转存/建链、付费生成或对外发布。持久分区代码接入不等于三平台真实登录保留已经验收。
