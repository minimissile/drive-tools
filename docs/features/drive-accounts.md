# 网盘账号管理

更新：2026-10-31。当前源码开发版功能。

账号页保留白色主题与公共控件，将账号数量、登录状态、搜索和新增操作集中到一个工具栏。列表按网盘筛选，账号身份、UID、副本数量和核验时间集中展示；容量、刷新、设置及删除操作按列对齐。容量来源、上次数据与读取失败分别保留，不因页面打开自动请求网盘。

标题与“网盘账号 / 其他账号”切换共用一行，移除重复的页面说明，缩小账号页顶部留白。两类账号共用紧凑工具栏、平台筛选和列表密度；新增表单按需展开，筛选空态使用公共紧凑状态组件。

## 百度网盘后台环境

新增百度账号时选择“内置浏览器”或“比特指纹浏览器”。指纹方式需要先选择独立配置，读取并核对真实 UID 与出口，再创建账号；浏览器方式和具体配置在创建后固定。已有账号保留原方式，不再提供切换、改绑或解除入口。指纹账号仍可打开原环境登录、转为后台、核验登录及重新核对同一环境的信息。日常操作统一在固定配置中后台发起。具体要求与真实联调边界见[百度网盘比特后台环境](baidu-headless-browser.md)。

## 其他账号

其他账号按平台、昵称、备注或UID筛选，身份、浏览器环境与操作按列对齐。登录、检查登录与移除保留直接入口；统计、发布、答题资格、环境关联和修改备注等操作收进对应账号的更多菜单，原有的平台能力限制继续保留。新增账号独立为领域表单，平台筛选不会覆盖正在编辑的新账号平台；什么值得买仍限制单账号，文档平台仍使用独立内置浏览器。

新增百度贴吧的官方登录和身份检查。贴吧、知道、微博和知乎新增账号默认关联指纹浏览器；百度营销默认内置，什么值得买及三类文档平台仍使用内置方式。原账号保持已有环境，列表标明内置或指纹方式。知道的采集、资格查询、自动答题和批量问答上传按关联环境运行，具体路径与本轮验证边界见[浏览器环境](browser-environments.md#2026-10-31--贴吧及知道指纹方式)。

微博、知乎、百度知道、百度营销、飞书、腾讯文档、石墨文档及其他发布平台共27个平台图标从官网获取后保存在本地，列表和平台选项复用 `src/platforms/PlatformIcon.tsx`。查看账号不联网加载图标，未来新增平台使用 `scripts/sync-platform-icons.mjs` 获取，来源及更新方式记录于 `src/assets/websites/SOURCES.md`。

## 删除账号

每行垃圾桶图标打开本地删除预览。一次展示账号、副本、仅属于此账号的资源及未发布稿件数量，不需要重复勾选或输入账号名。

- 仅清理本地账号、隔离登录会话、容量记录、分享统计、相关本地凭据和资源记录；不调用网盘删除、撤销分享或 Cloudflare 写入接口。
- 资源只有此账号的副本时，清理资源与关联未发布稿件；还有其他账号副本时，保留资源和其他副本。
- 沿用资源删除的引用保护：发布历史、文章引用、待核对提交或网盘写入，以及启用或待核对的固定入口等，会显示阻断原因。先处理原流程再删除，不删除用于恢复未知结果的记录。
- 本地记录在同一数据库事务内清理，共用资源删除的清理方法；保留独立历史与本地导出文件，不自动删除网盘实际文件。
- 删除默认账号后，为同网盘剩余的启用账号补选默认值；当前窗口选中的账号、资源或副本仅在确实被删除时清理，其他选择保留。

预览只读取本地数据，有15分钟有效期；提交前、等待账号互斥锁后及清理会话后都会重新核对范围与引用。账号或资料发生变化时要求刷新范围。清理期间阻止新的业务写入、更新安装及退出；原有账号请求通过同一互斥锁收敛。

隔离会话先于数据库记录清理。若会话清理失败，本地账号和资源继续保留；若会话已清理但后续核对失败，记录保留，可能需要重新登录。数据库提交失败时整批本地记录回滚。成功结果按操作编号持久保存，重试同一操作返回原结果，不重复删除；成功后的视图刷新失败使用警告提示。

实现集中在 `core/account-deletion.ts`、`core/resource-records.ts`、类型契约及领域IPC中。UI通过 `AccountDeleteDialog` 读取预览并提交，不直接处理数据库或网盘文件。
