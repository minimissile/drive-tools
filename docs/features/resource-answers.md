# 资源问答

入口：工作台 → 通用内容操作 → 资源问答。

输入问题，搜索并选择最多10项本地资源，选择文本、图片或图文，以及清晰实用、简洁直接、专业详解、新手友好、自然口语、推广推荐等回答风格。内容根据资源标题、摘要、标签和文件名生成，不代表已读取网盘附件正文。

每次点击生成都会保存独立版本。补充校准说明后，以所选历史版本、当前问题、资源、风格和说明生成新版本，保留原版本。问题、资源选择、风格、形式、校准文字及所选版本按工作空间暂存。最近50个生成版本可在页面直接查看，记录保存在本地数据库。

图片形式生成1张画面方案，图文生成2张画面方案。确认方案后，在图片制作区域选择模型及单张预留预算，显式点击生成实际图片。复用内容工作室的模型目录、费用台账、素材持久化、任务状态及重复提交保护，不自动提交图片或视频任务。

文字可直接复制；已生成图片可单独复制或导出；全部配图完成后，可复制包含文字和嵌入图片的富文本到支持该格式的编辑器。目标应用是否接收嵌入图片由其粘贴能力决定，单图复制和文字复制可分别使用。

生成失败保留输入、历史版本和费用记录。生成请求按请求ID去重，应用重启后未完成的请求显示待核对，不自动再次付费生成；明确点击新版本才发起新请求。版本读取失败提供重试，已返回的生成结果不会因列表刷新失败被丢弃。

## 复用本地界面验收环境

仅在用户明确授权测试后使用：

1. 复用已运行的 `npm run dev`，不要再开桌面实例。
2. 运行 `node --import tsx scripts/qa-resource-answers-server.ts`，创建一次性的临时工作空间，监听本机5199端口。若端口占用则停止，不改端口另开实例。
3. 在浏览器打开源码服务的 `/__qa-resource-answers.html`。此页加载实际 `src/main.tsx`，只替换IPC和剪贴板传输，使用模拟模型；底部按钮可注入下一次生成失败或版本读取失败，也可查看模拟调用计数。
4. 完成后关闭此验收标签，向测试桥接进程发送SIGINT或SIGTERM；它会关闭数据库并清理该临时工作空间。保留原有源码开发服务。
