# 网盘内容预览与文件管理

更新日期：2026-10-30。开发版源码功能，未制作新的安装包。

## 入口与使用

- **资源库 → 网盘文件**，或 **工作台 → 网盘文件**：选择网盘类型与已登录的本人账号，点击“读取目录”，逐层浏览文件。支持百度、夸克、UC、迅雷、光鸭和 PikPak 的现有账号适配器。
- **录入资源 → 下一步：选择文件**：第一步填写资料、封面与保存位置，链接或提取码失焦后只读取分享第一页检查有效性并显示状态图标；需要转存时进入第二步，再主动读取分享并选择文件。同一目录最多选择 100 项，进入子目录查看不会清除原选择；改选另一目录前需要清空原选择。返回第一步保留已读内容与选择，修改链接、提取码或目标账号后重新读取。
- **资源库 → 查看网盘**：入库后通过公共资源弹窗维护本人文件与广告。录入页不再嵌入本人网盘管理器，避免未保存资源时误入整个账号的根目录；自有资源可以在第一步直接入库。

目录按需读取，不在选择账号或打开页面时自动访问网盘。“搜索当前目录”仅筛选已经完整读取的当前目录，不代表全盘递归搜索。文件详情提供目录与元信息，不读取 PDF、视频等二进制正文。

## 文件和广告操作

- 新建文件夹、重命名，以及明确勾选后的批量删除；文件夹删除包含其内部内容。
- 插入广告复用本地素材库：名称文件夹、TXT（最多 512 KiB）和 PNG / JPEG / WebP 图片（最多 4 MiB）。可先在素材预览中核对文字或图片；创建素材本身只写入本地库。
- 替换广告支持 TXT 和上述图片。先将原文件重命名为带“替换前备份”后缀的备份，读取并确认备份存在后，再向原文件名写入格式相符的素材。备份保留在同一目录。JPG 和 JPEG 均按 JPEG 格式校验。
- 清理已有广告通过“删除 / 清理广告”处理明确选中的文件，显示待删除名单；不根据文件名自动识别或删除广告。
- 暂未提供任意大文件上传、在线编辑文档正文、移动文件或全盘递归批量清理。

每次远端写入前重新读取目标目录并核对所选文件的 ID、名称、类型与大小。同名新增被阻止；替换需要先完成备份。操作意图与结果保存在本地，连接中断后不会自动重放写入，同一个请求也不能变更参数后重复使用。结果不确定时，先“只读核对上次结果”，或者自行核对后显式解除待处理记录。账号活动任务和文件管理互斥。

## 资源清单和分享

内容变更会使相关副本、分享和衍生内容的旧核验失效。打开当前资源原目录、勾选修改后的项目后，可使用“更新当前资源清单”，确认后重新读取文件并更新本地清单；此步骤不创建分享。随后回资源库核验或重新创建本人分享，并重新审阅相关草稿。

独立文件页也支持将选中项目分别分享并归档，沿用已存在的分享意图记录和本人账号核验。创建分享始终需要用户明确确认权利；没有执行自动分享或发布。

## 接口实现参考

文件管理沿用现有隔离的官方网页会话。协议参考实现包括 [OpenList 的迅雷适配器](https://github.com/OpenListTeam/OpenList/blob/main/drivers/thunder/driver.go)、[PikPak 适配器](https://github.com/OpenListTeam/OpenList/blob/main/drivers/pikpak/driver.go)、[光鸭适配器](https://github.com/OpenListTeam/OpenList/blob/main/drivers/guangyapan/driver.go)；夸克 / UC 复用现有同族请求与异步任务查询。它们是开源协议实现参考，不代表平台提供了稳定公开的第三方管理 API。
