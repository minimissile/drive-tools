# 贴吧资源发帖与帖子统计

日期：2026-11-07。贴吧分为“自动养号”和“资源发帖”两个工作区，复用账号、浏览器环境和目标贴吧目录，执行范围独立。源码开发阶段，后端编译暂存，用户手动应用更新；本文中的离线测试不代表真实发布成功。

## 使用流程

1. 选择贴吧账号和发布贴吧；可在发帖工作区添加目标，添加只读解析官网，不会自动关注或签到。
2. 从历史流量词、本地词池选择选题，也可填写已确定的词。本地词池是现有流量词池，流量指标的来源保持原样，不当作贴吧站内搜索量。
3. 从资源库选择1至10份已有本人分享链接的资源。只使用已核验的本人分享，不自动转存、重新建链或付费查询。没有匹配结果时调整资源搜索条件，或先在资源库准备本人分享。
4. 用所选资源填充标题正文，编辑并预览。正文应为80–10000字，保留本次资源的准确链接及提取码；更换资源、分享或正文后，发布时自动核对当前版本。
5. 点击“发布到所选贴吧”，自动保存并校验当前内容后发布单篇；“保存草稿”只保存，不发布。不再要求先保存检查或勾选额外确认。稿件及目标范围与养号任务分开，开启养号不会自动发布资源帖子。
6. 官网准确作者、主题、首帖、正文及链接一致才记核实。审核中与结果未知分别展示；未知只核对原结果，不重新发出正文。

## 帖子统计范围

统计标题旁的感叹号使用 Tooltip（提示浮层），鼠标悬停或键盘聚焦均能查看范围：**当前仅统计已核实为本人发布、且首帖正文中包含受支持网盘分享链接的主题帖。** 标题、回帖、评论中的链接不计入。网盘链接由现有分享解析器核验，单纯提到域名不是分享链接。

来源包括本系统已取得准确主题ID的发布记录、官网“我的帖子”分页扫描，以及手动导入本人的官网主题链接。每次扫描一页，存在下一页时提供继续入口；不会把首批扫描结果当作全部历史。手动导入只读核验，不发布帖子。

概览展示已收录帖子、浏览、回复和获赞；明细保留所属账号和贴吧、读取时间及历史。排行对比每篇帖子最近两次有效读取，明确各帖时间可能不同，不当作统一的每日增长。首次读取仅建立基线；官网未提供的指标保留未知，计数下降不推算为负增长或删除原因。真实官网已观察到 `PageData.thread.reply_num` 与“回复贴”标签不一致，因此不把该字段直接当回复总数，也不减一猜测。

统计刷新失败保留原数据和原有效时间；当前正文已移除网盘链接的帖子退出当前统计范围，原历史保留。只读扫描、导入和刷新均显式触发，打开页面不会访问官网。

## 数据与恢复

稿件按版本保存，窗口之间发生冲突时保留本地输入，由用户载入已保存版本；账号、资源、词、标题正文和备注按窗口、空间和稿件恢复。发布意图只来自当前明确的发布按钮，切页、刷新和恢复稿件不会自动提交。

发布前再次核实原UID、环境版本、目标准确吧ID、暂停状态、资源和分享版本。点击前持久化提交检查点，关闭、异常或重启后未知结果不重放。资源发帖和养号签到、回复、主题共用环境队列、未知提交阻断及既有提交间隔；二者不会并行抢用同一账号环境。备份保留稿件与未知记录，撤销待发布资格。
