# 简书账号登录

入口为“账号管理 → 其他账号 → 连接新账号”，账号平台选择“简书”。账号备注可选，默认沿用其他账号的序号命名。

- 内置浏览器：关闭“关联指纹浏览器”，点击“登录新账号”。工具创建独立内置环境并打开简书官方登录页；完成登录后返回检查身份。不会要求手工填写 Cookie 或平台 UID。
- 比特指纹浏览器（可选）：开启“关联指纹浏览器”，选择已登记的比特环境，点击“关联并检查登录”读取已有登录身份。尚未登录时，在该账号行打开官方登录窗口，完成登录或安全验证后点击“检查登录”。请求使用所选环境的登录态和网络，不回退内置会话。

身份检查通过官方同源 `/author/current_user` 实时读取当前登录用户，禁用缓存并核验响应地址、状态与 JSON，展示 UID 和昵称，不再依赖主页 `JS_ENV` 模板，也不把文章作者、个人主页链接或 Cookie 存在当作登录成功。UID 变化会拦截使用并保留原账号身份；未知页面或网络异常保留历史记录并要求重新检查。明确退出后必须重新登录。

环境复用沿用现有规则：受网盘共用保护的环境不会自动放开给简书。登录与核验按环境串行执行，使用账号发起窗口；不会操作主工作台或其他任务窗口。

源码后端更新需由用户点击“应用更新并重启”加载。内置与指纹两种方式的自动化验收覆盖创建、登录分流、身份读取、未知页面、退出、错号及重新登录；测试不发文、不修改简书草稿。真实账号核验需本人先在对应环境完成登录。

## 登录后仍显示待核验（2026-11-24）

官网已登录与当前进程已核对身份分别记录。后台重新加载或浏览器环境变化后，普通账号列表保留上次昵称，但不会自动发起官网身份请求，因此可能显示“待核验”，并不表示需要重新扫码登录。

简书创作页的新文章和文章编辑区现在都在账号选择下提供当前状态、具体原因和“检查登录”。点击后只读取所选账号的官网身份，成功立即更新下拉和状态；失败保留账号与稿件，显示重试原因。重复点击不重复请求，切换账号或离开页面后不把旧请求结果写到当前界面。
