# 百度知道多账号智能问答

2026-11-08：智能问答的自动回答模式支持多选账号。选择器优先显示已核验的百度昵称，备注不同时追加备注；没有昵称时回退到备注。旧单账号草稿自动恢复为单项多选，切页与刷新保留选择，提交授权不恢复。

目标数按每个账号计算，启动区同时展示账号数、每号目标与本次总目标。启动前统一核对全部账号、模型配置与账号占用；预检失败不创建部分任务。每个账号分别保存任务、间隔、回答、进度及日志，可独立停止、核对未知回执和继续。同账号不能叠加任务，相同百度身份不能在同批重复选择。多个账号可使用同一种题目分类，分类仍为单选。

各账号进度集中在回答进度区，点击账号切换详细进度和下方通栏日志。已有账号正在回答时，可以取消选择该账号，再选择其他可用账号启动；不会因当前打开的历史任务仍在运行而锁住全部账号。

自动答题使用各自浏览器环境的租约，不长期占用全局两槽业务队列；不同环境可并发，同一环境的占用和身份核验继续由原环境服务控制。取题时同时预占问题ID及规范化标题，生成、等待和提交期间阻止其他账号处理同题；释放预占后，已提交或结果未知的题目仍由持久化历史拦截。此机制不宣称覆盖其他工作空间或平台未提供的历史。
