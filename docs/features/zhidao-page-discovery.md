# 百度知道网盘回答页发现

这是只读的回答页发现工具。主要产物是可以直接打开的百度知道回答页，网盘链接与提取码只作为命中依据；不下载网盘文件，不核验网盘有效性，不转存、建链、生成或发布内容。

入口：工作台 → 百度知道答题 → 网盘回答发现。复用项目当前源码后台，不额外启动应用或更换端口。

## 独立脚本

```sh
node --import tsx scripts/discover-zhidao-pages.ts \
  --keyword '小提琴教程' --keyword 'Excel教程' \
  --pages 2 --limit 50 --interval 2000 \
  --out /tmp/zhidao-pages.json
```

也可以先检查指定问题页或独立回答页，`--url` 可重复传入：

```sh
node --import tsx scripts/discover-zhidao-pages.ts \
  --url 'https://zhidao.baidu.com/question/1811441075743285707/answer/5013312792.html' \
  --out /tmp/zhidao-example.json
```

`--out` 后缀为 `.csv` 时导出 CSV，不指定时 JSON 写入标准输出，进度写入标准错误。暂停或访问受限时仍保存已经确认的部分结果，进程退出码为2，不能把它视为完整检索结束。脚本使用 HTTP，不会自动打开或绕过安全验证。

## 发现流程

1. 对每个关键词执行百度限定站点检索，每词1–5页，最多20个关键词。指定页面可以单独检查，也可与关键词一起运行。
2. 搜索页只提供候选地址，随后实际读取问题页或独立回答页。搜索摘要中的网盘链接不直接作为命中结果。
3. 只读取与回答ID绑定的正文区域，排除元描述、脚本、问题描述、相关推荐和评论。若从问题页发现多个匹配回答，为每个回答生成独立回答页地址；指定回答页只检查该回答。
4. 使用现有网盘域名与分享路径识别规则，识别百度、夸克、阿里、UC、迅雷等已支持的网盘链接。没有提取码的链接也可以命中；只识别图片中的链接不在此版范围内。
5. 按问题ID与回答ID去重。保留问题标题、回答页、问题页、正文节选（最多12000字）、网盘链接与提取码、关键词、来源及发现时间。ID始终按字符串处理。

桌面页与脚本共用 `core/zhidao/page-discovery/` 下的解析、队列与导出逻辑。桌面页使用按工作空间隔离的独立 Chromium 后台页面，不借用已有知道账号的Cookie，也不操作其他任务窗口。只允许导航百度搜索、百度知道问题/回答及百度验证页面；不访问网盘链接或搜索结果中的其他网站。

## 执行与检查

页面支持手动开始、停止、继续、筛选、分页、JSON/CSV导出与读取日志。“检查示例页”只检查用户给出的示例，来源明确标记为“指定页面”，不作为关键词发现的新结果。结果列表以回答页为主，展开可查看正文节选及网盘链接。

安全验证、空响应、搜索结构变化和搜索读取失败会暂停并保留当前位置，不能按真实空结果处理。可通过“查看读取页面”人工检查，完成验证后再明确继续。单页正文解析失败记录为异常页；重复结果和正文没有网盘链接分别记录。每次执行最多确认200个回答、检查500个正常正文页，候选队列最多1000项。

当前页面展示最近一次执行，旧执行仍保留在本机 `settings` 的独立记录中。进度和结果在重启后保留，执行中的记录恢复为暂停，不自动发起请求；新检索需要显式开始。日志保存最近300条，每页100条。关键词与参数按工作空间和窗口暂存。
