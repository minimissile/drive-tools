# 整盘目录同步

在“工作台 → 网盘文件”选择本人账号，打开“本地目录”，点击“同步整个网盘”。同步覆盖普通个人文件区的全部可读取目录和分页，把文件名、文件 ID、父目录、路径、类型、大小及本地读取时间保存到当前工作空间。文件正文、回收站和保险箱不在本次范围内。

百度、夸克、UC、迅雷、光鸭和 PikPak 共用同步服务，各自保留原来的内置或指纹浏览器方式。同步最多并发处理 3 个账号；百度和夸克复用现有环境队列，同一环境串行；其他平台沿用原生分区及账号锁。页面不会自动登录、改绑环境或创建分享。PikPak 本轮按用户要求跳过真实账号验收。

## 浏览和恢复

- “本地目录”支持目录树、全盘名称与路径搜索、录入状态筛选和数据库分页。账号登录失效或停用时仍可查看历史索引。
- 同步显示已发现文件、目录、待处理和失败数量，不推算未知总量的百分比。切页不停止后台任务。
- “暂停同步”在当前只读请求完成后停止；“继续同步”重读未完成目录，按文件 ID 去重。进程重启后不自动扫描。
- 子目录失败显示“部分完成”，“重试未完成目录”保留成功目录，只重试失败范围。
- 身份或绑定环境变化会停止写入。核对账号后可以重新扫描，旧索引在新扫描期间保留。
- “更新本地目录”重新遍历目录并更新变化。只有完整成功的扫描，才把旧记录标为“本轮未发现”；不自动删除资源或网盘文件。

## 资源关联与登记

关联以本地账号、网盘 UID 和目标文件 ID 为依据，使用有效副本的本人清单及目录 ID。来源分享的文件 ID 和同名文件不会被自动认领。目录关联已有资源时，未出现在原清单中的子项显示待核对。

勾选文件或文件夹，点击“录入资源库”，在预览中修改标题后保存。每批最多 50 项，支持跨页选择；父目录与子项不能同时登记。登记时重新读取远端目标，重复提交返回既有资源，重名冲突逐项提示。

保存的资源属于本人已有文件，副本状态为待完善分享；保存不会转存、建链或发布。资源资料可在原账号记录中继续编辑，分享通过资源中的正式创建流程单独处理。源文件的真实路径保存在清单中，便于后续重新定位。

从索引打开“实时网盘”后，沿用既有目录读取与文件管理功能；实际修改前仍需重新读取并核对目标，不能以历史索引直接提交删除或替换。

## 存储和验证

数据库新增目录索引、同步任务、目录队列和资源关联表。副本清单或归属更新后，由数据库触发器维护关联；账号或副本删除时同步清理其索引关系。现有整库备份包含新增数据，旧库升级保留原资源和加密值。
