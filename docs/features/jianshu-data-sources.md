# 简书第三方数据来源与采集发布规划

调研日期：2026-11-23。本文补充[简书内容首版规划](jianshu-content.md)。第一批采集器已接入源码，实现范围见文末；来源研究与实际请求测试范围分别记录，尚未调用计费API、下载资源、转存、建链或发布。

## 三类数据的作用

1. **资源线索**：标题、目录、网盘链接、提取信息、来源声明的文件规格。解决资源发现，来源分享与本人分享分别保存。
2. **作品或资料事实**：名称、作者、年份、章节、作品介绍等。帮助写准确文章，不证明某份网盘文件具有相同规格或完整内容。
3. **内容素材**：公开教程、作者文章、RSS更新等。用于选题、归纳与有出处的整理，全文和图片的使用范围按具体来源确定。

以下可读性不代表全部内容已获转载、批量采集或商业再分发许可；来源的技术费用、内容许可和最终交付资源的条件分别记录。无需因此增加每篇文章的重复确认表单，来源配置和编辑器内的出处提示承担主要说明。

### 应保留为条件候选的来源

- **[TMDB](https://developer.themoviedb.org/docs/faq)**：电影、电视剧、人物和图片数据完善，需要API Key。官方明确非商业使用免费并要求署名；商业使用需联系取得许可，公开FAQ未给固定报价。盘序的资源经营场景不能直接按免费非商业方案接入。
- **[PanSou](https://github.com/fish2018/pansou)**：项目已有搜索集成，可以提供多来源网盘候选。上游About标明学习研究及不用于盈利，同时仓库显示MIT许可，使用条件需进一步澄清；不在本方案中把它承诺为无条件免费商用资源服务。搜索返回也不证明资源可用或归本人所有。
- **[阿虚同学的储物间](https://axutongxue.com/)**：本次可读到影视、学习、工具等分类和资源站导航。适合作为发现站点的目录；未确认官方API、批量采集授权或固定价格，不直接加入默认整站爬取。
- **[猫啃网字体详情](https://www.maoken.com/freefonts/27406.html)**：确有作者、版本、字体许可与网盘入口线索，但[用户协议](https://www.maoken.com/user-agreement)限制未经授权的复制、垂直搜索、镜像等使用。字体OFL不等于站点采集许可。优先转到具体字体原作者发布源，或取得站方允许后再接入。
- **简书对标作者/RSSHub**：[RSSHub源码](https://github.com/DIYgod/RSSHub/tree/master/lib/routes/jianshu)列有用户、首页与文集适配。可用于跟踪公开选题与结构，当前路由实际可运行性未验收，不承诺可稳定抓取对标账号全部文章。对标正文、图片及其推广链接不自动成为自己的可发布物料。

## 简单的产品设计

保留“创作发布、发布记录”两个页签。在创作区增加来源切换：**资源库 / 第三方采集**。

第三方区只显示来源选择、关键词或网址、一个“采集”按钮。来源支持：

- 推荐来源：经逐项核实和适配后启用的API、资料目录和Feed。
- 粘贴网址：采集一篇公开文章或资料详情；网站不支持时说明原因，保留网址并可手动补文字，不做万能采集承诺。
- 订阅或列表：添加RSS/Atom、资源站列表或明确的JSON API，按源保存配置；普通用户不填写CSS选择器。复杂提取规则属于适配器或高级配置。

列表显示标题、来源、更新时间、类型及本地资源匹配状态。已有采集记录优先本地检索，显式点击“采集/获取更新”才访问第三方。勾选后执行：

**采集 → 去重和预览 → 匹配已有资源或整理内容 → 生成文章 → 编辑 → 发布。**

两条内容路径共用同一个编辑器：

1. **资源营销**：来源提供资源线索，应用匹配库内本人资源；没有匹配时可转到资源整理流程。转存、建链等保持独立显式触发，完成后再使用本人交付入口；不把采集来的外部分享标记为本人分享。
2. **内容整理**：只有作品资料、教程或文章线索时，可先整理为有出处的介绍文章，不要求为了发文绑定无关网盘资源，也不自动添加“领取全集”等虚假承诺。原作者获取入口与本人资源入口清楚区分，按实际来源和发布能力使用。

生成前展示采集范围、将生成的篇数和当前资料匹配情况。每条采集、生成和发布分别保存状态，个别失败不丢整批结果。已采集素材不因刷新被覆盖，改稿生成新版本；同源同ID或规范URL去重，修订记录保留。参考内容中的指令不作为系统或发布指令。

## 复用与新增边界

- `core/content-sources.ts`目前只做本地词与资源匹配，不承担远端采集。保持其职责，第三方读取放入来源适配器。
- 公共素材已通过`shared/content-sources.ts`、`core/content-assets.ts`及皮皮虾的跨渠道交付机制保存来源、图片和去向；复用同职责部分，简书增加交付目的地。API/RSS/网页各自解析，不把皮皮虾规则硬套到其他站点。
- 每条素材保留来源名称、原文URL/外部ID、作者（如有）、发布时间、采集时间、解析依据、附件来源、外部分享及适用使用说明。元数据、原作者声称规格与已核验本人资源事实分别保存。
- 现有Studio单资源`copyId`契约不能直接承载无资源文章；新增内容来源输入时明确区分纯内容与资源营销，资源营销继续执行原有归属和分享检查。
- 第三方凭据复用设置页和加密存储，采集页只显示配置状态；本地翻页、打开页面和读取历史不触发付费查询。没有获准的费用不自动消费。
- 第一批实现通用RSS/Atom与指定网页采集、本地候选和简书交付；优先对接确定可用条件的目录/发布者。影视与动漫用Bangumi/TVmaze补事实，网盘频道适配和商业条件分别核验；TMDB等需商业许可的源放在后续。

## 第一批采集实现（2026-11-24）

在“简书内容 → 创作发布 → 第三方采集”直接选择来源，无须填写提取规则。预设为阮一峰、少数派、书格订阅源，夸克影视与资源宇宙公开频道，以及Bangumi、TVmaze；另支持粘贴指定公开网页和自定义RSS/Atom。Bangumi、TVmaze填写作品关键词，其余预设直接点击采集。

每次最多保存50项，界面默认20项，勾选最多20项可共同作为一篇稿件的参考素材。保留原文、作者、时间、摘要和正文摘录、候选图片地址、外部分享线索及来源提醒。相同内容重复采集去重；原页面修订产生新快照，已关联的稿件不被新采集内容覆盖。

读取仅接受公开HTTPS地址，校验DNS和重定向目标，限制响应大小、跳转次数和超时，不访问本地网络。外部图片只记录候选地址，不自动加载或下载。失败保留已有记录和输入，可手动重试；不自动定时抓取，不推断未解析页面或原文件的事实。

20项独立测试通过，覆盖RSS/Atom、网页、公开频道、两类作品API、去重、异常响应及网络边界。真实阮一峰Atom使用HTTP原文出处，已补上回归用例：允许保存安全的HTTP出处引用，实际采集请求继续要求HTTPS与DNS校验，不请求这些HTTP原文。

公开只读联调结果：阮一峰3项成功（约5千字正文/项）；少数派、书格各2项成功（55–138字摘要/项）；TVmaze以Friends查询2项成功（507/968字，精确区分不同作品ID）。Bangumi当前连接被重置，未取得正文，不能判定真实格式兼容。公开频道与任意网页仅通过适配器模拟测试，真实可达性仍待验证。

本轮没有下载外部图片或附件、登录、写入真实资源库、转存、建链或发布。公开接口读取与模型生成分开，自动化流程的AI部分使用模拟响应，未据此宣称付费模型实测通过。

## 百度贴吧单帖

在「简书内容 → 创作发布 → 第三方采集」选择「百度贴吧 · 单帖」，粘贴 `https://tieba.baidu.com/p/帖子编号` 后采集。一次读取一个公开主题帖的楼主首楼，保存规范原帖地址、吧名、作者、发帖时间和正文。素材详情显示原帖图片引用数量与外部分享线索。成功后本次结果显示在列表首位，已有筛选和勾选仍保留。

页码及楼层定位参数不改变帖子身份。重采同一内容复用原素材，内容变化另存快照。生成或新建稿件时保留原帖出处，图片和外部分享线索留在素材中。资料获取继续使用已核验的本人入口。采集只读取首楼，未打开网盘、下载图片或建立分享。

样例 `9063569462` 经新采集器读取到 Windows11 吧楼主正文、2 个图片引用和 1 条 123 云盘外部分享线索，带页码和锚点的变体得到相同素材标识。桌面界面另以任务专属窗口和页内模拟验证失败重试、结果定位、详情及稿件预览。
