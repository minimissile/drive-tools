# 资源库与封面

## 封面入库

录入资源支持上传、拖放和粘贴 JPG、PNG、WebP 图片，原图上限仍为8MB。选择图片和本地表单暂存保留原图，点击保存、直接入库或创建转存任务时，统一在资源保存环节处理封面。

保存后的封面使用真正的 WebP 编码，体积不超过200,000字节（200KB）。按原比例将最长边限制为1600像素，优先调整编码质量；仍超过体积限制时继续等比例缩小。保留透明背景，不放大小图，动态图片作为静态封面保存。图片内容无法解码、超过6000万像素、处理超时或最终文件不符合格式与体积要求时，本次资源不保存，表单保留供重试。

处理在本机完成，不调用外部图片服务，也不增加平台原生图片依赖。编辑资源时，已保存且未更换的 WebP 封面复用原文件，避免反复有损压缩。移除封面仍按原有操作生效。

已有 PNG 封面保持可读，不批量迁移历史图片；重新保存携带原封面的资源时转换为 WebP。封面预览、单独导出、内容包、Obsidian 附件、内容工作室参考图及工作空间备份与恢复均兼容新旧格式。微博图文包在导出时另外转换为平台原有的 PNG 配图，资源库中的 WebP 文件保留。

## 筛选布局

搜索框最大宽度为360像素，在列表空间不足时收缩，不填满宽窗口的剩余空间。右侧依次为“清除筛选”、分类下拉框、账号下拉框；存在筛选条件时显示清除按钮。筛选、清除与分页行为沿用原逻辑。

资源库顶部移除宣传标题与副标题，保留资源统计及主要操作。每行复选框右侧统一使用压缩包、文件、文档三类图标，优先根据副本文件清单识别；没有清单时根据标题中的扩展名或格式标记识别，其他情况显示文件图标。

## 网盘资源查看

资源行及资源档案提供“查看网盘资源”入口，统一使用 `DriveResourceDialog`。文章配套资源也复用此弹窗，可传入资源及副本、本人目录或分享链接。

弹窗区分本人资源、他人分享和未核验分享。打开弹窗先读取本地资料，检查本人分享、定位文件及读取分享内容均由用户明确触发。本人副本根据账号身份和文件 ID 定位，目录名或文件名相同不会被当作同一份资源。

本人目录复用网盘文件管理功能，可进行文件重命名、广告文件插入及广告清理。分享内容以只读方式查看，未确认本人身份时不开放网盘写入。

## 删除资源

资源行及档案菜单提供删除入口，默认仅删除本地数据库记录，也可通过并排按钮选择同时删除本人网盘文件。列出涉及的全部账号副本、文件及关联草稿后，点击底部删除按钮即可提交，不再额外勾选确认。网盘删除要求账号身份、已核验副本与文件清单齐全，按记录的文件 ID 删除，不把所在目录整体当作资源删除。弹窗右上角统一使用关闭图标，靠近边缘放置。

网盘删除会先定位全部副本，核对身份、文件清单和重复或父子重叠，逐个副本记录处理进度。只有全部网盘删除结果确认成功后才移除本地记录；结果不明确时保留本地资源，重新打开删除弹窗可只读核对结果，或明确确认后继续尚未提交的副本，不重复提交结果未知的操作。

本地删除会清理资源、副本及关联的未发布稿件，解除选题和分发来源关联，保留独立的历史记录及本地导出文件。关联发布历史、未完成任务或待核对网盘写入的资源会显示阻断原因，需要先处理原流程。
