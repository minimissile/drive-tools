# 资源库与封面

## 封面入库

录入资源支持上传、拖放和粘贴 JPG、PNG、WebP 图片，原图上限仍为8MB。选择图片和本地表单暂存保留原图，点击保存、直接入库或创建转存任务时，统一在资源保存环节处理封面。

保存后的封面使用真正的 WebP 编码，体积不超过200,000字节（200KB）。按原比例将最长边限制为1600像素，优先调整编码质量；仍超过体积限制时继续等比例缩小。保留透明背景，不放大小图，动态图片作为静态封面保存。图片内容无法解码、超过6000万像素、处理超时或最终文件不符合格式与体积要求时，本次资源不保存，表单保留供重试。

处理在本机完成，不调用外部图片服务，也不增加平台原生图片依赖。编辑资源时，已保存且未更换的 WebP 封面复用原文件，避免反复有损压缩。移除封面仍按原有操作生效。

已有 PNG 封面保持可读，不批量迁移历史图片；重新保存携带原封面的资源时转换为 WebP。封面预览、单独导出、内容包、Obsidian 附件、内容工作室参考图及工作空间备份与恢复均兼容新旧格式。微博图文包在导出时另外转换为平台原有的 PNG 配图，资源库中的 WebP 文件保留。

## 筛选布局

搜索框最大宽度为360像素，在列表空间不足时收缩，不填满宽窗口的剩余空间。右侧依次为“清除筛选”、分类下拉框、账号下拉框；存在筛选条件时显示清除按钮。筛选、清除与分页行为沿用原逻辑。

资源库顶部移除宣传标题与副标题，保留资源统计及主要操作。每行复选框右侧统一使用压缩包、文件、文档三类图标，优先根据副本文件清单识别；没有清单时根据标题中的扩展名或格式标记识别，其他情况显示文件图标。

资源行铺满列表可用宽度，不再为未出现的滚动条保留右侧空白。“公众号文章”“什么值得买”这两个旧的来源、用途标签不再显示或自动添加，保留手工填写的其他资源标签。

## 资源去重

一份资源在同类型网盘只允许保存一次，切换同类网盘账号也不会新增第二份。保存时同时核对来源链接、同类型网盘副本和规范化同名记录；普通录入、批量导入和网盘目录入库共用校验，并在异步处理前与最终事务内检查。历史副本不自动删除或合并，明确编辑原记录仍可继续。

录入标题后延迟300毫秒检查名称，忽略大小写、全半角、空格与标点，保留数字，用标准化编辑距离计算相似度。相似度达到80%的记录按相似度降序展示，最多10条，包含名称、网盘类型及百分比。可直接查看已有资源，当前表单继续保留在本地暂存。规范化同名且网盘类型相同会阻止新增；其他相似项只提醒，不要求额外确认。批量导入的预检说明也列出相似提醒并跳过同类网盘重复项。

## 标签输入

录入页标签在失去焦点时自动整理，例如 `#1 #2` 变为 `1，2`。支持半全角话题符号、中英文逗号、顿号、分号和换行分隔，移除空项及重复项，保留顺序；普通标签内部的空格和 `C#` 等内容保持原样。保存参数复用同一个解析方法，避免未触发失焦时存入未拆分的话题文本。格式化结果继续随资料草稿在本机暂存。

## 录入步骤

第一步填写资源信息、封面和保存位置，并展示重复提醒。网盘链接及提取码失焦后先识别分享，再复用 `share.inspect` 读取分享第一页检查可访问性；只检查，不选择文件、保存资源或转存。输入框保留粘贴的完整原文，不在失焦时替换域名、链接路径或移除查询参数；解析后的标准链接仅用于检查和保存，识别出的提取码与网盘账号仍可自动填入。状态行显示检查中、有效、不可用或暂无法检查的图标及具体原因，并可手动重新检查。同一输入一分钟内复用结果，修改链接、提取码或目标账号即清除旧结果，离开页面后的响应不回写状态。

可以保存资料草稿，或点击“下一步：选择文件”进入校验与转存；进入第二步本身不保存资源、不读取网盘、不创建任务。第二步显示当前资源与目标位置摘要，主动读取分享后选择文件，再保存并开始转存。返回第一步保留已读内容与选择，改变链接、提取码或账号时清空旧选择；刷新后恢复资料草稿，文件内容仍需重新读取，有效性结果不随草稿恢复。

自有资源在第一步直接入库，不显示文件选择步骤。本人网盘文件维护统一从入库后的“查看网盘”进入，录入页不再嵌入文件管理器；已归档资源编辑资料时也不展示转存操作。

资料页移除“从本地TXT / Markdown载入说明”按钮，说明直接填写或粘贴。基本信息与右侧封面、保存位置共用自适应高度，顶部和底部对齐，说明框与封面区域随内容伸展；保留公共控件尺寸、焦点样式与原有响应式规则。

## 网盘资源查看

资源行及资源档案提供“查看网盘资源”入口，统一使用 `DriveResourceDialog`。文章配套资源也复用此弹窗，可传入资源及副本、本人目录或分享链接。

打开弹窗后直接加载内容，只用右上角标记区分本人资源、他人资源及归属未核验，不再提供“本人资源 / 来源分享”切换或首次读取按钮。已核验本人副本根据账号身份和文件 ID 定位，目录名或文件名相同不会被当作同一份资源；他人或未核验分享直接以只读方式加载。失败提供重试，首次加载使用占位，打开弹窗不创建分享或自动提交写入。

弹窗聚焦资源查看和文件维护，内容依次为资源信息、目录导航、搜索筛选、维护操作和文件列表。目录导航支持上一级、根目录、层级跳转及刷新，长目录名省略显示并可查看完整路径；搜索框限制宽度，文件名称、类型、大小和详情分列展示。本人目录保留多选、新建文件夹、广告插入、重命名、广告替换与删除清理；只读分享隐藏选择列及维护操作。首次读取、刷新、错误恢复、真实空目录和筛选无结果分别展示。

弹窗不再挂载“分别分享并归档”“去生成问答模板”及“更新当前资源清单”，独立网盘文件页面和录入页继续保留各自原有流程。维护文件后，清单待重新核验不改变已核验的资源归属；重新打开弹窗优先核对原目录 ID，原路径失效时交给严格的文件 ID 定位，不按同名目录冒认资源，也不自动改写资源清单。分享内容以只读方式查看，未确认本人身份时不开放网盘写入。

## 分享有效性与独立建链

资源档案中的有效性检查统一为“检查有效性”，放在更多菜单。复制资源原有分享时复用同一检查流程，联网确认归属与文件清单后再复制，并同步保存检查结果；用户无需先手动检查一次。资源归档状态与分享有效性分别展示，列表及档案共用有效性判断，检查失效、待检查、账号待登录等状态不会继续显示分享可用。首次核验自有资源不附带笔记导出操作。

“恢复本人分享”改为独立的“创建新分享”，可设置网盘支持的有效期和提取码。此操作基于本人已核验的实际文件创建链接，直接入库但未记录目录的资源也可按文件 ID 定位。创建结果用于查看和复制，不新增资源或副本，不替换原分享、递增原分享版本或修改关联草稿。原链接失效不会因创建新链接而恢复。

独立建链仅保存用于防重复提交和重新查看结果的操作记录，提取码加密保管。用户点击创建后才调用网盘，提交结果未知时保留原操作并阻止重复创建；不会把查询失败当作可重新提交的依据。各网盘仅提供已确认支持的设置，不静默忽略有效期或自定义提取码。

夸克、UC、百度支持永久、1天、7天、30天，以及自定义4位字母数字提取码，留空自动生成。迅雷提供永久、1天、7天及平台提取码；PikPak提供永久、1天、7天、30天的公开无提取码链接；光鸭目前仅提供永久有效及平台提取码。实际到期时间仅使用平台返回值。

右侧档案优先显示存储位置、文件概况、分享状态及资源说明。未配置知识库时不展示知识笔记占位，检查、搜索选题等次要操作放入更多菜单；底部保留复制分享和查看网盘等常用入口。正常检查结果使用一行状态与时间，异常信息只保留一处提示。

“拆分为多个链接”与其他菜单项统一使用图标。公共复合输入中的操作按钮统一为居中的方形点击区域，不再撑满输入框高度；搜索清除后焦点回到输入框，焦点边框仍由公共表单样式管理。

## 弹窗操作

新建文件夹、重命名、广告插入、替换及文件清理移除重复的“我已核对”勾选，底部按钮直接命名实际动作。账号设置、关闭浏览器窗口、发布和回执登记等弹窗也移除额外确认勾选；保留账号、目录、文件清单、参数、权限和提交状态校验。远端结果未知时仍由用户主动选择实际结果，不自动推定成功、失败或重试。问答编辑可直接“保存修改”或“保存并审核”，无需再次勾选审核确认。

## 删除资源

资源行及档案菜单提供删除入口，默认仅删除本地数据库记录，也可通过并排按钮选择同时删除本人网盘文件。列出涉及的全部账号副本、文件及关联草稿后，点击底部删除按钮即可提交，不再额外勾选确认。网盘删除要求账号身份、已核验副本与文件清单齐全，按记录的文件 ID 删除，不把所在目录整体当作资源删除。弹窗右上角统一使用关闭图标，靠近边缘放置。

网盘删除会先定位全部副本，核对身份、文件清单和重复或父子重叠，逐个副本记录处理进度。只有全部网盘删除结果确认成功后才移除本地记录；结果不明确时保留本地资源，重新打开删除弹窗可只读核对结果，或明确确认后继续尚未提交的副本，不重复提交结果未知的操作。

本地删除会清理资源、副本及关联的未发布稿件，解除选题和分发来源关联，保留独立的历史记录及本地导出文件。关联发布历史、什么值得买文章（含编辑中引用）、未完成任务或待核对网盘写入的资源会显示阻断原因，需要先处理原流程或解除文章资源关联。
