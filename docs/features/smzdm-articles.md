# 什么值得买文章分发（开发中）

入口位于“工作台 → 什么值得买内容操作 → 什么值得买文章分发”。账号登录统一放在“账号管理 → 其他账号”，选择“什么值得买”。本功能仅连接一个账号，使用独立内置浏览器环境保存官方登录会话。

## 使用流程

1. 添加什么值得买账号，在官方窗口完成登录，返回点击“检查登录”。应用从官方当前用户接口核对 UID 与昵称，不用手工填写 UID。绑定身份变化时停止使用，不能把原任务自动切换到另一个身份。
2. 输入 `https://mp.weixin.qq.com/s/…` 或带查询参数的公众号文章地址，点击“抓取文章”。保留标题、作者、发布时间、正文、可识别配图和原文地址；原文与编辑稿分开保存。抓取失败时打开原站窗口，处理验证后可重试。音视频、交互内容和无法导入的图片会提示人工核对。
3. 每个支持的网盘链接可关联同源已有副本，或选择对应网盘账号进入现有资源录入页面。导入文章和创建入库草稿都不会自动转存；文件选择、权利确认、转存、本人建链与归档沿用现有流程。
4. 资源处理完返回文章任务，刷新并点击“同步替换为本人链接”。应用检查本人副本归属和已核验的分享，逐处替换 URL 与相邻提取码。新增、删除文章内的网盘链接会同步调整资源关联。暂未支持入库的常见网盘会阻止审阅，需移除或换成可核验的本人资源。
5. 编辑标题与 Markdown 正文，可整理排版、预览并对照原文。AI 润色由按钮显式触发，使用现有文案模型和预算；编辑指令要求去掉空泛开场、机械过渡和夸张表达，保留事实、引用、图片与链接，不虚构用户亲测经历。链接占位符变化会拒绝润色结果并保留原稿。
6. 核对检查项并完成当前版本审阅。什么值得买标题上限为 30 字。修改正文、排版、润色、资源关联或分享链接后，旧审阅失效。可先打开官方发布预览，核对分类、封面和配图等平台要求。使用过 AI 润色的稿件会保留这一标记，提交前须在官方创作声明中确认含 AI 生成内容。
7. 点击“一键发布”并确认当前稿件。提交前再次核对账号、环境、文章版本、本人分享实时状态与提取码。官方编辑器必须能被明确识别并接受内容；分类、封面、安全验证和图片处理未完成时停止，由用户在官方窗口处理后继续。提交后按绑定 UID、草稿 ID 与标题核对“我的文章”记录，保存实际文章地址，区分待审核和已发布。后续可点击“核对官方投稿结果”更新历史任务，不重新投稿。

## 本地保存和恢复

- 任务和原文保存在当前工作空间数据库；文章列表仅返回概要，按需读取正文。
- 链接输入、选中任务、未保存文稿和待回填地址按工作空间与文章隔离暂存。权利确认、审阅勾选和发布授权不随表单恢复。
- 保存时检查版本冲突；旧暂存不会覆盖新稿，可先复制需要保留的内容，再选择以任务版本替换本机暂存。
- 提交前写入发布意图。点击后发生超时、窗口关闭、程序中断或无法识别回执时，标记“结果待核对”，禁止自动重试。重新启动时也会恢复这一状态。
- 官方草稿地址按文章、账号身份与浏览器环境保存。重新预览或开发重启后继续同一篇草稿，保留平台上传的图片和封面；环境或身份改变时不复用旧地址。
- 官方明确显示“提交成功”时记录“待审核”，即使尚未返回文章地址也不记为失败，不把进入审核当成已经公开发布。待审核可稍后补填同一篇文章地址；确认公开发布时必须填写文章地址。仅在结果未知且人工确认没有提交后，才恢复编辑与重新审阅。
- 官方“我的文章”记录显示同一草稿 ID 的“已发布”且返回文章地址时，同步为已发布。结果读取允许同一账号更新后的登录会话，不要求沿用投稿时的会话版本，但仍须验证同一 UID；不会只凭同名标题匹配，也不会把其他任务的状态算到当前文章。已发布记录不能降回待审核或允许重发。
