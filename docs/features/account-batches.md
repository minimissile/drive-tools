# 同类型账号批量核验

网盘账号和其他账号列表支持按同一平台批量核验登录。先切换到具体网盘或平台，勾选账号或全选当前筛选结果，再点击“批量核验登录”。网盘另提供“批量刷新容量和会员”。停用账号不参与，单批最多 100 个；搜索时保留已选账号，切换平台会清空选择。

批量操作卡片默认收起，标题栏保留所选数量、最近任务的平台和进度。运行中收起后仍可停止排队，失败项可直接重试并展开详情。展开与收起状态按会话窗口、工作空间及网盘/其他账号页面分别暂存，刷新后恢复。

## 调度方式

后台最多同时处理 3 个账号，相邻启动随机错开 0.4–1 秒。前一个账号尚未完成时，后续独立环境可以开始；共用同一浏览器环境的账号依次执行。等待共用或外部占用环境的账号不会阻塞其他空闲环境。

批量调度沿用每个平台原来的核验接口、账号 UID 校验、内置/指纹登录方式和代理策略。窗口行为沿用各平台原核验流程，调度器不额外执行登录、改绑环境或重置登录态；需要本人重新登录或处理浏览器故障的账号，逐条报告原错误。网盘身份已核验但容量或会员读取失败，报告“部分完成”。

工作空间同一时间保留一个批量操作。批量运行及等待期间，后端保持忙状态，源码更新依旧等待用户手动应用。单个账号失败不影响其他账号。

## 结果、停止与恢复

- 列表上方显示完成进度和逐项结果，区分等待、运行、成功、部分完成、失败与未执行。
- “停止排队”取消尚未启动的账号，已启动的账号完成本次操作后结束调度。
- “重试未完成项”只重新提交失败、部分完成及未执行账号，已成功的账号不重复核验。
- 后台保留本次进度，切页或打开其他会话窗口后仍可查看。应用进程中断后标记未完成项，不自动重发操作。
