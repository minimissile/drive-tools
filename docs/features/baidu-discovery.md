# 百度批量扩词

状态：开发源码功能，2026-10-31；未提升版本或生成安装包。

入口为“工作台 → 资源发现与采集 → 百度批量扩词”。输入初始关键词，每行一个，也可使用中英文逗号或分号。关键词按 Unicode 规范化、空白和大小写去重，保留短语中的空格。最多输入200词，每词100字符。

选择“下拉联想词”“相关搜索词”，再点击“开始采集”。实际访问由盘序客户端自己的可见 Chromium 窗口执行：联想词使用百度公开联想服务，相关搜索从真实搜索结果页面的对应模块提取。使用按工作空间隔离的持久浏览器会话，保留此采集窗口的 Cookie；不会切换账号编辑页，也不要求百度营销账号。没有接入 Codex 浏览器或付费词库接口。

默认只查询初始词。勾选“自动继续扩词”后按广度优先继续到第2或第3层；每任务最多查询500词、保存10000个去重结果，查询词之间间隔1.5–30秒。新发现的词按顺序入队，同词不会重复查询。达到上限时明确提示，实际数量不补齐。两类推荐数据本身没有独立分页，界面分页只是本地结果每页30条。

采集完成后，可勾选尚未查询的结果，点击“所选词继续扩词”；续扩沿用该任务的查询上限，最多到第3层。任务保留每个词的来源类别、来源查询词、初始词、层级、来源链接和采集时间。CSV 每个去重词一行并包含来源字段；TXT 每个词一行。可以导出全部或所选，筛选不会暗中改变“导出全部”的范围。

任务及来源断点保存在当前工作空间的本地数据库，不随页面退出取消。当前任务、表单、筛选、跨页选择按工作空间、任务与窗口分别暂存。进行中的采词任务接入顶部任务切换器，能从其他页面返回对应任务。后台重启后任务转为暂停，不自动发送新搜索。

安全验证、模块未识别与读取失败会暂停任务。验证页保留在采集窗口，由用户手动完成后返回点击“继续采集”。两种来源分别保存，第二种来源失败不会丢弃第一种结果；继续时仅重试尚未完成的来源。“跳过当前词”明确记录跳过，已取得的结果保留。暂停会终止当前读取并保存断点，浏览器 Cookie 保留；关闭采集窗口后可重新打开。采集窗口打开期间延后开发后端重启和工作空间切换，完成后可点击“关闭采集窗口”。

## 本轮验证

- 10项针对性测试通过，覆盖来源合并、去重导出、验证后续采、查询边界、手动与自动扩词、取消、跳过、重启恢复与公共任务导航；类型检查通过。
- 通过 `test:session` 在唯一源码开发后台创建本轮专属窗口，验证工作台入口、表单刷新恢复、DOM模块提取、验证页识别、筛选无结果恢复、跨刷新选择及分页；检查1366×768和1440×900的实际界面。
- 真实内置浏览器对“画竹子教程”“水墨画入门”分别取得20条联想词、20条相关搜索，合并去重39词。勾选一词继续采集后共54词；另一次仅联想词的2层、2查询上限自动扩词取得18词并按上限停止。结果仅代表本轮关键词、时段与客户端会话，不承诺始终返回相同词数。
- 验证页识别与断点续采使用局部DOM夹具和隔离数据库模拟验证；本轮真实百度访问未触发验证码，没有实际完成验证码流程。
- 已在测试结束后的专属窗口手动操作客户端原生保存对话框，分别导出CSV与TXT；实际文件各54词，顺序一致、无重复，CSV来源字段完整。另验证历史任务选择、任务内筛选在刷新后恢复。

主要实现：`shared/baidu-discovery.ts` 定义契约，`core/baidu-discovery.ts` 管理任务及本地记录，`desktop/baidu-discovery-session.ts` 管理客户端采集窗口，`src/baidu-discovery` 组织表单、结果与交互。无数据库版本迁移，记录使用现有本地 `api_cache` 命名空间持久保存。
