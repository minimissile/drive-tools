# 百度批量扩词

状态：开发源码功能，2026-10-31；未提升版本或生成安装包。

入口为“工作台 → 资源发现与采集 → 百度批量扩词”。输入初始关键词，每行一个，也可使用中英文逗号或分号。关键词按 Unicode 规范化、空白和大小写去重，保留短语中的空格。最多输入200词，每词100字符。

选择“下拉联想词”“相关搜索词”，再点击“开始采集”。实际访问由盘序客户端自己的 Chromium 后台页面执行，默认不显示窗口或抢占焦点：联想词使用百度公开联想服务，相关搜索从真实搜索结果页面的对应模块提取。使用按工作空间隔离的持久浏览器会话，保留此采集窗口的 Cookie；不会切换账号编辑页，也不要求百度营销账号。不关联指纹浏览器，没有接入 Codex 浏览器或付费词库接口。

默认只查询初始词。勾选“自动继续扩词”后按广度优先继续到第2或第3层；每任务最多查询500词、保存10000个去重结果，查询词之间间隔1.5–30秒。新发现的词按顺序入队，同词不会重复查询。达到上限时明确提示，实际数量不补齐。两类推荐数据本身没有独立分页，界面分页只是本地结果每页30条。

采集完成后，可勾选尚未查询的结果，点击“继续扩词”；续扩沿用该任务的查询上限，最多到第3层。任务保留每个词的来源类别、来源查询词、初始词、层级、来源链接和采集时间。CSV 每个去重词一行并包含来源字段；TXT 每个词一行。可以导出全部或所选，筛选不会暗中改变“导出全部”的范围。

任务及来源断点保存在当前工作空间的本地数据库，不随页面退出取消。当前任务、表单、筛选、跨页选择按工作空间、任务与窗口分别暂存。进行中的采词任务接入顶部任务切换器，能从其他页面返回对应任务。后台重启后任务转为暂停，不自动发送新搜索。

安全验证、模块未识别与读取失败会暂停任务，当前页面保留在后台。点击“查看异常页”显示同一会话，用户手动处理后返回点击“继续采集”。两种来源分别保存，第二种来源失败不会丢弃第一种结果；继续时仅重试尚未完成的来源。“跳过当前词”明确记录跳过，已取得的结果保留。暂停会终止当前读取并保存断点，浏览器 Cookie 保留。关闭已显示的浏览器窗口会返回后台；“结束会话”释放页面并保留采集结果。正在读取或显示浏览器时延后开发后端重启和工作空间切换，空闲的隐藏页面不会一直占用；最后一个工作台窗口关闭时清理这些页面。
