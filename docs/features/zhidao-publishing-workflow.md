# 问答发布五步流程

2026-11-24，问答发布采用内容优先的五步顺序制作表格，顶部展示步骤进度。已有问答上传、发布记录保留独立入口，不会在制作或下载过程中自动上传。

1. **录入资源**：搜索资源库中的百度资源，或以名称、百度分享链接、分类、描述四列录入库外资源。分类读取资源录入选项。支持 Excel 四列粘贴、带引号的多行描述、逐行编辑删除和分页；一次最多50份，重复链接与不完整行不能进入下一步。
2. **检查关键词**：直接复用 `IntakeKeywords` 及 `resource.keywordLookup`，使用已有百度营销账号、5118和百度搜索建议。逐份资源保留自己的搜索词与候选词，可直接删去无关词或手动填写。库中已有关键词时自动跳过；每份需保留1–100个有效词。
3. **生成并检查问答**：明确点击“AI 生成问答”后，文案创作模型将相近搜索意图归并为1–20组，再分批生成不同标题和资源介绍。保留原始关键词，关联词按实际内容自然融入，不强凑20条。此时不转存、不检查分享、不建链，正文不含分享URL。逐资源编辑、移除、撤销移除与排序，确认并保存整份问答；未确认、未完成AI生成或存在未保存修改时不能进入链接准备。步骤导航只切页，不自动付费。旧流程记录保留原样，明确按新流程生成时另存新记录。
4. **转存与独立链接**：按已确认问答的实际条数N准备N个不同URL，最多20条；不再按关键词数量建链，也不循环分配链接。库中资源沿用原副本与账号，已就绪副本跳过转存；库外资源先按原队列转存。关键词保存到资源库。常规分享只核验一次，未被本地已知发布记录使用时可作为一条；其他链接只调用创建接口，不新增远端匹配或历史扫描。每行固定问答ID绑定URL与提取码，排序、编辑、删行不改变其余问答链接。批内与本地已提交、待核对URL不能重复分配。可一键准备、停止和继续，保留已有回执，未知回执先核对，不自动重发。
5. **预览与下载**：全部资源确认且独立链接齐备后，将分享CTA、链接、提取码与各条介绍组合，预览完整内容，再下载XLSX。固定 `qid`、`问题标题`、`回答内容` 三列，qid留空，不自动上传。导出再次验证审核、生成版本、内容、标题重复、每行链接归属、URL唯一与本地提交记录；取消保存不提示下载成功。

输入、当前步骤和未保存的问答修改按窗口与工作空间暂存。权利确认不恢复。返回修改资源信息或关键词后，原问答与审核不沿用；已经转存的资源可复用本地副本，不重复转存。此前已创建的远端分享不会随修改、删行或关闭窗口自动删除。处理记录和分享回执存储在当前工作空间，刷新后只读取进度，不自动启动转存或建链。

### 本地副本的分享检查与网络恢复

资源库中的 `ready` 表示本人副本已完成归档，仍需检查本次要复用的常规分享；额外链接只新建并保存回执。检查结果为 `unavailable` 时保留具体连接、登录或平台错误，不将它当作分享已失效，页面提供“重新检查并继续”。确认 `invalid` 时仍阻止复用，不绕过账号归属和分享检查。比特本地 API 断连或超时单独提示启动客户端、开启 API 并核对地址，不自动重发请求。旧通用错误从本地分享检查记录恢复具体原因，读取本身不会发起远端操作。重试沿用原副本和已有回执，不重复入库或转存。
