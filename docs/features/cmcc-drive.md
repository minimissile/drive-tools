## 登录与请求

1. 用户手动应用已编译的后端更新。
2. 在“账号管理 → 新增账号”选择“移动云盘”，别名可留空。
3. 在该账号的内置窗口完成官网登录，并进入个人云盘。
4. 点击“核验登录”，或关闭登录窗口触发已有核验流程。账号 UID 由官方身份接口确认，用户名用于填写空别名。
5. 在“网盘文件”选择账号，使用“本地目录 → 同步整个网盘”建立索引；“实时网盘 → 读取目录”管理本人文件。

凭据沿用 `WebTokenSession` 与项目加密秘密存储，按账号隔离；普通 Cookie 与密码不传给前端。139 的 Basic 会话不进入其他网盘的 Bearer 续期接口。过期时在原账号窗口重新登录。请求按官网 JSON 签名协议生成新的时间戳和随机串；服务路由只允许移动云盘官方域名，上传不携带账号登录令牌。

接口失败不自动重试写入，目录结构或分页不完整时不记为同步完成。新增渠道不需要清库或重建现有账号数据。

- [官网前端入口](https://yun.139.com/w/)，本轮读取入口引用的 `app.56b4a805.js` 及按需模块，核对身份、路由、容量、文件列表、创建、更新、回收站删除、小文件上传字段。
