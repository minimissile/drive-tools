# 资源转存与归档耗时优化

## 执行方式（2026-11-24）

任务仍保留预检、转存、文件校验、本人分享和本地归档五个检查点，便于中断恢复；同一次任务会复用已经接入的网盘浏览器会话，不再为每次接口请求重复准备环境、连接浏览器和读取身份。仍保留账号、环境印记及会话过期核验，跨任务重新建立作用域，不把登录身份长期缓存。网盘操作完成后释放会话，再处理本地归档、固定入口和笔记导出。

预检只读取寻找所选文件所需的分页，找到全部所选项后停止翻页；缺失文件仍阻止转存。恢复未知转存结果时，同一次执行复用刚核验过的目标清单，不再立即读取第二遍，也不重新提交转存。已经完成或取消的任务直接返回，不再访问网盘。

启用自动固定入口时，新转存任务先入队，转存前不等待云端创建空入口；文件和本人分享核验完成后，直接创建已绑定本人分享的入口，正常情况由两次写入减少为一次。手动创建入口和不入队的录入流程保持原有行为；普通分享检查不会顺带创建缺失入口。固定入口同步与本地笔记导出并行执行，结果仍按原模块保存。队列仍等待后续工作结束才释放任务占用，不把它们改为不受管理的后台请求。

日志新增任务开始及各阶段的开始时间，可区分排队、预检、转存、校验、建分享和归档的等待。具体速度仍取决于网盘、代理和远端任务处理。
