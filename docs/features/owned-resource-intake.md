# 自有资源直接入库

入口：录入资源 → 基本信息 → 自有资源。

开关默认关闭，保留原来的草稿、读取分享、选择文件和转存流程。开启后，填写自己的网盘分享链接、标题及资源所属账号，点击“直接入库”即可保存到资源库；无需登录核验、读取文件或选择转存目录。已填的分类、标签、说明、封面和提取码继续保存，提取码通过现有凭据存储加密保存。

自有模式不创建目录、不创建转存任务、不新建分享链接，也不自动请求网盘。开关作为录入模式随本地表单暂存，保存后按记录本身恢复。已有非草稿副本保持原录入方式，另存到其他账号仍走原有转存流程。

## 本地记录与后续使用

资源沿用 `resources.source_kind='owned'`，关联副本使用 `recorded` 状态，显示“自有资源已入库”，保留录入的分享地址。手动选择模式不会伪造远端UID、文件清单或已核验时间，也不计入已核验归档副本。

需要对外使用分享时，在资源详情点击“核验自有分享”。该动作显式读取分享文件清单，在所选账号的本人分享记录中匹配同一链接和文件，核验通过后复用原链接并更新归属状态；不调用转存或建链。最多处理100个顶层文件/目录，读取失败或归属不匹配时保留本地资料，不自动重试。

保存接口新增可选 `isOwnResource` 布尔值，不影响未传入字段的原有调用方。`isOwnResource=true` 与 `enqueue=true` 的组合会在入口拒绝。重复录入同一链接、同一账号会复用记录；有转存历史的草稿不能改写为自有资源，已有不同本人分享的副本不能被覆盖。编辑已核验自有资源时修改提取码，会将分享重新标记为待核验。
