# 夸克网盘指纹浏览器

新增夸克网盘账号时，可选择内置浏览器或比特指纹浏览器。浏览器方式与指纹环境在创建时固定；已有内置账号保留原方式。

## 添加账号

1. 在比特环境中登录本人夸克网盘，关闭启动时随机指纹和启动清理 Cookie。
2. 在盘序的账号管理中新增账号，选择夸克与比特指纹浏览器，读取环境列表并选择已登录环境。
3. 读取登录账号，核对用户名、UID、实际出口和运行状态，再添加账号。别名留空时使用网盘用户名。
4. 环境仍有可见窗口时，账号保存后通过浏览器管理显式转为后台，再核验登录；日常操作要求后台模式。

要求代理时，比特环境必须配置代理并开启网络不通停止打开。使用直连环境时取消“要求代理并固定出口 IP”；请求仍由该环境发送，但不保证独立出口。相同出口仍最多绑定三个浏览器环境。

## 请求与账号隔离

绑定账号的身份核验、容量、目录、增删改查、转存、分享及分享统计均经绑定环境发送。文件正文下载与上传分片、存储合并也由浏览器发送，避免使用内置会话或本机 Node 网络。存储请求仅携带临时签名，不附带账号 Cookie。

官方账号接口确认登录后才接受环境中的稳定 UID。账号 UID、指纹配置、连接或出口变化时停止操作，不回退到内置会话。网盘 Cookie 保留在比特环境；传给工具的身份信息仅包含稳定 UID 与用户名。

已支持的网盘、贴吧、知道和公众号可共用同一比特环境，按环境串行执行并分别记录身份。每个环境仅允许关联一个同类网盘账号。
