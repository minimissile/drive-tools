# 网盘账号容量

在“账号管理”查看每个账号的总容量、已使用、剩余容量和使用率。容量来自该账号的网盘接口，按1024换算为KB、MB、GB、TB；悬停总量或已用数值可查看原始字节数。达到90%时进度条提示空间紧张，已用超出总容量时保留实际已用值，剩余显示0，不把比例或剩余算成负数。

点击“核验登录”会在确认本人UID后顺带读取容量；也可单独点击“刷新容量”。打开账号页直接展示本地保存的最近记录，不循环请求远端。实际容量变化后需要刷新；页面标明容量更新时间，不能把旧记录当作实时数据。查询不调用AI、不创建分享、不转存或删除文件。

百度读取`/api/quota`的`total`、`used`；夸克和UC读取各自`/1/clouddrive/member`的`total_capacity`、`use_capacity`；迅雷读取`/drive/v1/about`的`quota.limit`、`quota.usage`。不把保险箱容量、离线转存配额或资源清单大小相加冒充总容量。接口契约参考[百度容量说明](https://pan.baidu.com/union/doc/Cksg0s9ic)、[OpenList夸克/UC适配器](https://github.com/OpenListTeam/OpenList/blob/main/drivers/quark_uc/util.go)及[迅雷适配器](https://github.com/OpenListTeam/OpenList/blob/main/drivers/thunder_browser/driver.go)，真实结果以当前账号接口返回为准。

容量与账号ID、已核验UID共同绑定，不能混用其他账号的缓存。重复同时刷新合并，查询与该账号其他业务串行。接口返回不完整、非整数字节或精度无法保证时显示未知，不能用0代替；失败保留上次成功数据、时间及明确原因。登录失效或停用时，上次数据标为“上次记录”。一般网络失败不会误把已登录账号标为登录过期；明确身份过期或UID不一致仍阻止操作。仅容量读取失败不会撤销已经成功的身份核验。

迅雷若提示会话授权或人工验证，可打开该账号的官方隔离窗口，完成官网要求后关闭窗口，再刷新容量。盘序只使用该窗口原有会话，不绕过验证。容量快照保存在本地SQLite设置中，无数据库版本升级；刷新页面或重开数据库仍可读取。备份恢复会清理连接设置及容量快照，恢复后需重新登录查询。

账号卡片的资源副本数改为全库统计，不依赖当前页面加载的500份资源范围。网盘容量与盘序管理的副本数含义不同：容量反映该账号全部官方空间使用情况，副本数只计算盘序已录入的记录。

2026-10-16验证：源码开发窗口内分别读取百度、夸克、UC、迅雷四个真实账号的容量，均成功显示总量、已用、剩余和进度；迅雷首次会话拒绝后，经官方窗口更新会话重试成功。实际操作网盘筛选和页面重载，确认保存的容量保留；普通1320宽窗口及约856宽半屏布局无遮挡。完整170项核心测试与类型检查通过，新增6项覆盖只读接口、边界值、重复请求、持久化、失败保留、身份变化、多账号隔离及503份资源的副本统计。网络失败、超额和损坏数据使用临时数据库与模拟服务；本轮没有新增AI费用，也未进行真实视频生成测试。
